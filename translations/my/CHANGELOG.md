## [၂၀၂၆-၀၇-၁၅] — သင်ခန်းစာ ၀၉ (ရုပ်ပုံ အသုံးချမှုများ) GPT ရုပ်ပုံ မော်ဒယ်များအတွက် ပြန်လည်ရေးသားခြင်း

### ပြောင်းလဲမှုများ

- **သင်ခန်းစာ ၀၉ "ရုပ်ပုံ ဖန်တီးခြင်း အက်ပ်များဖန်တီးခြင်း" ကို လက်ရှိ **`gpt-image`** အပေါ် ရေးသား ပြန်လည်ပြင်ဆင်ခဲ့သည်။
  မော်ဒယ်မိသားစု (ပုံမှန် **`gpt-image-2`**; `gpt-image-1.5` / `gpt-image-1-mini` ကို GA အဖြစ်လည်းပါဝင်သည်)၊
  အခြေခံ DALL·E 2/3 အကြောင်းအရာအား အစားထိုးသည်။ အဓိကပြုပြင်ချက်များမှာ -
  - `gpt-image` မော်ဒယ်များသည် ပုံကို **base64 (`b64_json`)** အဖြစ် ပြန်လည်ပေးပို့ပြီး URL မဟုတ်ပါ။
    `base64.b64decode(...)` ကို အားလုံးနမူနာများအတွက် ပြင်ဆင်ပြီး `url` နှင့် `requests` ကို ဒေါင်းလုပ်မလုပ်ဘဲ အသုံးပြုသည်။
  - ပုံ API ဗားရှင်းကို `2025-04-01-preview` သို့တိုးမြှင့်ခဲ့သည်။
  - ဖန်တီးထားသော "အပူချိန်" အပိုင်း (ပုံ မော်ဒယ်များသည် `temperature` မယူပါ) နှင့်
    DALL·E-2 အထူးပုံ **မတူကွဲပြားမှုများ** အကြောင်းအရာကို **ပုံတည်းဖြတ်ခြင်း** (မတ်စ်/အင်ပိန်းတင်း) အပိုင်းဖြင့် အစားထိုးခဲ့သည်။
  - `README.md`, `python/aoai-app.py`, `python/oai-app.py`, `python/aoai-solution.py` နှင့်
    နှစ်ခုလုံးသော ရေးသွင်းမှု နုတ်ဘတ်များ (`aoai-assignment.ipynb`, `oai-assignment.ipynb`),
    `typescript/image-generation-app` (`main.ts`, `.env-sample`) နှင့် .NET `.dib` နုတ်ဘတ်ကို သွားရောက် ပြင်ဆင်ထားသည်။

### ဖယ်ရှားခဲ့သည်

- မသုံးတော့တဲ့ `python/aoai-app-variation.py` နဲ့ `python/oai-app-variation.py` နမူနာတွေကို ဖျက်ပစ်လိုက်တယ်

- ဖယ်ရှားထားတဲ့ အပူချိန်နှိုင်းယှဉ်မှု အပိုင်းနဲ့ ဆက်နွယ်ထားတဲ့ အတည်မရှိသော ဓာတ်ပုံပစ္စည်း ၄ ခု ဖျက်လည်း။

### အတည်ပြုပြီးစိစစ်ထားသည်
