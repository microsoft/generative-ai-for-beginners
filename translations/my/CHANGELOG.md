## [2026-07-15] — သင်ခန်းစာ 09 (ပုံစံလျက် အသုံးပြုမှုများ) GPT ပုံစံအတွက် ပြန်ရေးသားခြင်း

### ပြောင်းလဲခဲ့သည်

- **သင်ခန်းစာ ၀၉ "ပုံရိပ်ဖန်တီးမှု အက်ပလီကေးရှင်းများ တည်ဆောက်ခြင်း" ကို** လက်ရှိ **`gpt-image`** 
  မော်ဒယ်မိသားစု (ပုံမှန် **`gpt-image-2`**; `gpt-image-1.5` / `gpt-image-1-mini` ကိုလည်း GA ထည့်သွင်းထား), အစားထိုးပြင်ဆင်ခဲ့သည်၊
  ဟောင်းကြီး DALL·E 2/3 အကြောင်းအရာကို။ ထိပ်တန်းပြင်ဆင်မှုများမှာ -
  - `gpt-image` မော်ဒယ်များသည် ပုံရိပ်ကို **base64 (`b64_json`)** အဖြစ် ပြန်ပေးဆောင်သည်၊ URL မဟုတ်ပါ။ စံနမူနာအားလုံးကို
    `base64.b64decode(...)` သို့ ပြောင်းလဲခဲ့ပြီး `url` ကို `requests` ဖြင့် ဒေါင်းလုဒ်မလုပ်တော့ပါ။
  - ပုံရိပ် API ဗားရှင်းကို `2025-04-01-preview` သို့ မြှင့်တင်ခဲ့သည်။
  - ဖန်တီးလိုက်သော "အပူချိန်" အပိုင်းကို (ပုံများ မော်ဒယ်များသည် `temperature` မလက်ခံပါ) ဖယ်ရှားပြီး
    DALL·E-2 သီးသန့် ရုပ်ပုံ **မျိုးစုံ** အကြောင်းအရာကို **ရုပ်ပုံတည်းဖြတ်ခြင်း** (မတ်စ့်/ပိုင်းစပ်ခွဲတပ်ခြင်း) အပိုင်းဖြင့် အစားထိုးခဲ့သည်။
  - `README.md`, `python/aoai-app.py`, `python/oai-app.py`, `python/aoai-solution.py` နှင့်၊
    တာဝန်ပေးကျမ်းများ (`aoai-assignment.ipynb`, `oai-assignment.ipynb`),
    `typescript/image-generation-app` (`main.ts`, `.env-sample`) နှင့် .NET `.dib` ကျမ်းကို ပြင်ဆင်ထားသည်။

### ဖယ်ရှားပြီး

- ရှေးဟောင်း `python/aoai-app-variation.py` နှင့် `python/oai-app-variation.py` အမည်ပျောက်နမူနာများကို ဖျက်ထားသည်
  (`images.create_variation` သည် DALL·E-2 သာဖြစ်ပြီး `gpt-image` မှ ထောက်ပံ့မှုမရှိပါ)။
- ဖယ်ရှားသွားသော အပူချိန်နှိုင်းယှဉ်ခြင်း အပိုင်းနှင့်ဆက်စပ်သော ၄ ခုသော စာရုပ်ပုံရိပ် ဓာတ်ပုံ ပစ္စည်းများအား ဖျက်သိမ်းခဲ့သည်
  (`v1-generated-image.png`, `v2-generated-image.png`, `v1-temp-generated-image.png`,
  `v2-temp-generated-image.png`)။
- သင်ခန်းစာ၏ Python နမူနာများနှင့် လိုအပ်ချက်များမှ မလိုအပ်သော `requests` ပါဝင်မှုကို လျှော့ချခဲ့သည်။

### အတည်ပြုကြောင်း

- ထောက်ပံ့ထားသော `gpt-image-1.5` မော်ဒယ်အား တူးထွင်ပြီး `aoai-app.py` အဆုံးအစအနေနှင့် စစ်ဆေးပြီး base64
  decode/save လည်ပတ်မှုမှ PNG ဖိုင် တည်ရှိကြောင်း အတည်ပြုခဲ့သည်။ ကျမ်းစာများသည် ဝကျကျ JSON ဖြစ်ကြောင်း အတည်ပြုခဲ့သည်။

  - `.env.copy`, `00-course-setup/03-providers.md` (အကြံပြုထားသော ဖြန့်ချိမှုနှင့် `az cognitiveservices`
    ဖြန့်ချိမှု ကုဒ်များ), နှင့် သင်ခန်းစာ 04, 06, 07, နှင့် 15 များအတွက် README များ။

    အတန်းသင်ခန်းစာ ၀၆ နှင့် ၀၇။
  - အမှန်တင်စာအုပ်များကို အတန်းသင်ခန်းစာ ၀၄၊ ၀၆၊ ၀၇၊ နှင့် ၁၁ (ကုဒ်ဆဲလ်များ) တွင်၊ ထို့အပြင် `shared/python/api_utils.py`

  - နမူနာများထဲမှ `temperature`/`top_p`/`max_tokens` ကို ဖယ်ရှားပြီး ယခု `gpt-5-mini` သို့ ရှေ့နေသတ်မှတ်ထားသည်။
    (`githubmodels-app.py`, `aoai-app-recipe.py`, `oai-app-recipe.py`, ပညာသင်ခန်းစာ ၁၅ RAG README)။
  - သင်ခန်းစာ 06 တွင် **"နည်းလမ်းချက်ပုံစံများသည် `temperature` ကို မသုံးပါ"** ဆိုသော မှတ်ချက်ကို ထည့်သွင်းခဲ့ပြီး

    sampling knobs များဖြင့် မဖြစ်ကြောင်း ရှင်းလင်းပြောကြားထားသည်။ `temperature`/`top_p` များသည်
