# စတင်သင်ကြားသူများအတွက် Generative AI (ဗားရှင်း ၃) - သင်တန်း

Microsoft Cloud Advocates က တင်ဆက်ထားသည့် Generative AI အပလီကေးရှင်းများ တည်ဆောက်ခြင်း အခြေခံများကို ၂၁ ပုဒ် သင်ကြားပေးသည့် ကျယ်ပြန့်သည့် သင်တန်း။

## 🌱 စတင်သင်ယူခြင်း

ဒီသင်တန်းမှာ ပုဒ် ၂၁ ပါဝင်သည်။ မည်သည့်ပုဒ်ကို မဆို စတင်လေ့လာနိုင်ပါသည်။

သင်ခန်းစာများကို "Learn" (သင်ယူရန်) generative AI သဘောတရားရှင်းပြသည့် သင်ခန်းစာများနှင့် "Build" (တည်ဆောက်ရန်) ကို သဘောတရားရှင်းသည့် ပဟေဋိန့်ပေါင်းများကို Python နှင့် TypeScript ဖြင့် ရေးထားသည့် ကုဒ်နမူနာအပါအဝင် သင်ခန်းစာများအဖြစ် သတ်မှတ်ထားသည်။

.NET Developer များအတွက် [Generative AI for Beginners (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst) ကို ကြည့်ပါ။

သင်ခန်းစာတစ်ခုစီတွင် "Keep Learning" အပိုင်းတွင် ပိုမိုလေ့လာနိုင်သော ကိရိယာများပါဝင်သည်။

## လိုအပ်သည့် အရာများ
### ဤသင်တန်း၏ ကုဒ်များကို လုပ်ဆောင်ရန် ကိုယ့်မှာ ရွေးချယ်နိုင်ပါသည် - 
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **သင်ခန်းစာများ:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **သင်ခန်းစာများ:** "githubmodels" (GitHub Models ကို ၂၀၂၆ ခုနှစ် ဇူလိုင်အဆုံးတွင် ပိတ်သင့်သဖြင့် Microsoft Foundry Models ကို အသုံးပြုပါ)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **သင်ခန်းစာများ:** "oai-assignment" 
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - ကိုယ်ပိုင်ကိရိယာပေါ်တွင် မီးလျှပ်စစ်မလိုဘဲ   အွန်လိုင်းမလိုဘဲ မော်ဒယ်များကို လုံးဝ စက်ပစ္စည်းပေါ်တွင် ပြေးနိုင်သည်
   
- Python သို့မဟုတ် TypeScript အခြေခံနားလည်မှုပိုင်ဆိုင်ထားခြင်း ကူညီပေးပါသည် - စတင်သင်ယူသူများအတွက် သင်တန်းများ [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) နှင့် [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) ကို အကြံပြုပါသည်
- [အတူတူ အစိတ်အပိုင်းလုံးကို Fork လုပ်ရန်](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) သင့် GitHub အကောင့်တစ်ခု လိုအပ်သည်

စက်ပစ္စည်းဖွဲ့စည်းထားခြင်းအတွက် အကူအညီပေးရန် **[Course Setup](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** သင်ခန်းစာကို ဖန်တီးထားပါသည်။

နောက်ဖန်လွယ်ကူစေရန် ဤ Repo ကို [ကြယ်ပွင့် (🌟) ထိုးရန်မမေ့လိုက်ပါနဲ့](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)
