# בינה מלאכותית יוצרת למתחילים (גרסה 3) - קורס

למד את היסודות של בניית אפליקציות בינה מלאכותית יוצרת עם הקורס המקיף שלנו הכולל 21 שיעורים על ידי Microsoft Cloud Advocates.

## 🌱 מתחילים

לקורס יש 21 שיעורים. כל שיעור מכסה נושא משלו, כך שאפשר להתחיל בכל מקום שתבחר!

השיעורים מתויגים כ"שיעורי למידה" המסבירים מושג בבינה מלאכותית יוצרת או כ"שיעורי בנייה" המסבירים מושג ודוגמאות קוד ב-**Python** וב-**TypeScript** כאשר אפשרי.

למפתחים ב-.NET מומלץ לבדוק את [בינה מלאכותית יוצרת למתחילים (מהדורת .NET)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

כל שיעור כולל גם חלק "המשך ללמוד" עם כלים נוספים ללמידה.

## מה צריך
### להפעלת קוד הקורס, אפשר להשתמש באחד מ:
 - [שירות Azure OpenAI](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **שיעורים:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **לקחים:** "githubmodels" (GitHub Models מפסיק לפעול בסוף יולי 2026 - השתמש במקום זאת ב-Microsoft Foundry Models)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **לקחים:** "oai-assignment" 
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - הפעל מודלים במלואם במצב לא מקוון על המכשיר שלך, ללא צורך במנוי לענן
   
- ידע בסיסי בפייתון או TypeScript מועיל - \*למתחילים מוחלטים מומלץ לבדוק את קורסי ה-[Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) וה-[TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) הללו
- חשבון GitHub כדי [לעשות fork לכל המאגר הזה](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) לחשבון ה-GitHub האישי שלך

יצרנו שיעור **[הגדרת קורס](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** כדי לסייע לך בהקמת סביבת הפיתוח שלך.

אל תשכח [לסמן בכוכب (🌟) מאגר זה](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) כדי למצוא אותו בקלות מאוחר יותר.
