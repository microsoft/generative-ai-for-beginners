# AI גנרטיבי למתחילים (גרסה 3) - קורס

למדו את יסודות בניית אפליקציות AI גנרטיבי עם הקורס המקיף שלנו הכולל 21 שיעורים, עם Microsoft Cloud Advocates.

## 🌱 להיכנס לעניינים

לקורס זה יש 21 שיעורים. כל שיעור מכסה נושא משלו אז התחילו היכן שתרצו!

השיעורים מסומנים או כ"שיעורי למידה" המסבירים מושג AI גנרטיבי, או כ"שיעורי בנייה" המסבירים מושג ודוגמאות קוד בשתי שפות **Python** ו-**TypeScript** כשאפשר.

למפתחים של .NET מומלץ לבדוק את [AI גנרטיבי למתחילים (מהדורת .NET)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

כל שיעור כולל גם סעיף "למידה נוספת" עם כלים נוספים ללמידה.

## מה צריך
### להריץ את הקוד של הקורס הזה, אפשר להשתמש באחת מהאפשרויות:
 - [שירות Azure OpenAI](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **שיעורים:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **שיעורים:** "githubmodels" (GitHub Models ייפסק בסוף יולי 2026 - השתמשו במקום זאת ב-Microsoft Foundry Models)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **שיעורים:** "oai-assignment"
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - להריץ מודלים במצב לא מקוון לחלוטין במכשיר שלכם, לא נדרשת מנוי ענן
   
- ידע בסיסי ב-Python או TypeScript מועיל - \*למתחילים מוחלטים מומלץ לעיין בקורסים אלו של [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) ו-[TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst)
- חשבון GitHub כדי [לפרוץ את כל המאגר הזה](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) לחשבון ה-GitHub האישי שלכם

יצרנו שיעור **[הקמת הקורס](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** שיעזור לכם להגדיר את סביבת הפיתוח שלכם.

אל תשכחו [לתת כוכב (🌟) למאגר זה](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) כדי שיהיה לכם קל יותר למצוא אותו אחר כך.
