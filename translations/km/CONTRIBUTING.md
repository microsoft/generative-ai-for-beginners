# ការរួមចំណែក

គម្រោងនេះស្វាគមន៍ការរួមចំណែក និងឱ្យដំបូន្មាន។ ការរួមចំណែកភាគច្រើនតម្រូវឱ្យអ្នក
အម្រង់សំណុំសិទ្ធិរបស់អ្នករួមចំណែក (CLA) ដែលបញ្ជាក់ថាអ្នកមានសិទ្ធិ,
ហើយពិតជាអនុញ្ញាតឱ្យយើងប្រើសិទ្ធិនោះសម្រាប់ការរួមចំណែករបស់អ្នក។ សម្រាប់ព័ត៌មានលម្អិត សូមទស្សនា
<https://cla.microsoft.com>។

> សំខាន់៖ បើករៀបចំការបកប្រែអត្ថបទក្នុងឃ្លាំងនេះ សូមប្រាកដថាអ្នកមិនប្រើការបកប្រែដោយម៉ាស៊ីនឡើយ។ យើងនឹងផ្ទៀងផ្ទាត់ការបកប្រែតាមរយៈសហគមន៍ ដូចនេះសូមស្ម័គ្រចិត្តធ្វើការបកប្រែចំពោះភាសាដែលអ្នកមានជំនាញគ្រប់គ្រាន់តែប៉ុណ្ណោះ។

នៅពេលអ្នកដាក់ស្នើការទាញយក, CLA-bot នឹងកំណត់ដោយស្វ័យប្រវត្តិនិយាយថាអ្នកត្រូវ
ផ្ដល់ CLA ហើយតុបតែង PR ឲ្យសមស្រប (ឧ. ស្លាក, មតិយោបល់)។ គ្រាន់តែអនុវត្តតាម
សេចក្តីណែនាំដែលបញ្ជាក់ដោយបុត។ អ្នកត្រូវធ្វើការនេះតែម្តងប៉ុណ្ណោះសម្រាប់ឃ្លាំងទាំងអស់ដែលប្រើ CLA របស់យើង។

## សំណួរ ឬ បញ្ហា?

សូមកុំបើកបញ្ហា GitHub សម្រាប់សំណួរជំនួយទូទៅ ព្រោះបញ្ជី GitHub ត្រូវបានប្រើសម្រាប់ការស្នើសុំលក្ខណៈពិសេស និងរាយការណ៍កំហុស។ វិធីនេះអាចធ្វើឱ្យយើងតាមដានបញ្ហា ឬកំហុសពិតប្រាកដពីកូដបានតែងតែមានភាពល្អប្រសើរជាងមុន ហើយរក្សាការពិភាក្សាទូទៅផ្សេងពីកូដពិតប្រាកដ។

## កំហុសវាយអត្ថបទ, បញ្ហា, កំហុស និងការរួមចំណែក

រាល់ពេលដែលអ្នកដាក់ស្នើការផ្លាស់ប្តូរណាមួយទៅក្នុងឃ្លាំង Generative AI for Beginners សូមអនុវត្តតាមអនុសាសន៍ដូចខាងក្រោម។

* តែងតែភ្ជាប់ឃ្លាំងទៅគណនីផ្ទាល់របស់អ្នកមុនធ្វើការផ្លាស់ប្តូរ
* កុំបញ្ចូលការផ្លាស់ប្តូរច្រើនក្នុងពាក្យសម្គាល់ទាញយកមួយ។ ឧទាហរណ៍ ស្នើសុំកំណត់ត្រាកំហុសនិងការអាប់ដេតឯកសារប្រើ PR ផ្សេងៗគ្នា
* ប្រសិនបើសំណើទាញយករបស់អ្នកបង្ហាញពីជម្លោះការ merge, សូមធ្វើឱ្យដំណើរការ update មូលដ្ឋានទៅជាគំរូនៃឯកសារចម្បងមុនធ្វើការផ្លាស់ប្តូររបស់អ្នក
* ប្រសិនបើអ្នកកំពុងដាក់ស្នើការបកប្រែ សូមបង្កើត PR មួយសម្រាប់ឯកសារបកប្រែទាំងអស់ ព្រោះមិនទទួលការបកប្រែខ្លះៗសម្រាប់មាតិកា
* ប្រសិនបើអ្នកដាក់ស្នើកំហុសវាយអត្ថបទ ឬកំណែឯកសារ អ្នកអាចបញ្ចូលការផ្លាស់ប្តូរទៅក្នុង PR មួយដែលសមស្រប

## វិសាលភាពកែសម្រួល និងផលិតផលតែមួយភាគី មីទៀត

មេរៀននេះផ្ដោតលើបច្ចេកវិទ្យា Microsoft និងស្តង់ដារបើកដែលមិនអាស្រ័យលើអ្នកផ្គត់ផ្គង់ណាមួយ។ ការរួមចំណែកគួរតែមានគោលបំណងផ្ដល់ការអប់រំយ៉ាងច្បាស់ ហើយមិនគួរត្រូវបានបង្កើតដើម្បីណែនាំឬផ្សព្វផ្សាយផលិតផលពាណិជ្ជកម្មភាគីទីបី សេវាកម្មផ្ដល់ជាសេវា ម៉ូឌែលរ៉ូទ័រ SDK MCP server ឬសេវាកម្មផ្សេងៗជាក់លាក់ពីអ្នកផ្គត់ផ្គង់នោះទេ។

កម្មវិធីប្រភពបើក និងការពឹងផ្អែកភាគីទីបីអាចត្រូវបានយោងពេលដែលពួកវាចាំបាច់សម្រាប់ពន្យល់ពីស្តង់ដារបើក ឬសេណារីអ៊ីម៉េបារ៉ាប្តូរសមាសភាព ដែលត្រូវបានបង្ហាញដោយចម្រង់ស្តង់ដារ ហើយមិនផ្តោតទៅលើផលិតផលអ្នកផ្គត់ផ្គង់ ឬចំណុចបញ្ចប់ដែលផ្ដល់សេវាឡើងវិញទេ។ ប្រសិនបើការរួមចំណែករបស់អ្នករួមបញ្ចូលផលិតផលឬសេវាកម្មរបស់អ្នកផ្គត់ផ្គង់, សូមបើកបញ្ហា និងទទួលយកការអនុម័តពីអ្នកថែរក្សាមុនស្នើសំណើទាញយក។

អ្នករួមចំណែកត្រូវចេញបញ្ជាក់ពីការងារ ការកាន់កាប់ ការឧបត្ថម្ភ ឬសំរបសំរួលផ្សេងៗជាមួយនឹងផលិតផលឬសេវាណាមួយដែលបានយោងនៅក្នុងការរួមចំណែករបស់ពួកគេ។ កុំបញ្ចូលបញ្ជាក់លើតម្លៃការលក់ការថា, សមត្ថភាព, សុវត្ថិភាព, បុគ្គលិកភាព ឬការប្រៀបធៀបទាំងឡាយដែលគ្មានការគាំទ្រ។ ឧទាហរណ៍ដែលអាចដំណើរការបានមិនគួរផ្ទេរព័ត៌មានអ្នករៀន ឬអនុវត្តន៍សកម្មភាពសាធារណៈតាមរយៈសេវាកម្មភាគីទីបីក្រៅប្រព័ន្ធដោយឡែកលំនាំដើមទេ។

## មគ្គុទេសក៍ទូទៅសម្រាប់ការសរសេរ

- ប្រាកដថា URL ទាំងអស់របស់អ្នកត្រូវបានបិទជាអក្សរកោសិកាមោទិការួចបន្ទាប់មកដោយសញ្ញាក្រហមមិនមានចន្លោះបន្ថែមនៅជុំវិញវា ឬនៅខាងក្នុងវា `[]()` ។
- ប្រាកដថាខ្សែភ្ជាប់សព្វថ្ងៃណាមួយ (ឧ. ខ្សែភ្ជាប់ទៅឯកសារ និងថតផ្សេងទៀតក្នុងបណ្ណាល័យ) អាចចាប់ផ្តើមជាមួយ `./`ដែលយោងទៅឯកសារ ឬថតដែលស្ថិតនៅក្នុងថតការងារបច្ចុប្បន្ន ឬ `../` ដែលយោងទៅឯកសារ ឬថតដែលស្ថិតនៅក្នុងថតការងារប្រធានបង្វិល។
- ប្រាកដថាខ្សែភ្ជាប់សព្វថ្ងៃណាមួយ (ឧ. ខ្សែភ្ជាប់ទៅឯកសារ និងថតផ្សេងទៀតក្នុងបណ្ណាល័យ) មានលេខអត្តសញ្ញាណតាមដាន (ឧ. `?` ឬ `&` បន្ទាប់ពីនោះ `wt.mc_id=` ឬ `WT.mc_id=`) នៅចុងខ្សែភ្ជាប់។
- ប្រាកដថា URL មួយណាមួយពីដែនបណ្តាញដូចជា _github.com, microsoft.com, visualstudio.com, aka.ms, និង azure.com_ មានលេខអត្តសញ្ញាណតាមដាន (ឧ. `?` ឬ `&` បន្ទាប់ពីនោះ `wt.mc_id=` ឬ `WT.mc_id=`) នៅចុងវា។
- ប្រាកដថា ខ្សែភ្ជាប់របស់អ្នកមិនមានតំបន់ភាសាជាតិឲ្យនៅក្នុងវា (ឧ. `/en-us/` ឬ `/en/`)។
- ប្រាកដថារូបភាពទាំងអស់ត្រូវបានរក្សាទុកនៅក្នុងថត `./images`។
- ប្រាកដថារូបភាពមានឈ្មោះពិពណ៌នាដែលប្រើអក្សរអង់គ្លេស លេខ និងសញ្ញា​ដុំ​ចុចក្នុង​ឈ្មោះរូបភាព​របស់អ្នក។
