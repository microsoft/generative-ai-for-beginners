# បញ្ចូលបញ្ហាផលិតភាព AI សម្រាប់អ្នកចាប់ផ្តើម (កំណែ ៣) - វគ្គសិក្សា

រៀនមូលដ្ឋាននៃការបង្កើតកម្មវិធីផលិតភាព AI ជាមួយវគ្គសិក្សាពេញវគ្គ ២១ មេរៀនពីអ្នកផ្សព្វផ្សាយ Microsoft Cloud Advocates។

## 🌱 ចាប់ផ្តើម

វគ្គសិក្សានេះមាន ២១ មេរៀន។ មេរៀននីមួយៗគ្របដណ្តប់ប្រធានបទរបស់វា ដូច្នេះចាប់ផ្តើមនៅកន្លែងណានឹងបាន!

មេរៀនត្រូវបានបញ្ជាក់ថាជា "រៀន" ដែលពន្យល់អំពីយល់ដឹង Generative AI ឬ "ស្ថាបនា" ដែលលើកឡើងពីយល់ដឹង និងឧទាហរណ៍កូដទាំង **Python** និង **TypeScript** នៅពេលអាចធ្វើបាន។

សម្រាប់អ្នកអភិវឌ្ឍន៍ .NET សូមមើល [Generative AI សម្រាប់អ្នកចាប់ផ្តើម (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)។
