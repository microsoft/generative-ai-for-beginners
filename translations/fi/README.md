# Generatiivinen tekoäly aloittelijoille (Versio 3) - Kurssi

Opiskele generatiivisten tekoälysovellusten rakentamisen perusteet Microsoft Cloud Advocates -tiimimme kattavalla 21 oppitunnin kurssilla.

## 🌱 Aloittaminen

Kurssilla on 21 oppituntia. Jokainen oppitunti kattaa oman aiheensa, aloita mistä tahansa!

Oppitunnit on merkattu joko "Learn"-oppitunneiksi, jotka selittävät generatiivisen tekoälyn konseptin, tai "Build"-oppitunneiksi, jotka selittävät konseptin ja sisältävät esimerkkikoodia sekä **Pythonilla** että **TypeScriptilä** aina kun mahdollista.

.NET-kehittäjille suosittelemme [Generatiivinen tekoäly aloittelijoille (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst) -kurssia!

Jokainen oppitunti sisältää myös "Keep Learning" -osion lisäoppimistyökaluineen.

## Mitä tarvitset
### Voit ajaa tämän kurssin koodia käyttämällä joko: 
 - [Azure OpenAI Servicea](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Oppitunnit:** "aoai-assignment"
 - [Microsoft Foundry -malleja](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Oppitunnit:** "githubmodels" (GitHub Models poistuu käytöstä heinäkuun 2026 lopussa - käytä sen sijaan Microsoft Foundry -malleja)
 - [OpenAI APIa](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Oppitunnit:** "oai-assignment" 
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Aja mallit täysin offline-laitteellasi ilman pilvitarjousta
   
- Perustiedot Pythonista tai TypeScriptistä auttavat - \*Täysin aloittelijoille tutustu näihin [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) ja [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) -kursseihin
- GitHub-tili, johon voit [forkata tämän koko repositorion](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst)

Olemme luoneet **[Kurssin asennus](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** -oppitunnin auttamaan kehitysympäristön asetuksissa.

Älä unohda [tähtää (🌟) tähän repositorioon](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst), jotta löydät sen helpommin myöhemmin.
