# Generativna umetna inteligenca za začetnike (Različica 3) - Tečaj

Spoznajte osnove ustvarjanja aplikacij z generativno umetno inteligenco z našim obsežnim tečajem iz 21 lekcij, ki ga pripravljajo Microsoft Cloud Advocates.

## 🌱 Začetek

Ta tečaj ima 21 lekcij. Vsaka lekcija pokriva svojo temo, zato začnite kjer želite!

Lekcije so označene bodisi kot "Learn" (Nauči se) lekcije, ki razlagajo koncept generativne umetne inteligence, ali kot "Build" (Zgradi) lekcije, ki razložijo koncept in prikazujejo primere kode v **Pythonu** in **TypeScriptu**, kadar je to mogoče.

Za .NET razvijalce preverite [Generative AI for Beginners (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Vsaka lekcija vključuje tudi odsek "Keep Learning" (Nadaljuj z učenjem) z dodatnimi orodji za učenje.

## Kaj potrebujete
### Za zagon kode tega tečaja lahko uporabite:
