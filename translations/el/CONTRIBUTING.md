# Συμβολή

Αυτό το έργο καλωσορίζει συνεισφορές και προτάσεις. Οι περισσότερες συνεισφορές απαιτούν να
συμφωνήσετε σε μια Συμφωνία Άδειας Συνεισφοράς (CLA) που δηλώνει ότι έχετε το δικαίωμα,
και πραγματικά δίνετε, τα δικαιώματα χρήσης της συνεισφοράς σας. Για λεπτομέρειες, επισκεφθείτε
<https://cla.microsoft.com>.

> Σημαντικό: όταν μεταφράζετε κείμενο σε αυτό το αποθετήριο, παρακαλούμε βεβαιωθείτε ότι δεν χρησιμοποιείτε μηχανική μετάφραση. Θα επαληθεύσουμε τις μεταφράσεις μέσω της κοινότητας, οπότε παρακαλώ προσφέρετε εθελοντικά μόνο για μεταφράσεις σε γλώσσες που γνωρίζετε καλά.

Όταν υποβάλλετε ένα pull request, ένα CLA-bot θα καθορίσει αυτόματα αν χρειάζεται
να παράσχετε CLA και θα διακοσμήσει το PR ανάλογα (π.χ., ετικέτα, σχόλιο). Απλώς ακολουθήστε τις
οδηγίες που παρέχονται από το bot. Θα χρειαστεί να το κάνετε μόνο μία φορά για όλα τα αποθετήρια που χρησιμοποιούν το CLA μας.

Παρακαλούμε μην ανοίγετε θέματα στο GitHub για γενικές ερωτήσεις υποστήριξης καθώς η λίστα στο GitHub πρέπει να χρησιμοποιείται για αιτήματα χαρακτηριστικών και αναφορές σφαλμάτων. Με αυτόν τον τρόπο μπορούμε να παρακολουθούμε πιο εύκολα πραγματικά θέματα ή σφάλματα από τον κώδικα και να κρατάμε τη γενική συζήτηση χωριστή από τον ίδιο τον κώδικα.

## Τυπογραφικά λάθη, Θέματα, Σφάλματα και συνεισφορές

Όποτε υποβάλλετε αλλαγές στο αποθετήριο Generative AI for Beginners, παρακαλούμε ακολουθήστε αυτές τις συστάσεις.

* Πάντα δημιουργείτε fork του αποθετηρίου στο δικό σας λογαριασμό πριν κάνετε τις τροποποιήσεις σας
* Μην συνδυάζετε πολλές αλλαγές σε ένα pull request. Για παράδειγμα, υποβάλετε την επιδιόρθωση σφάλματος και τις ενημερώσεις τεκμηρίωσης με ξεχωριστά PRs
* Αν το pull request σας εμφανίζει συγχωνευτικά ζητήματα, βεβαιωθείτε ότι έχετε ενημερώσει το τοπικό main ώστε να είναι κατοπτρικό του βασικού αποθετηρίου πριν τις τροποποιήσεις σας
* Αν υποβάλλετε μετάφραση, παρακαλούμε δημιουργήστε ένα PR για όλα τα μεταφρασμένα αρχεία καθώς δεν δεχόμαστε μερικές μεταφράσεις για το περιεχόμενο
* Αν υποβάλλετε διόρθωση τυπογραφικού λάθους ή τεκμηρίωσης, μπορείτε να συνδυάσετε τροποποιήσεις σε ένα μόνο PR όπου είναι κατάλληλο

## Πεδίο επιμέλειας και προϊόντα τρίτων

Το πρόγραμμα σπουδών εστιάζει σε τεχνολογίες της Microsoft και ουδέτερα ανοιχτά πρότυπα. Οι συνεισφορές πρέπει να έχουν σαφή εκπαιδευτικό σκοπό και να μην στοχεύουν κυρίως στην εισαγωγή ή προώθηση εμπορικού προϊόντος τρίτου μέρους, φιλοξενούμενης υπηρεσίας, μοντέλου δρομολογητή, SDK, MCP server ή άλλης προσφοράς συγκεκριμένου προμηθευτή.

Λογισμικό ανοιχτού κώδικα και τρίτες εξαρτήσεις μπορεί να αναφέρονται όταν είναι απαραίτητα για την εξήγηση ενός ανοιχτού προτύπου ή σεναρίου διαλειτουργικότητας, παρουσιάζονται ουδέτερα και δεν επικεντρώνονται σε προϊόν ή φιλοξενούμενο endpoint προμηθευτή. Αν η προτεινόμενη συνεισφορά σας περιλαμβάνει προϊόν ή υπηρεσία συγκεκριμένου προμηθευτή, ανοίξτε ένα θέμα και λάβετε την έγκριση του διαχειριστή πριν υποβάλετε pull request.

Οι συνεισφέροντες πρέπει να αποκαλύπτουν οποιαδήποτε σχετική απασχόληση, ιδιοκτησία, χορηγία ή άλλη σύνδεση με προϊόν ή υπηρεσία που αναφέρεται στην συνεισφορά τους. Μην συμπεριλαμβάνετε αβάσιμους ισχυρισμούς για τιμές, απόδοση, ασφάλεια, ιδιωτικότητα ή συγκρίσεις. Παραδείγματα κώδικα που μπορούν να εκτελεστούν δεν πρέπει εξ ορισμού να μεταδίδουν δεδομένα εκπαιδευόμενων ή να πραγματοποιούν δημόσιες ενέργειες μέσω εξωτερικών υπηρεσιών τρίτων.

## Γενικές Οδηγίες για τη συγγραφή

- Βεβαιωθείτε ότι όλοι οι σύνδεσμοι URL σας είναι περικλεισμένοι σε αγκύλες ακολουθούμενες από παρενθέσεις χωρίς επιπλέον κενά γύρω ή μέσα σε αυτές `[]()`.
- Βεβαιωθείτε ότι κάθε σχετικός σύνδεσμος (δηλαδή σύνδεσμοι σε άλλα αρχεία και φακέλους στο αποθετήριο) ξεκινά με `./` που αναφέρεται σε αρχείο ή φάκελο που βρίσκεται στον τρέχοντα φάκελο εργασίας ή `../` που αναφέρεται σε αρχείο ή φάκελο σε γονικό φάκελο εργασίας.
- Βεβαιωθείτε ότι κάθε σχετικός σύνδεσμος (δηλαδή σύνδεσμοι σε άλλα αρχεία και φακέλους στο αποθετήριο) έχει tracking ID (δηλαδή `?` ή `&` και μετά `wt.mc_id=` ή `WT.mc_id=`) στο τέλος του.
- Βεβαιωθείτε ότι κάθε URL από τους ακόλουθους τομείς _github.com, microsoft.com, visualstudio.com, aka.ms, και azure.com_ έχει tracking ID (δηλαδή `?` ή `&` και μετά `wt.mc_id=` ή `WT.mc_id=`) στο τέλος του.
- Βεβαιωθείτε ότι οι σύνδεσμοί σας δεν έχουν συγκεκριμένη τοπική ρύθμιση χώρας (π.χ. `/en-us/` ή `/en/`).
- Βεβαιωθείτε ότι όλες οι εικόνες αποθηκεύονται στον φάκελο `./images`.
- Βεβαιωθείτε ότι οι εικόνες έχουν περιγραφικά ονόματα χρησιμοποιώντας λατινικούς χαρακτήρες, αριθμούς και παύλες στο όνομα της εικόνας.

### Έλεγχος σπασμένων σχετικών διαδρομών

Αυτή η ροή εργασίας διασφαλίζει ότι κάθε σχετική διαδρομή στα αρχεία σας λειτουργεί.
Αυτό το αποθετήριο αναπτύσσεται σε σελίδες GitHub, οπότε πρέπει να είστε πολύ προσεκτικοί όταν γράφετε τους συνδέσμους που συνδέουν τα πάντα ώστε να μην κατευθύνετε κάποιον σε λάθος μέρος.

Για να βεβαιωθείτε ότι οι σύνδεσμοι σας λειτουργούν σωστά απλώς χρησιμοποιήστε το VS code για να το ελέγξετε.

Για παράδειγμα, όταν τοποθετήσετε τον δείκτη πάνω σε οποιονδήποτε σύνδεσμο στα αρχεία σας, θα σας ζητηθεί να ακολουθήσετε τον σύνδεσμο πατώντας **ctrl + click**

![VS code follow links screenshot](../../translated_images/el/vscode-follow-link.85520ab6a1237adc.webp?WT.mc_id=academic-105485-koreyst "Στιγμιότυπο από προτροπή VS code να ακολουθήσει σύνδεσμο όταν τοποθετείτε τον δείκτη πάνω σε σύνδεσμο.")

Αν κάνετε κλικ σε σύνδεσμο και δεν λειτουργεί τοπικά τότε σίγουρα θα ενεργοποιήσει τη ροή εργασίας και δεν θα λειτουργεί στο GitHub.

Για να διορθώσετε αυτό το πρόβλημα, προσπαθήστε να πληκτρολογήσετε τον σύνδεσμο με τη βοήθεια του VS code.

Όταν πληκτρολογήσετε `./` ή `../`, το VS code θα σας προτρέπει να επιλέξετε από τις διαθέσιμες επιλογές σύμφωνα με ό,τι πληκτρολογήσατε.

![VS code select relative path screenshot](../../translated_images/el/vscode-select-relative-path.3804eb73c3a9e5f2.webp?WT.mc_id=academic-105485-koreyst "Στιγμιότυπο από προτροπή VS code για επιλογή σχετικής διαδρομής από αναδυόμενη λίστα.")

Ακολουθήστε τη διαδρομή κάνοντας κλικ στο επιθυμητό αρχείο ή φάκελο και θα είστε βέβαιοι ότι η διαδρομή σας δεν είναι σπασμένη.

Μόλις προσθέσετε τη σωστή σχετική διαδρομή, αποθηκεύστε και στείλτε τις αλλαγές σας, η ροή εργασίας θα ενεργοποιηθεί ξανά για να επαληθεύσει τις αλλαγές σας.
Αν περάσετε τον έλεγχο, τότε είστε έτοιμοι.

### Έλεγχος διαδρομών για tracking

Αυτή η ροή εργασίας διασφαλίζει ότι κάθε σχετική διαδρομή έχει tracking μέσα της.
Αυτό το αποθετήριο αναπτύσσεται σε σελίδες GitHub, οπότε χρειαζόμαστε να παρακολουθούμε την κίνηση μεταξύ των διαφορετικών αρχείων και φακέλων.

Για να βεβαιωθείτε ότι οι σχετικές διαδρομές σας έχουν tracking μέσα τους, απλώς ελέγξτε για το ακόλουθο κείμενο `?wt.mc_id=` στο τέλος της διαδρομής.
Αν είναι προσαρτημένο στις σχετικές διαδρομές σας, τότε θα περάσετε αυτόν τον έλεγχο.

Αν όχι, μπορεί να λάβετε το ακόλουθο σφάλμα.

Για να διορθώσετε αυτό το πρόβλημα, προσπαθήστε να ανοίξετε το αρχείο που επισήμανε η ροή εργασίας και να προσθέσετε το tracking ID στο τέλος των σχετικών διαδρομών.

Μόλις προσθέσετε το tracking ID, αποθηκεύστε και στείλτε τις αλλαγές σας, η ροή εργασίας θα ενεργοποιηθεί ξανά για να επαληθεύσει τις αλλαγές σας.

### Έλεγχος URLs για απουσία τοπικής ρύθμισης χώρας

Αυτή η ροή εργασίας διασφαλίζει ότι κανένα URL διαδικτύου δεν έχει συγκεκριμένη τοπική ρύθμιση χώρας.
Αυτό το αποθετήριο είναι διαθέσιμο σε όλο τον κόσμο, οπότε πρέπει να βεβαιωθείτε να μην συμπεριλάβετε την τοπική ρύθμιση της χώρας σας στα URLs.

Για να βεβαιωθείτε ότι τα URLs σας δεν έχουν τοπική ρύθμιση χώρας, απλώς ελέγξτε για το ακόλουθο κείμενο `/en-us/` ή `/en/` ή οποιαδήποτε άλλη γλωσσική ρύθμιση οπουδήποτε στο URL.
