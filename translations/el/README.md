# Γεννητική Τεχνητή Νοημοσύνη για Αρχάριους (Έκδοση 3) - Ένα Μάθημα

Μάθετε τα θεμέλια της δημιουργίας εφαρμογών Γεννητικής Τεχνητής Νοημοσύνης με το ολοκληρωμένο μας μάθημα 21 μαθημάτων από τους Microsoft Cloud Advocates.

## 🌱 Ξεκινώντας

Αυτό το μάθημα περιλαμβάνει 21 μαθήματα. Κάθε μάθημα καλύπτει το δικό του θέμα, οπότε ξεκινήστε όπου θέλετε!

Τα μαθήματα χαρακτηρίζονται είτε ως "Μάθετε" για την εξήγηση μιας έννοιας Γεννητικής ΤΝ είτε ως "Δημιουργία", που εξηγούν μια έννοια και παρέχουν παραδείγματα κώδικα και στις **Python** και **TypeScript**, όταν είναι δυνατό.

Για προγραμματιστές .NET δείτε το [Generative AI for Beginners (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Κάθε μάθημα περιλαμβάνει επίσης ενότητα "Συνέχισε να Μαθαίνεις" με επιπλέον εργαλεία εκμάθησης.
