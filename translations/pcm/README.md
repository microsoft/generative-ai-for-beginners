# Generative AI for Beginners (Version 3) - A Course

Learn di koko of how to build Generative AI applikeshon dem with our 21-lesson complete course from Microsoft Cloud Advocates.

## 🌱 How to Start

Dis course get 21 lessons. Each lesson get e own topic so you fit start anywhere wey you like!

Lessons dem na either "Learn" wey dey explain Generative AI concept or "Build" wey dey explain concept plus code example for both **Python** and **TypeScript** if e possible.

If na .NET Developer you be, check [Generative AI for Beginners (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Each lesson get "Keep Learning" section too wey get extra tools to help you learn more.

## Wetin You Need
### To run the code for dis course, you fit use any of dis:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Lessons:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Lessons:** "githubmodels" (GitHub Models dey retire by end July 2026 - use Microsoft Foundry Models instead)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Lessons:** "oai-assignment"
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Run models 100% offline for your own device, no need cloud subscription
   
- Basic knowledge for Python or TypeScript go help - \*If you be absolute beginner, check dis [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) and [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) courses
- You go need GitHub account to [fork this whole repo](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) go your own GitHub account

We don create **[Course Setup](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** lesson to help you arrange your development environment.

No forget to [star (🌟) dis repo](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) so you fit find am easily later.
