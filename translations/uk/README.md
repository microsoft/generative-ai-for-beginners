# Генеративний ШІ для Початківців (версія 3) - курс

Засвойте основи створення додатків Генеративного ШІ з нашим комплексним курсом з 21 уроку від Microsoft Cloud Advocates.

## 🌱 Початок роботи

Цей курс має 21 урок. Кожен урок охоплює свою тему, тож починайте з того, що вам подобається!

Уроки позначені як "Learn" — уроки, що пояснюють концепцію Генеративного ШІ, або "Build" — уроки, що пояснюють концепцію та наводять кодові приклади на **Python** та **TypeScript**, коли це можливо.

Для .NET розробників дивіться [Генеративний ШІ для Початківців (.NET версія)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Кожен урок також містить розділ "Keep Learning" з додатковими інструментами для навчання.

## Що вам потрібно
### Щоб запускати код цього курсу, ви можете використовувати:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) — **Уроки:** "aoai-assignment"

- Базові знання Python або TypeScript корисні — \*Для абсолютних початківців дивіться ці курси з [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) та [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst)
