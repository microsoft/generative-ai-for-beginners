# Generatiivne tehisintellekt algajatele (versioon 3) - kursus

Õppige generatiivsete tehisintellekti rakenduste loomise põhialuseid meie 21-õppetunni põhjalikus kursuses Microsoft Cloud Advocatesi poolt.

## 🌱 Algus

Sellel kursusel on 21 õppetundi. Iga õppetund käsitleb oma teemat, seega võite alustada ükskõik kust!

Õppetunnid on märgistatud kas "Õppige" õppetundidena, mis selgitavad generatiivse tehisintellekti kontseptsiooni või "Ehita" õppetundidena, mis selgitavad kontseptsiooni ja näitavad koodinäiteid nii **Pythonis** kui ka **TypeScriptis**, kui võimalik.

.NET arendajatele vaadake [Generatiivne tehisintellekt algajatele (.NET väljaanne)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Igas õppetunnis on ka "Jätka õppimist" jaotis täiendavate õppematerjalidega.

## Mida vajate
### Selle kursuse koodi käivitamiseks võite kasutada:
 - [Azure OpenAI teenus](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Õppetunnid:** "aoai-assignment"
 - [Microsoft Foundry mudelid](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Õppetunnid:** "githubmodels" (GitHub mudelid lõpetavad teenuse 2026. aasta juuli lõpus - kasutage selle asemel Microsoft Foundry mudelite teenust)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Õppetunnid:** "oai-assignment"
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Käitage mudeleid täielikult võrguühenduseta oma seadmes, pole vaja pilve tellimust
   
- Põhiteadmised Pythonist või TypeScriptist on kasulikud - \*Algajatele on soovitatavad need [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) ja [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) kursused
- GitHub konto, et [forkida see hoidla](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) oma GitHubi kontole

Oleme loonud **[kursuse seadistamise](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** õppetunni, mis aitab teil arenduskeskkonda seadistada.

Ärge unustage [tähistada (🌟) seda hoidlat](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst), et leida see hiljem kergemini.
