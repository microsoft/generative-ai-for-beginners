# Generative KI für Anfänger (Version 3) - Ein Kurs

Lernen Sie die Grundlagen zum Erstellen von Generative KI-Anwendungen mit unserem umfassenden 21-Lektionen-Kurs von Microsoft Cloud Advocates.

## 🌱 Erste Schritte

Dieser Kurs hat 21 Lektionen. Jede Lektion behandelt ein eigenes Thema, starten Sie also, wo immer Sie möchten!

Lektionen sind entweder als "Learn"-Lektionen gekennzeichnet, die ein Generative KI-Konzept erklären, oder als "Build"-Lektionen, die ein Konzept und Codebeispiele in **Python** und **TypeScript** erklären, wann immer möglich.

Für .NET-Entwickler sehen Sie sich [Generative KI für Anfänger (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst) an!

Jede Lektion umfasst auch einen Abschnitt "Weiter Lernen" mit zusätzlichen Lernmaterialien.

## Was Sie benötigen
### Um den Code dieses Kurses auszuführen, können Sie entweder verwenden:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Lektionen:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Lektionen:** "githubmodels" (GitHub Models wird Ende Juli 2026 eingestellt – verwenden Sie stattdessen Microsoft Foundry Models)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Lektionen:** "oai-assignment"
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Führen Sie Modelle vollständig offline auf Ihrem eigenen Gerät aus, kein Cloud-Abonnement erforderlich
   
- Grundkenntnisse in Python oder TypeScript sind hilfreich - \*Für absolute Anfänger sehen Sie sich diese [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) und [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) Kurse an
- Ein GitHub-Konto, um [dieses gesamte Repo zu fork](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) auf Ihr eigenes GitHub-Konto

Wir haben eine **[Kursvorbereitung](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)**-Lektion erstellt, die Ihnen beim Einrichten Ihrer Entwicklungsumgebung hilft.

Vergessen Sie nicht, [dieses Repo mit einem Stern (🌟) zu markieren](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst), um es später leichter zu finden.
