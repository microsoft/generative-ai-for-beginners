# Generative AI para sa mga Baguhan (Bersyon 3) - Isang Kurso

Alamin ang mga pundasyon ng paggawa ng mga aplikasyon ng Generative AI gamit ang aming 21-aralin na komprehensibong kurso mula sa Microsoft Cloud Advocates.

## 🌱 Pagsisimula

Ang kurso na ito ay may 21 mga aralin. Ang bawat aralin ay sumasaklaw sa sarili nitong paksa kaya simulang kahit saan mo gusto!

Ang mga aralin ay tinatawag na "Learn" na mga aralin na nagpapaliwanag ng konsepto ng Generative AI o "Build" na mga aralin na nagpapaliwanag ng konsepto at mga halimbawa ng code sa parehong **Python** at **TypeScript** kung posible.

Para sa mga .NET Developers tingnan ang [Generative AI para sa mga Baguhan (.NET Edisyon)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Ang bawat aralin ay mayroon ding seksyon na "Keep Learning" na may mga dagdag na kasangkapan sa pag-aaral.

## Ano ang Kailangan Mo
### Para patakbuhin ang code ng kurso na ito, maaari kang gumamit ng alinman sa: 
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Mga Aralin:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Mga Aralin:** "githubmodels" (Ang GitHub Models ay magtatapos sa dulo ng Hulyo 2026 - gamitin na ang Microsoft Foundry Models)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Mga Aralin:** "oai-assignment" 
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Patakbuhin ang mga modelo nang ganap offline sa iyong sariling device, walang kailangang cloud subscription
   
- Ang pangunahing kaalaman sa Python o TypeScript ay nakatutulong - \*Para sa mga ganap na baguhan tumingin sa mga kursong ito na [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) at [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst)
- Isang GitHub account para [i-fork ang buong repo na ito](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) sa iyong sariling GitHub account

Nilikha namin ang isang **[Course Setup](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** na aralin para tulungan ka sa pag-set up ng iyong development environment.

Huwag kalimutang [bigyan ng star (🌟) ang repo na ito](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) para mas madali mo itong makita sa susunod.

## 🧠 Handa Ka Na Bang I-deploy?
