# Генеративен ИИ за начинаещи (Версия 3) - Курс

Научете основите на създаването на приложения с Генеративен ИИ с нашия изчерпателен курс от 21 урока, представен от Microsoft Cloud Advocates.

## 🌱 Започване

Този курс има 21 урока. Всеки урок покрива своя тема, така че започнете откъдето пожелаете!

Уроките са означени като „Научете“ - уроци, обясняващи концепции на Генеративния ИИ, или „Създайте“ - уроци, които обясняват концепция и примерен код както на **Python**, така и на **TypeScript**, когато е възможно.

За .NET разработчици разгледайте [Генеративен ИИ за начинаещи (.NET издание)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Всеки урок включва и секция „Продължавайте да учите“ с допълнителни учебни ресурси.

## Какво ви е необходимо
### За да стартирате кода от този курс, можете да използвате едно от следните:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Уроци:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Уроци:** "githubmodels" (GitHub Models се оттегля в края на юли 2026 г. - използвайте Microsoft Foundry Models вместо това)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Уроци:** "oai-assignment"
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Стартирайте модели изцяло офлайн на собственото си устройство, не е необходим абонамент за облак
   
- Основни знания по Python или TypeScript са полезни - \*За абсолютно начинаещи разгледайте тези [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) и [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) курсове
- GitHub акаунт, за да [форкнете този цял репозиториум](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) във вашия собствен GitHub акаунт

Създадохме урок **[Настройка на курса](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)**, за да ви помогнем с настройването на вашата развойна среда.

Не забравяйте да [даденете звезда (🌟) на този репозиториум](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst), за да го намирате по-лесно по-късно.
