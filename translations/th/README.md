# ปัญญาประดิษฐ์สร้างสรรค์สำหรับผู้เริ่มต้น (เวอร์ชัน 3) - หลักสูตร

เรียนรู้พื้นฐานการสร้างแอปพลิเคชันปัญญาประดิษฐ์สร้างสรรค์กับหลักสูตรครอบคลุม 21 บทเรียนโดย Microsoft Cloud Advocates

## 🌱 เริ่มต้นใช้งาน

หลักสูตรนี้มี 21 บทเรียน แต่ละบทเรียนครอบคลุมหัวข้อของตนเอง คุณสามารถเริ่มได้จากที่ที่คุณต้องการ!

บทเรียนถูกจัดเป็นบทเรียน "เรียนรู้" ที่อธิบายแนวคิดปัญญาประดิษฐ์สร้างสรรค์ หรือบทเรียน "สร้าง" ที่อธิบายแนวคิดพร้อมตัวอย่างโค้ดทั้ง **Python** และ **TypeScript** เมื่อเป็นไปได้

สำหรับนักพัฒนา .NET โปรดดูที่ [ปัญญาประดิษฐ์สร้างสรรค์สำหรับผู้เริ่มต้น (เวอร์ชัน .NET)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

แต่ละบทเรียนยังมีส่วน "เรียนรู้เพิ่มเติม" พร้อมเครื่องมือการเรียนรู้เพิ่มเติม

## สิ่งที่คุณต้องการ
### เพื่อรันโค้ดของหลักสูตรนี้ คุณสามารถใช้:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **บทเรียน:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **บทเรียน:** "githubmodels" (GitHub Models จะหยุดให้บริการปลายเดือนกรกฎาคม 2026 - ใช้ Microsoft Foundry Models แทน)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **บทเรียน:** "oai-assignment"
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - รันโมเดลแบบออฟไลน์เต็มรูปแบบบนอุปกรณ์ของคุณเอง ไม่ต้องสมัครสมาชิกคลาวด์
   
- ความรู้พื้นฐานเกี่ยวกับ Python หรือ TypeScript จะช่วยได้ - \*สำหรับผู้เริ่มต้นอย่างแท้จริงเชิญดูหลักสูตร [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) และ [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst)
- บัญชี GitHub สำหรับ [ฟอร์กที่เก็บทั้งหมดนี้](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) ไปยังบัญชี GitHub ของคุณเอง

เราได้สร้างบทเรียน **[การตั้งค่าสิ่งแวดล้อมของหลักสูตร](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** เพื่อช่วยคุณตั้งค่าสภาพแวดล้อมการพัฒนา

อย่าลืม [กดดาว (🌟) ให้ที่เก็บนี้](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) เพื่อให้ง่ายต่อการค้นหาในภายหลัง
