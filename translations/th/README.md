# Generative AI สำหรับผู้เริ่มต้น (เวอร์ชัน 3) - หลักสูตร

เรียนรู้พื้นฐานการสร้างแอปพลิเคชัน Generative AI ด้วยหลักสูตรครบวงจร 21 บทเรียนโดย Microsoft Cloud Advocates

## 🌱 การเริ่มต้น

หลักสูตรนี้มี 21 บทเรียน บทเรียนแต่ละบทครอบคลุมหัวข้อเฉพาะ เริ่มต้นได้จากบทเรียนใดก็ได้ที่คุณชอบ!

บทเรียนถูกจัดประเภทเป็นบทเรียน "เรียนรู้" อธิบายแนวคิด Generative AI หรือบทเรียน "สร้าง" ที่อธิบายแนวคิดและตัวอย่างโค้ดทั้งใน **Python** และ **TypeScript** เมื่อเป็นไปได้

สำหรับนักพัฒนา .NET โปรดดู [Generative AI สำหรับผู้เริ่มต้น (ฉบับ .NET)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

แต่ละบทเรียนยังมีส่วน "เรียนรู้อย่างต่อเนื่อง" พร้อมเครื่องมือการเรียนรู้เพิ่มเติม

## สิ่งที่คุณต้องมี
### ในการรันโค้ดของหลักสูตรนี้ คุณสามารถใช้ได้ทั้ง:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **บทเรียน:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **บทเรียน:** "githubmodels" (GitHub Models จะเลิกใช้ในปลายเดือนกรกฎาคม 2026 - โปรดใช้ Microsoft Foundry Models แทน)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **บทเรียน:** "oai-assignment" 
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - รันโมเดลได้แบบออฟไลน์เต็มรูปแบบบนอุปกรณ์ของคุณเอง ไม่ต้องสมัครสมาชิกคลาวด์
   
- ความรู้พื้นฐานเกี่ยวกับ Python หรือ TypeScript จะเป็นประโยชน์ - \*สำหรับผู้เริ่มต้นอย่างแท้จริง สามารถดูหลักสูตร [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) และ [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) เหล่านี้
- บัญชี GitHub เพื่อ [fork repo ทั้งหมดนี้](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) ไปที่บัญชี GitHub ของคุณเอง

เราได้สร้างบทเรียน **[Course Setup](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** เพื่อช่วยคุณในการตั้งค่าสภาพแวดล้อมการพัฒนา

อย่าลืม [กดดาว (🌟) ที่ repo นี้](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) เพื่อให้หาง่ายขึ้นในภายหลัง
