# Generatywna AI dla początkujących (Wersja 3) - Kurs

Poznaj podstawy tworzenia aplikacji Generatywnej AI dzięki naszemu 21-lekcyjnemu kompleksowemu kursowi prowadzonemu przez Microsoft Cloud Advocates.

## 🌱 Zacznijmy

Ten kurs zawiera 21 lekcji. Każda lekcja omawia inny temat, więc zacznij tam, gdzie chcesz!

Lekcje są oznaczone jako „Nauka” tłumaczące koncepcję Generatywnej AI lub „Buduj” zawierające wyjaśnienie koncepcji oraz przykłady kodu w **Python** i **TypeScript**, o ile to możliwe.

Dla programistów .NET sprawdź [Generatywna AI dla początkujących (edycja .NET)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Każda lekcja zawiera również sekcję „Kontynuuj naukę” z dodatkowymi materiałami edukacyjnymi.

## Czego potrzebujesz
### Aby uruchomić kod z tego kursu, możesz użyć jednego z:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Lekcje:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Lekcje:** "githubmodels" (GitHub Models zostanie wycofany pod koniec lipca 2026 - zamiast tego używaj Microsoft Foundry Models)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Lekcje:** "oai-assignment"
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Uruchamiaj modele całkowicie offline na własnym urządzeniu, bez wymogu subskrypcji chmurowej
   
- Podstawowa znajomość Pythona lub TypeScript jest pomocna - \*Dla zupełnych początkujących sprawdź te kursy [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) i [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst)
- Konto GitHub, aby [sforkować całe to repozytorium](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) na swoje konto GitHub

Stworzyliśmy lekcję **[Konfiguracja kursu](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)**, która pomoże Ci w skonfigurowaniu środowiska programistycznego.

Nie zapomnij [dodać repozytorium do gwiazdek (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst), aby łatwiej je znaleźć później.
