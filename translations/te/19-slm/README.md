# జనరేటివ్ AI కోసం ప్రారంభదారుల కోసం చిన్న భాషా నమూనాలలో పరిచయం
జనరేటివ్ AI అనేది ఒక ఆసక్తికరమైన కళాఖండం, ఇది కొత్త కంటెంట్‌ను సృష్టించే సిస్టములను సృష్టించడంపై దృష్టి సారిస్తుంది. ఈ కంటెంట్ టెక్స్ట్, చిత్రాలు, సంగీతం మరియు అంతటా వర్చువల్ పరిసరాలను కలిగి ఉండవచ్చు. జనరేటివ్ AI యొక్క అత్యంత ఉత్సాహభరితమైన అప్లికేషన్‌లలో ఒకటి భాషా నమూనాల శ్రేణిలో ఉంది.

## చిన్న భాషా నమూనాలు అంటే ఏమిటి?

చిన్న భాషా నమూనా (SLM) అనేది పెద్ద భాషా నమూనా (LLM) యొక్క స్వల్ప పరిమాణం కలిగిన రూపం, ఇది LLMల యొక్క అనేక నిర్మాణ సూత్రాలు మరియు పద్ధతులను ఉపయోగించుకుంటూ, గణనాత్మక భారాన్ని గణనీయంగా తగ్గిస్తుంది.

SLMలు వ్యక్తి వంటి టెక్స్ట్‌ను ఉత్పత్తి చేసేందుకు రూపొందించిన భాషా నమూనాల ఉపశ్రేణి. GPT-4 వంటి పెద్ద నమూనాలతో అందుబాటులో ఉన్నవాటికి భిన్నంగా, SLMలు చిన్న మరియు సమర్థవంతమైనవిగా ఉంటాయి, ఇది గణనాత్మక వనరుల పరిమితుల్లో ఉన్న అప్లికేషన్‌లకు అనుకూలంగా ఉంటుంది. చిన్న పరిమాణం ఉన్నా కూడా, వీటికి వివిధ విధులలో పని చేయడం సాధ్యమవుతుంది. సాధారణంగా, SLMలు LLMలను కంప్రెస్ లేదా డిస్టిల్ చేయడం ద్వారా నిర్మించబడతాయి, ఇది అసలు నమూనా యొక్క పనితీరు మరియు భాషా సామర్థ్యాల పెద్ద భాగాన్ని నిల్వ ఉంచేందుకు లక్ష్యంగా ఉంటుంది. నమూనా పరిమాణం ఈ తగ్గింపు మొత్తం సంకీర్ణతను తగ్గిస్తూ, స్మృతి వినియోగం మరియు గణనాత్మక అవసరాల్లో సమర్థతను మెరుగు పరుస్తుంది. ఈ ఆప్టిమైజేషన్ల వెంట కూడా, SLMలు సహజ భాషా ప్రాసెసింగ్ (NLP) పనులను విస్తృతంగా చేయగలవు:

- టెక్స్ట్ ఉత్పత్తి: సమగ్రమైన మరియు సందర్భానుగుణమైన వాక్యాలు లేదా పేరాలు సృష్టించడం.
- టెక్స్ట్ పూర్తి: ఇచ్చిన ప్రాంప్ట్ ఆధారంగా వాక్యాలను ఊహించి పూర్తి చేయడం.
- అనువాదం: ఒక భాష నుండి మరో భాషకు టెక్స్ట్ మార్చడం.
- సమరీకరణ: పొడవాటి టెక్స్ట్ టుక్కల్ని సంక్షిప్త, సులభంగా అర్థం అయ్యే సారాంశాలుగా మార్చడం.

సాధారణంగా వారి పెద్దనమూనాలతో పోలిస్తే కొంత పనితీరు లేదా అర్ధం లోతులో తేడాలు ఉంటాయి.

## చిన్న భాషా నమూనాలు ఎలా పని చేస్తాయి?
SLMలు తిరుగుతున్నంత ఫార్మాట్లలో విశాలమైన టెక్స్ట్ డేటా పై శిక్షణ పొందుతాయి. శిక్షణ సమయంలో, అవి భాషా నమూనాల నమూనాలు మరియు నిర్మాణాలను నేర్చుకుని, వ్యాకరణ పరంగా సరిగా మరియు సందర్భానుగుణంగా ఉన్న టెక్స్ట్‌ను సృష్టించగలిగేలా తయారవుతాయి. శిక్షణ ప్రక్రియలో:

- డేటా సేకరణ: వివిధ మూలాల నుండి పెద్ద టెక్స్ట్ డేటాసెట్లను సేకరించడం.
- ప్రీప్రాసెసింగ్: శిక్షణ కోసం డేటాను శుభ్రపరచి, సజావుగా ఆర్గనైజ్ చేయడం.
- శిక్షణ: యంత్ర అధ్యయన అల్గోరిథమ్లను ఉపయోగించి నమూనాను టెక్స్ట్ ఎలా అర్థం చేసుకోవాలో మరియు ఉత్పత్తి చేయాలో నేర్చించడం.
- ఫైన్-ట్యూనింగ్: ప్రత్యేక పనులపై పనితీరు మెరుగుపరచడానికి నమూనాను సర్దుబాటు చేయడం.

SLMల అభివృద్ధి, పూర్తి పరిమాణ LLMలు భారమైన వనరుల అవసరాల కారణంగా ప్రాప్యత లేకపోయే మొబైల్ పరికరాలు లేదా ఎజ్ కంప్యూటింగ్ ప్లాట్ఫారమ్‌ల వంటి వనరు-పరిమిత వాతావరణాలలో ఉపయోగించడానికి సరిపోతున్న నమూనాల అవసరానికి అనుగుణంగా ఉంది. సమర్థతపై దృష్టి సారించడం ద్వారా, SLMలు పనితీరు మరియు ప్రాప్యత మధ్య సంతులనం కోరుతూ విస్తృత పరిధిలో అప్లికేషన్‌లను సాధ్యం చేస్తాయి.

## నేర్చుకునే లక్ష్యాలు

ఈ పాఠంలో, మేము SLMకు సంబంధించిన సమాచారాన్ని పరిచయం చేసి, Microsoft Phi-3తో ఆ మెర్సేపోతు క్రొత్త దృశ్య, టెక్స్ట్ కంటెంట్ మరియు MoEలోని వివిధ వేదికలను తెలుసుకుంటాం.

ఈ పాఠం ముగిసినప్పుడు, మీరు ఈ కింది ప్రశ్నలకు జవాబివ్వగలుగుతారు:

- SLM అంటే ఏమిటి?
- SLM మరియు LLM మధ్య తేడా ఏమిటి?
- Microsoft Phi-3/3.5 కుటుంబం అంటే ఏమిటి?
- Microsoft Phi-3/3.5 కుటుంబంతో ఎలా ఇన్ఫెరెన్స్ అమలు చేయాలి?

సిద్ధమా? మనం మొదలెట్టుదాం.

## పెద్ద భాషా నమూనాలు (LLMs) మరియు చిన్న భాషా నమూనాలు (SLMs) మధ్య తేడాలు

LLMలు మరియు SLMలు probabilistic యంత్ర అధ్యయనం యొక్క ప్రాథమిక సూత్రాలపై నిర్మించబడి ఉంటాయి, నిర్మాణ రూపకల్పన, శిక్షణ పద్ధతులు, డేటా ఉత్పత్తి ప్రక్రియలు మరియు నమూనా మదింపు పద్ధతులలో సమానమైన దారులను అనుసరిస్తాయి. కానీ, ఈ రెండు నమూనాల రకాలను వేరు చేసే కొన్ని ముఖ్యమైన అంశాలు ఉన్నాయి.

## చిన్న భాషా నమూనాల అప్లికేషన్లు

SLMలకు విస్తృత అప్లికేషన్లు ఉన్నాయి, వాటిలో:

- చాట్ బాట్‌లు: కస్టమర్ సమర్థన అందించడం మరియు సంభాషణాత్మకంగా వినియోగదారులతో వ్యవహరించడం.
- కంటెంట్ సృష్టి: రచయితలకు ఆలోచనలు లేదా మొత్తం ఆర్టికల్స్ ప్రణాళిక చేస్తూ సహాయం చేయడం.
- విద్య: విద్యార్థులకు రాయడం అసైన్‌మెంట్స్ లేదా కొత్త భాషలు నేర్చుకోవడంలో సహాయం.
- ప్రాప్యం: వైకల్యాలతో ఉన్న వ్యక్తుల కోసం పాఠ్య-కు-స్పీచ్ వ్యవస్థలు వంటి పరికరాలను సృష్టించడం.

**పరిమాణం**
  
LLMలు మరియు SLMల మధ్య ప్రధాన తేడా నమూనాల పరిమాణంలోనే ఉంటుంది. ChatGPT (GPT-4) వంటి LLMలు సుమారు 1.76 ట్రిలియన్ల పరిమాణాలను కలిగి ఉంటాయి, అలాగే ఓపెన్ సోర్స్ SLMలు మిస్ట్రాల్ 7B వంటి నమూనాలు సుమారు 7 బిలియను పరిమాణాలతో రూపొందించబడ్డాయి. ఈ తేడా ప్రధానంగా నమూనా నిర్మాణం మరియు శిక్షణ పద్ధతుల వేరియేషన్లకు కారణం. ఉదాహరణకు, ChatGPT ఒక ఎన్‌కోడర్-డికోడర్ ఫ్రేమ్‌వర్క్‌లో స్వీయ దృష్టి (self-attention) మెకానిజం ఉపయోగిస్తుంటే, మిస్ట్రాల్ 7B స్ర్కోలింగ్ విండో దృష్టి (sliding window attention) ఉపయోగించి ఒక డికోడర్-మాత్ర నమూనాలో సమర్థవంతమైన శిక్షణ అందిస్తుంది. ఈ నిర్మాణ వ్యత్యాసం నమూనాల సంక్లిష్టత మరియు పనితీరు పై తీవ్రమైన ప్రభావాలు కలిగిస్తుంది.

**అర్థం చేసుకోవడం**

SLMలు సాధారణంగా నిర్దిష్ట డొమైన్లలో పనితీరు కోసం ఆప్టిమైజ్ చేయబడి ఉండి, చాలా ప్రత్యేకత గలవని అంటే విస్తృత రాజకీయ విషయాల లేదా విభిన్న జ్ఞాన రంగాలలో సమగ్ర భావనకు పరిమితులుగా ఉండవచ్చు. వేరే వైపు, LLMలు విస్తృతంగా విభిన్న డేటాను శిక్షణ పొందించి, మానవీయ బుద్ధి సిమ్యులేట్ చేయడానికి లక్ష్యంగా ఉంటాయి. విస్తృత డొమైన్లకు అనువైన ఈ నమూనాలు అనేక తల్లి-చిన్న పనుల కోసం అనుకూలంగా ఉంటాయి, సహజ భాషా ప్రాసెసింగ్ మరియు ప్రోగ్రామింగ్ సహా. 

**గణన**

LLMల శిక్షణ మరియు అమలు గణన పరిధి భారీగా ఉండటం వల్ల పెద్ద స్థాయి GPU క్లస్టర్లు అవసరం అవుతాయి. ఉదాహరణకు, ChatGPT నమూనాను మొదలుండి శిక్షణ చేయడంలో వేలల పొడవునట్టు GPUs అవసరం. SLMలు తక్కువ పరిమాణం గలవిగా, తక్కువ గణన వనరులు అవసరమైంది. మిస్ట్రాల్ 7B వంటి నమూనాలు మోస్తరు GPU సామర్థ్యాలున్న లోకల్ మెషీన్లపై శిక్షణ చేయవచ్చని, అయితే శిక్షణ కొంత గంటల పాటు అనేక GPUsపై కొనసాగుతుంది.

**పక్షపాతం**

LLMలలో పక్షపాతం ఒక సాధారణ సమస్య, ఇది శిక్షణ డేటా స్వభావం కారణంగా జరుగుతుంది. ఈ నమూనాలు ఎక్కువగా ఇంటర్నెట్ నుండి లభించే సారాంశం లేని డేటా ఆధారంగా పనిచేస్తాయి, ఇది కొన్ని గుంపులను తక్కువ ప్రాతినిధ్యం ఇవ్వవచ్చు లేదా తప్పు లేబుల్‌లను తీసుకుని ఉండవచ్చు, లేదా భాషా తేడాలు, భౌగోళిక వైవిధ్యాలు మరియు వ్యాకరణ సందర్బాలతో పక్షపాతాలు కలిగించవచ్చు. అదనంగా, LLM నిర్మాణ సంక్లిష్టత ఈ పక్షపాతాలను అదే సమయంలో పక్కనుంచి పెంచగలదు, ఇది జాగ్రత్తగా ఫైన్-ట్యూన్ చేయకపోతే కనిపించకపోవచ్చు. ప్రత్యామ్నాయంగా, SLMలు నిర్థిష్ట డొమైన్-స్పెసిఫిక్ డేటాసెట్‌లపై శిక్షణ పొందినప్పుడు, ఈ పక్షపాతాలకు తక్కువగా గురవుతాయి, అయినప్పటికీ పూర్తిగా విముక్తలే కావు.

**ఇన్ఫెరెన్స్**

SLMల తక్కువ పరిమాణం వారికి ఇన్ఫెరెన్స్ వేగం విషయంలో పెద్ద ప్రయోజనం అందిస్తుంది, ఇది స్థానిక హార్డ్‌వేర్‌పై వేగంగా అవుట్‌పుట్‌లను ఉత్పత్తి చేయగలదు, విస్తృత సమాంతర ప్రాసెసింగ్ అవసరం లేకుండానే. LLMలు వారి పరిమాణం మరియు సంక్లిష్టత కారణంగా, తగిన ఇన్ఫెరెన్స్ సమయాలు సాధించడానికి పెద్ద సమాంతర గణన వనరులు అవసరం. అనేక వినియోగదారుల ఉనికి LLMల స్పందన సమయాలను తగ్గిస్తుంది, ముఖ్యంగా పెద్ద స్థాయిలో అమలు చేయబడినప్పుడు.

సారాంశంగా, LLMలు మరియు SLMలు యంత్ర అభ్యాసంలో ప్రాథమికమైన పునాది పంచుకుని ఉండినప్పటికీ, నమూనా పరిమాణం, వనరుల అవసరాలు, సందర్భ అవగాహన, పక్షపాతానికి గురవడము, మరియు ఇన్ఫెరెన్స్ వేగం వంటి అంశాలలో ప్రముఖంగా భిన్నంగా ఉంటాయి. ఈ తేడాలు వారి వేటికి తగిన ఉపయోగాలను సూచిస్తాయి, LLMలు విస్తృత మరియు వనరులు ఎక్కువగా అవసరమో, SLMలు నిర్దిష్ట డొమైన్లలో సమర్థవంతంగా తక్కువ వనరులతో పనిచేస్తాయి.

***గమనిక: ఈ పాఠంలో Microsoft Phi-3/3.5 ఉపయోగించి SLMను పరిచయం చేస్తాం.***

## Phi-3 / Phi-3.5 కుటుంబ పరిచయం

Phi-3 / 3.5 కుటుంబం ప్రధానంగా టెక్స్ట్, దృష్టి, మరియు ఏజెంట్ (MoE) అప్లికేషన్ సన్నివేశాలను లక్ష్యంగా పెట్టుకుంది:

### Phi-3 / 3.5 ఇన్‌స్ట్రక్ట్

ముఖ్యంగా టెక్స్ట్ ఉత్పత్తి, చాట్ పూర్తి, మరియు కంటెంట్ సమాచారం పొందడం కోసం.

**Phi-3-మిని**

3.8B పరిమాణం గల భాషా నమూనా Microsoft Foundry, Hugging Face, మరియు Ollama వద్ద అందుబాటులో ఉంది. Phi-3 నమూనాలు సమానమైన మరియు పెద్ద పరిమాణం గల భాషా నమూనాల కంటే కీలక బెంచ్‌మార్క్‌లలో మెరుగైన పనితీరును చూపిస్తున్నాయి (క్రింది బెంచ్‌మార్క్ సంఖ్యలు చూడండి, సంఖ్య ఎక్కువైతే మెరుగైనది). Phi-3-మినీ తన పరిమాణంతో పోలిస్తే రెండు రెట్లు పెద్ద నమూనాలకు మించిపోయిందట, Phi-3-స్మాల్ మరియు Phi-3-మీడియం పెద్ద నమూనాలంటే, GPT-3.5 తలకు కూడా అధిగమిస్తోంది.

**Phi-3-స్మాల్ & మీడియం**

కేవలం 7B పారామిటర్లతో, Phi-3-స్మాల్ భాషా, తర్కం, కోడింగ్, మరియు గణితం వంటి వివిధ బెంచ్‌మార్క్‌లలో GPT-3.5T ను అధిగమిస్తోంది.

14B పారామిటర్లతో Phi-3-మీడియం ఈ ధోరణిని కొనసాగిస్తూ Gemini 1.0 Pro ను మించిపోతుంది.

**Phi-3.5-మినీ**

దీనిని Phi-3-మినీ యొక్క అప్గ్రేడ్‌గా పరిగణించవచ్చు. పారామిటర్లు మారలేదిగానీ, ఇది పలు భాషలకు మెరుగైన మద్దతును ఇస్తుంది (20+ భాషలను మద్దతు ఇస్తుంది: అరబ్బీ, చైనీస్, చెక్, డానిష్, డచ్, ఇంగ్లీష్, ఫినిష్, ఫ్రెంచ్, జర్మన్, హిబ్రూ, హंगेరు, ఇటాలియన్, జాపనీస్, కొరియన్, నార్వీజియన్, పాలిష్, పోర్చుగీస్, రషియన్, స్పానిష్, స్విడిష్, థాయ్, టర్కిష్, ఉక్రెయిన్) మరియు దీర్ఘ సందర్భాలకు బలమైన మద్దతు జోడించింది.

3.8B పారామిటర్లతో Phi-3.5-మినీ అదే పరిమాణం గల భాషా నమూనాల కంటే మెరుగైనది మరియు రెండు రెట్లు పెద్ద నమూనాలతో సమానంగా ఉంటుంది.

### Phi-3 / 3.5 దృష్టి

Phi-3/3.5 ఇన్‌స్ట్రక్ట్ నమూనాను Phi యొక్క అర్థం చేసుకోవడాన్ని సూచించడం కోసం పరిగణించవచ్చు, మరియు దృష్టి అనేది Phiకి ప్రపంచాన్ని అర్థం చేసుకునే కళ్ళను ఇస్తుంది.


**Phi-3-విజన్**

4.2B పారామిటర్లతో Phi-3-విజన్ ఈ ధోరణిని కొనసాగిస్తూ, విస్తృత దృష్టి తర్కం పనులలో, OCR, పట్టిక మరియు వివర గమనికలో Claude-3 Haiku మరియు Gemini 1.0 Pro V లాంటివి మెరుగుపరుస్తుంది.


**Phi-3.5-విజన్**

Phi-3.5-విజన్ Phi-3-విజన్ యొక్క అప్గ్రేడ్ కూడా, ఇది పలు చిత్రాలకు మద్దతు ఇస్తుంది. దీన్ని మెరుగైన దృష్టిగా పరిగణించవచ్చు, కేవలం చిత్రాలను మాత్రమే కాదు, వీడియోలను కూడా చూడగలుగుతారు.

Phi-3.5-విజన్ OCR, పట్టిక మరియు చార్ట్ అర్థం చేసుకోవడంలో Claude-3.5 Sonnet మరియు Gemini 1.5 Flash వంటి పెద్ద నమూనాలను అధిగమిస్తూ ఉంది మరియు సాధారణ దృష్టి పలు చిత్ర ప్రాసెసింగ్ పనులపై సమాన పనితీరును చూపిస్తుంది. పలు ఫ్రేమ్ ఇన్‌పుట్‌లకు మద్దతు ఇస్తుంది, అంటే పలు ఇన్‌పుట్ చిత్రాలలో తర్కాన్ని చేస్తుంది.


### Phi-3.5-MoE

***ఎక్స్‌పర్ట్స్ మిశ్రమం (MoE)*** నమూనాలను తక్కువ గణనతో ముందుగా శిక్షణ పొందగలిగేలా చేస్తుంది, అంటే మీరు డెన్స్ నమూనాతో సమానమైన గణన నిధులతో నమూనా లేదా డేటాసెట్ పరిమాణాన్ని విస్తరించవచ్చు. ముఖ్యంగా, MoE నమూనా తన డెన్స్ ప్రతిపాదిత నమూనాకు తక్కువ సమయంలో తక్కువ వేగంగా పూర్వశిక్షణలో అదే నాణ్యతను అందించాలి.

Phi-3.5-MoE 16x3.8B నిపుణ మాడ్యూల్స్ కలిగి ఉంది. 6.6B కార్యకలాప పారామిటర్లతో Phi-3.5-MoE పెద్ద నమూనాల లాంటి ఆలోచన, భాషా అర్థం చేసుకోవడం, మరియు గణితంలో సమాన స్థాయిని అందుతుంది.

మీరు వేర్వేరు సన్నివేశాలలో Phi-3/3.5 కుటుంబ నమూనాను ఉపయోగించవచ్చు. LLMతో భిన్నంగా, మీరు Phi-3/3.5-మినీ లేదా Phi-3/3.5-విజన్ ను ఎడ్జ్ పరికరాల్లో అమలు చేయవచ్చు.

మేము Phi-3/3.5ని వివిధ సన్నివేశాలలో ఉపయోగించాలనే ఆశగలము. తదుపరి, వివిధ సందర్భాలలో Phi-3/3.5 ను ఉపయోగిస్తాము.

క్లౌడ్ ఆధారిత Microsoft Foundry నమూనా каталాగ్కు మించి మీరు [NVIDIA NIM](https://developer.nvidia.com/nim?WT.mc_id=academic-105485-koreyst) ఉపయోగించి కూడా సంబంధిత కాల్‌లను పూర్తి చేయవచ్చు. NVIDIA NIM (NVIDIA ఇన్ఫెరెన్స్ మైక్రోసర్వీసెస్) అనేది వివిధ వాతావరణాల్లో, క్లౌడ్‌లు, డేటా సెంటర్‌లు, వర్క్‌స్టేషన్‌లు వంటి చోట్ల AI నమూనాలను సమర్థవంతంగా విస్తరించడంలో డెవలపర్లకు సహాయపడేందుకు రూపొందించిన వేగవంతమైన ఇన్ఫెరెన్స్ మైక్రోసర్వీసెస్ సెట్.

NVIDIA NIM యొక్క కొన్ని ప్రధాన లక్షణాలు:

- **అమలు సౌలభ్యం:** NIM ఒకే ఆదేశంతో AI నమూనా అమలును సులభంగా చేస్తుంది, ఇదేదైనా పని ప్రవాహంలో సమగ్రం చేయడం సులభం.
- **ఆప్టిమైజ్డ్ పనితీరు:** ఇది NVIDIA యొక్క ముందస్తుగా ఆప్టిమైజ్ చేసిన ఇన్ఫెరెన్స్ ఇంజిన్లు, TensorRT మరియు TensorRT-LLM వంటి వాటిని వినియోగించి తక్కువ ఆలస్యం మరియు ఉన్నత త్రుట్పుట్ నిర్ధారిస్తుంది.
- **విస్తరణ సామర్థ్యం:** NIM Kubernetesపై ఆటోస్కేలింగ్‌ను మద్దతు ఇస్తుంది, ఇది విభిన్న పనిభారం సమర్థవంతంగా నిర్వహించడానికి అనుమతిస్తుంది.
- **భద్రత మరియు నియంత్రణ:** సంస్థలు తమ డేటా మరియు అప్లికేషన్‌లపై నియంత్రణను నిర్వహించడానికి NIM మైక్రోసర్వీసెస్‌ను తమ స్వంత నిర్వహించిన ఇన్‌ఫ్రాస్ట్రక్చర్ లో స్వతంత్రమైన హోస్టింగ్ చేసుకోవచ్చు.
- **స్టాండర్డ్ APIలు:** NIM పరిశ్రమ-స్టాండర్డ్ APIలను అందిస్తుంది, ఇది చాట్‌బాట్లు, AI సహాయకులు మరియు మరిన్ని వంటి AI అనువర్తనాలను సృష్టించడం మరియు సమ్మిళితం చేయడం సులభం చేస్తుంది.

NIM NVIDIA AI ఎంటర్‌ప్రైజ్ భాగమయ్యింది, ఇది AI మోడళ్లని అమలు చేయడం మరియు ఆపరేషన్లను సులభతరం చేయడానికి లక్ష్యంగా ఉంది, అవి NVIDIA GPUలపై సమర్ధవంతంగా పనిచేయాలని గూడా నిర్ధారిస్తుంది.

**Hugging Face ట్రాన్స్‌ఫార్మర్**
Hugging Face Transformers ఒక శక్తివంతమైన గ్రంథాలయం, ఇది సహజ భాష ప్రాసెసింగ్ (NLP) మరియు ఇతర మెషీన్ లెర్నింగ్ పనుల కోసం రూపొందించబడింది. కొంత ముఖ్యమైన విషయాలు:

1. **పూర్వ శిక్షణ పొందిన మోడళ్లు**: ఇది వాచిక వర్గీకరణ, పేరు గుర్తింపు, ప్రశ్నోత్తర, సారాంశీకరణ, అనువాదం, వచనం ఉత్పత్తి వంటి వివిధ పనులకు ఉపయోగపడే వేలాది పూర్వ శిక్షణ పొందిన మోడళ్లను అందిస్తుంది.

2. **ఫ్రేమ్‌వర్క్ పరస్పరిభాగ్యత**: ఈ గ్రంథాలయం PyTorch, TensorFlow, JAX వంటి అనేక డీప్ లెర్నింగ్ ఫ్రేమ్‌వర్క్‌లకు మద్దతు ఇస్తుంది. దీనివలన ఒక ఫ్రేమ్‌వర్క్‌లో శిక్షణ పొందిన మోడల్‌ను మరో ఫ్రేమ్‌వర్క్‌లో ఉపయోగించవచ్చు.

3. **బహుమాధ్యమ శక్తులు**: NLP విభాగం కంటే బయట, Hugging Face Transformers కంప్యూటర్ విజన్ (ఉదా: ఇమేజ్ వర్గీకరణ, ఆబ్జెక్ట్ డిటెక్షన్) మరియు ఆడియో ప్రాసెసింగ్ (ఉదా: మాట గుర్తింపు, ఆడియో వర్గీకరణ) పనులకు మద్దతు ఇస్తుంది.

4. **వాడుక సౌలభ్యం**: ఈ గ్రంథాలయం మోడళ్ల‌ను సులభంగా డౌన్‌లోడ్ చేసి సర్దుబాటు చేసుకోవడానికి APIలు మరియు టూల్స్ అందిస్తుంది, ఇది ప్రారంభకులు మరియు నిపుణులకు సులభంగా అందుబాటులో ఉంటుంది.

5. **కమ్యూనిటీ మరియు వనరులు**: Hugging Face వద్ద ఉత్సాహభరిత సమూహం మరియు విస్తృతమైన డాక్యుమెంటేషన్, ట్యూటోరియల్స్, మార్గదర్శకాలు ఉన్నాయని ఉపయోగకరంగా శిక్షణ తీసుకోడానికి సహాయపడతాయి.

**Ollama**

**Foundry Local**

[Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) మైక్రోసాఫ్ట్ ఆఫ్‌లైన్, మీ స్వంత హార్డ్‌వేర్‌లో Phi వంటి మోడళ్లను నడపడానికి ఆన్-డివైస్ రన్‌టైమ్ - Azure సబ్‌స్క్రిప్షన్, API కీ లేదా నెట్‌వర్క్ కనెక్షన్ అవసరం లేదు. ఇది అందుబాటులో ఉన్న ఉత్తమ ఎగ్జిక్యూషన్ ప్రొవೈడర్ (NPU, GPU, CPU)ను ఆటోమేటిక్‌గా ఎంచుకుంటుంది మరియు OpenAI-సంకలిత ఎండ్పాయింట్‌ని అందిస్తుంది, కాబట్టి ఉన్న `openai`/Azure AI Inference SDK కోడ్‌ను తక్కువ మార్పులతో ఉపయోగించవచ్చు. ప్రారంభం కావడానికి [Foundry Local డాక్యుమెంటేషన్](https://learn.microsoft.com/azure/ai-foundry/foundry-local/get-started?WT.mc_id=academic-105485-koreyst) చూడండి.

**ONNX Runtime for GenAI**

[ONNX Runtime](https://github.com/microsoft/onnxruntime-genai?WT.mc_id=academic-105485-koreyst) అనేది క్రాస్-ప్లాట్‌ఫామ్ ఇన్ఫరెన్స్ మరియు శిక్షణ మెషీన్‌లెర్నింగ్ యాక్సిలరేటర్. ONNX Runtime for Generative AI (GENAI) అనేది వివిధ ప్లాట్‌ఫామ్స్‌లో జనరేటివ్ AI మోడళ్లను సమర్ధవంతంగా నడపడానికి సహాయపడే శక్తివంతమైన సాధనం.

## ONNX Runtime అంటే ఏమిటి?
ONNX Runtime అనేది ఓపెన్ సోర్స్ ప్రాజెక్ట్, ఇది మెషీన్ లెర్నింగ్ మోడళ్ల యొక్క హై-పర్ఫార్మెన్స్ ఇన్ఫరెన్స్‌ను సులభతరం చేస్తుంది. ఇది Open Neural Network Exchange (ONNX) ఫార్మాట్‌లో ఉన్న మోడళ్లకు మద్దతు ఇస్తుంది, ఇది మెషీన్ లెర్నింగ్ మోడళ్లను ప్రతినిధి చేసే స్టాండర్డ్. ONNX Runtime ఇన్ఫరెన్స్ వేగవంతమైన కస్టమర్ అనుభవాలను మరియు తక్కువ ఖర్చులను సాధ్యం చేస్తుంది, ఇది PyTorch, TensorFlow/Keras వంటి డీప్ లెర్నింగ్ ఫ్రేమ్‌వర్క్‌ల మోడళ్లతో పాటు scikit-learn, LightGBM, XGBoost వంటి క్లాసికల్ మెషీన్ లెర్నింగ్ లైబ్రరీలను సైతం మద్దతు ఇస్తుంది. ONNX Runtime వివిధ హార్డ్వేర్, డ్రైవర్స్, ఆపరేటింగ్ సిస్టమ్స్‌కు అనుకూలంగా ఉంటుంది, అలాగే హార్డ్వేర్ యాక్సిలరేటర్లను సమర్థవంతంగా ఉపయోగించి, గ్రాఫ్ ఆప్టిమైజేషన్స్ మరియు ట్రాన్స్‌ఫార్మ్స్ ద్వారా ఉత్తమ పనితీరును అందిస్తుంది.

## Generative AI అంటే ఏమిటి?
Generative AI అంటే శిక్షణ పొందిన డేటా ఆధారంగా కొత్త కంటెంట్, వచనం, చిత్రాలు లేదా సంగీతం వంటి అంశాలను సృష్టించగల AI వ్యవస్థలు. ఉదాహరణకు GPT-3 వంటి భాషా మోడళ్లు మరియు Stable Diffusion వంటి చిత్రం ఉత్పత్తి మోడళ్లు. ONNX Runtime for GenAI లైబ్రరీ ONNX మోడళ్ల కోసం జనరేటివ్ AI లూప్‌ను, ఇన్ఫరెన్స్, లోగిట్స్ ప్రాసెసింగ్, సెర్చ్ మరియు శాంప్లింగ్, KV క్యాచీ నిర్వహణ వంటి ఫీచర్లతో అందిస్తుంది.

## ONNX Runtime for GENAI
ONNX Runtime for GENAI ONNX Runtime సామర్థ్యాలను విస్తరించి జనరేటివ్ AI మోడళ్లను మద్దతు ఇస్తుంది. కొన్ని ముఖ్యమైన లక్షణాలు:

- **విస్తృత ప్లాట్‌ఫాం మద్దతు:** ఇది Windows, Linux, macOS, Android, iOS వంటి వివిధ ప్లాట్‌ఫామ్‌లపై పనిచేస్తుంది.
- **మోడల్ మద్దతు:** LLaMA, GPT-Neo, BLOOM మరియు మరిన్ని ప్రాచుర్యం పొందిన జనరేటివ్ AI మోడళ్లకు మద్దతు ఇస్తుంది.
- **పర్ఫార్మెన్స్ ఆప్టిమైజేషన్:** NVIDIA GPUలు, AMD GPUలు మరియు మరిన్ని వంటి వివిధ హార్డ్వేర్ యాక్సిలరేటర్లకు ఆప్టిమైజేషన్లు కలిగి ఉంది.
- **వాడుక సౌలభ్యం:** అప్లికేషన్లలో సులభంగా సమ్మిళితం చేయడానికి APIలను అందిస్తుంది, మీకు తక్కువ కోడ్‌తో వచనం, చిత్రాలు మరియు ఇతర కంటెంట్‌ను ఉత్పత్తి చేయడానికి వీలు ఇస్తుంది.
- వినియోగదారులు ఉన్నత స్థాయి generate() పద్ధతిని పిలవవచ్చు, లేదా ప్రతి పునరావృతంలో ఒక టోకెన్‌ను ఒకటిగా ఉత్పత్తి చేయగలిగే మోడల్‌ను లూప్‌లో నడపవచ్చు, మరియు కావలసిన పద్ధతిలో జనరేషన్ పరామితులని నవీకరించవచ్చు.
- ONNX runtime గ్రీడీ/బీం సెర్చి, TopP, TopK శాంప్లింగ్‌ను టోకెన్ శ్రేణుల ఉత్పత్తికి మద్దతు ఇస్తుంది మరియు లోగిట్స్ ప్రాసెసింగ్ (ఉదా: పునరావృత దండన)లను కూడా కలిగి ఉంటుంది. మీకు కావలసినట్లుగా అనుకూల స్కోరింగ్ కూడా సులభంగా జోడించవచ్చు.

## ప్రారంభించడం
ONNX Runtime for GENAIతో ప్రారంభించడానికి, మీరు ఈ చర్యలను అనుసరించవచ్చు:

### ONNX Runtime ఇన్‌స్టాల్ చేయండి:
```Python
pip install onnxruntime
```
### Generative AI Extensions ఇన్‌స్టాల్ చేయండి:
```Python
pip install onnxruntime-genai
```

### మోడల్ నడపండి: ఇది Pythonలో ఒక సాధారణ ఉదాహరణ:
```Python
import onnxruntime_genai as og

model = og.Model('path_to_your_model.onnx')

tokenizer = og.Tokenizer(model)

input_text = "Hello, how are you?"

input_tokens = tokenizer.encode(input_text)

output_tokens = model.generate(input_tokens)

output_text = tokenizer.decode(output_tokens)

print(output_text) 
```
### డెమో: ONNX Runtime GenAI ఉపయోగించి Phi-3.5-Vision కాల్ చేయడం


```python

import onnxruntime_genai as og

model_path = './Your Phi-3.5-vision-instruct ONNX Path'

img_path = './Your Image Path'

model = og.Model(model_path)

processor = model.create_multimodal_processor()

tokenizer_stream = processor.create_stream()

text = "Your Prompt"

prompt = "<|user|>\n"

prompt += "<|image_1|>\n"

prompt += f"{text}<|end|>\n"

prompt += "<|assistant|>\n"

image = og.Images.open(img_path)

inputs = processor(prompt, images=image)

params = og.GeneratorParams(model)

params.set_inputs(inputs)

params.set_search_options(max_length=3072)

generator = og.Generator(model, params)

while not generator.is_done():

    generator.compute_logits()
    
    generator.generate_next_token()

    new_token = generator.get_next_tokens()[0]
    
    output = tokenizer_stream.decode(new_token)
    
    print(tokenizer_stream.decode(new_token), end='', flush=True)

```
