# Генеративни АИ за Почетнике (Верзија 3) - Курс

Научите основе изградње апликација Генеративног АИ кроз наш свеобухватни курс од 21 лекције, у организацији Microsoft Cloud Advocates.

## 🌱 Почетак рада

Овај курс има 21 лекцију. Свака лекција покрива посебну тему, тако да можете почети где год желите!

Лекције су означене као „Научи“ лекције које објашњавају концепт Генеративног АИ или „Направи“ лекције које објашњавају концепт и дају примере кода у оба језика **Python** и **TypeScript**, када је то могуће.

За .NET програмере, погледајте [Генеративни АИ за Почетнике (.NET издање)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Свака лекција такође укључује одељак „Настави да учиш“ са додатним алатима за учење.

## Шта вам треба
### За покретање кода из овог курса, можете користити било шта од: 
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Лекције:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Лекције:** "githubmodels" (GitHub Models се повлачи крајем јула 2026 – користите уместо тога Microsoft Foundry Models)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Лекције:** "oai-assignment" 
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Покрените моделе потпуно офлајн на свом уређају, није потребна претплата на облак
   
- Основно знање Python или TypeScript је корисно - \*За апсолутне почетнике погледајте ове курсеве [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) и [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst)
- GitHub налог да бисте [форковали цео репозиторијум](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) на ваш лични GitHub налог

Креирали смо лекцију **[Постављање курса](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** која ће вам помоћи да подесите своје развојно окружење.

Не заборавите да [означите звездицом (🌟) овај репо](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) да бисте га касније лакше пронашли.
