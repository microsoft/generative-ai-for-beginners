# هوش مصنوعی مولد برای مبتدیان (نسخه ۳) — یک دوره آموزشی جامع

اصول و مهارت‌های ساخت برنامه‌های مدرن هوش مصنوعی مولد را با دوره ۲۱ جلسه‌ای و پروژه‌محور مهندسان ابری مایکروسافت (Microsoft Cloud Advocates) بیاموزید.

## 🌱 شروع یادگیری

این دوره شامل ۲۱ درسنامه تخصصی به همراه یک جلسه راه‌اندازی است. هر جلسه موضوع مستقل و منسجمی را پوشش می‌دهد، بنابراین می‌توانید یادگیری را از هر نقطه‌ای که نیاز دارید آغاز کنید!

دروس این دوره به دو شاخه کلی تقسیم شده‌اند:
- **شاخه «یادگیری» (Learn):** مفاهیم نظری، سازوکار مدل‌ها و اصول بنیادین هوش مصنوعی مولد را تشریح می‌کند.
- **شاخه «ساخت» (Build):** پیاده‌سازی عملی و نمونه‌کدهای واقعی را در دو زبان **Python** و **TypeScript** ارائه می‌دهد.

> برای توسعه‌دهندگان اکوسیستم دات‌نت، دوره تخصصی [هوش مصنوعی مولد برای مبتدیان (نسخه .NET)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst) نیز در دسترس است!

در پایان هر جلسه نیز بخشی تحت عنوان «ادامه یادگیری» قرار دارد که مراجع تکمیلی و ابزارهای مرتبط را برای تعمیق دانش در اختیارتان می‌گذارد.

## 🛠️ نیازمندی‌ها و پیش‌نیازها

### برای اجرای کدهای این دوره، می‌توانید از یکی از بسترهای زیر استفاده نمایید:
- [سرویس Azure OpenAI](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) — پروژه‌های پوشه `aoai-assignment`
- [کاتالوگ مدل‌های Microsoft Foundry](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) — پروژه‌های پوشه `githubmodels` (مدل‌های GitHub در حال انتقال به Microsoft Foundry هستند)
- [رابط برنامه‌نویسی OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) — پروژه‌های پوشه `oai-assignment`
- [محیط Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) — اجرای کاملاً آفلاین و محلی مدل‌ها روی سیستم شخصی بدون نیاز به اشتراک ابری

### دانش و ابزارهای مورد نیاز:
- آشنایی پایه با زبان Python یا TypeScript مفید است — اگر در ابتدای راه برنامه‌نویسی هستید، دوره‌های رایگان مایکروسافت برای [آموزش Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) و [آموزش TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) را بررسی فرمایید.
- یک حساب کاربری در گیت‌هاب برای [فورک کردن این مخزن](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) به حساب شخصی‌تان.
- پیشنهاد می‌کنیم ابتدا درسنامه **[راه‌اندازی دوره](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** را مطالعه فرمایید تا محیط توسعه شما (VS Code یا Codespaces) آماده شود.
- فراموش نکنید این مخزن را [ستاره (🌟) دهید](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) تا همواره در دسترس شما باشد.
