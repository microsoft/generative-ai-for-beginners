# തുടക്കക്കാർക്കായി ജനറേറ്റീവ് എഐയ്ക്ക് വേണ്ടി ചെറുകിട ഭാഷാ മോഡലുകളിൽ പരിചയം
ജനറേറ്റീവ് എഐ പുതിയ ഉള്ളടക്കം സൃഷ്ടിക്കാൻ കഴിയുന്ന സംവിധാനങ്ങൾ സൃഷ്ടിക്കുന്നതിൽ ശ്രദ്ധ കേന്ദ്രീകരിക്കുന്ന കൃത്രിമ ബുദ്ധിമുട്ടിന്റെ ഒരു രസകരമായ മേഖലയാണ്. ഈ ഉള്ളടക്കം വാക്കുകളും ചിത്രങ്ങളും സംഗീതവും甚至 മുഴുവൻ വെർച്വൽ പരിസരങ്ങളും ഉൾക്കൊള്ളാം. ജനറേറ്റീവ് എഐയുടെ ഏറ്റവും രസകരമായ ഉപയോഗങ്ങളിൽ ഒന്ന് ഭാഷാ മോഡലുകളുടെ മേഖലയിലൂടെയാണ്.

## ചെറുകിട ഭാഷാ മോഡലുകൾ എന്താണ്?

ചെറുകിട ഭാഷാ മോഡൽ (SLM) ഒരു വലിയ ഭാഷാ മോഡൽ (LLM) ൽ നിന്നുള്ള സ്ട്രക്ചറൽ സിദ്ധാന്തങ്ങളും സാങ്കേതിക വിദ്യകളും ഉപയോഗിച്ച് കുറഞ്ഞ കംപ്യൂട്ടേഷണൽ കാലിക സ്വഭാവം കാണിക്കുന്ന ഒരു ചെറിയ പതിപ്പാണ്.

SLMകൾ മനുഷ്യന്റെ സ്വഭാവം ഉൾക്കൊള്ളുന്ന വാചകങ്ങൾ സൃഷ്ടിക്കാൻ രൂപകല്പന ചെയ്ത ഒരു ഭാഷാ മോഡൽ വിഭാഗമാണ്. GPT-4 പോലുള്ള അവരുടെ വലിയ പതിപ്പുകളെ അപേക്ഷിച്ച്, SLMകൾ കൂടുതൽ കമ്പാക്റ്റും കാര്യക്ഷമവുമാണ്, കമ്പ്യൂട്ടേഷൻ സാധനസാധ്യതകൾ പരിമിതമായ പ്രയോഗങ്ങൾക്ക് അനുയോജ്യം ആക്കുന്നു. ചെറിയ വലുപ്പമുള്ളതായിട്ടും, അവ വിവിധ പ്രവൃത്തി മേഖലകൾ നിർവഹിക്കാം. സാധാരണയായി, SLMകൾ LLMകളെ സംയോജിപ്പിച്ചോ സംക്ഷിപ്തമാക്കിയോ നിർമ്മിച്ച് രൂപപ്പെടുത്താറുണ്ട്, അതിലൂടെ ഒറിജിനൽ മോഡലിന്റെ പ്രവർത്തനങ്ങളും ഭാഷാശക്തിയും വലിയ തോതിൽ നിലനിർത്തുക ലക്ഷ്യമാക്കുന്നു. മോഡൽ വലിപ്പം കുറയ്ക്കുന്നതിലൂടെ ആകെ സങ്കീർണ്ണത കുറക്കപ്പെടുന്നു, ഇത് അവയെ മെമറി ഉപയോഗത്തിലും കംപ്യൂട്ടേഷണൽ ആവശ്യങ്ങളിലും കൂടുതൽ കാര്യക്ഷമമായി മാറ്റുന്നു. ഈ ഒപ്റ്റിമൈസേഷനുകൾ ആയാലും, SLMകൾ താഴെപ്പറയുന്ന നാചുറൽ ലാംഗ്വേജ് പ്രോസസ്സിംഗ് (NLP) പ്രവർത്തനങ്ങൾ നിറവേറ്റാൻ കഴിയും:

- വാചക സൃഷ്ടി: ആത്മസമർത്ഥവും കാര്യാർത്ഥപരവുമായ വാചകങ്ങൾ അല്ലെങ്കിൽ പരാഗ്രാഫുകൾ സൃഷ്ടിക്കൽ.
- വാചക പൂർത്തീകരണം: നൽകിയ പ്രോംപ്റ്റിന്റെ അടിസ്ഥാനത്തിൽ വാചകങ്ങൾ പ്രവചിച്ച് പൂർത്തിയാക്കൽ.
- വിവർത്തനം: ഒരു ഭാഷയിൽ നിന്ന് മറ്റൊരഭാഷയിലേക്ക് വാചകങ്ങൾ മാറ്റി പകരൽ.
- സംക്ഷേപണം: വലിയ വാചകങ്ങൾ ചുരുക്കി സ്വാഭാവികമായും ബോധഗംഭീരം കൂടിയുള്ള സംക്ഷേപങ്ങൾ നിർമ്മിക്കൽ.

പെർഫോർമൻസിലോ അല്ലെങ്കിൽ ആഴത്തിലുള്ള അർത്ഥമാക്കലിലോ ചില വ്യവസ്ഥയുണ്ട്.

## ചെറുകിട ഭാഷാ മോഡലുകൾ എങ്ങനെ പ്രവർത്തിക്കുന്നു?
SLMകൾ വൻവ്യാപകമായ വാചക ഡാറ്റയിൽ പരിശീലനമെടുക്കുന്നു. പരിശീലനകാലത്ത്, അവർ ഭാഷയുടെ മാതൃകകളും ഘടനകളും പഠിക്കുന്നു, ഇതിലൂടെ വ്യാകരണപരവും പ്രാസക്തമായ വിഷയത്തിൽ യോജിച്ചും ഉള്ള വാചകങ്ങൾ സൃഷ്ടിക്കാൻ കഴിയും. പരിശീലനപ്രക്രിയയിൽ ഉൾപ്പെടുന്നു:

- ഡാറ്റ ശേഖരണം: വിവിധ ഉറവിടങ്ങളിൽ നിന്ന് വലിയ വാചക ഡാറ്റാസെറ്റുകൾ ശേഖരിക്കൽ.
- പ്രീപ്രോസസ്സിംഗ്: ഡാറ്റ മുന്നൊരുക്കി പരിശീലനത്തിന് അനുയോജ്യമാക്കൽ.
- പരിശീലനം: മെഷീൻ ലേണിംഗ് ആൾഗോരിതങ്ങൾ ഉപയോഗിച്ച് മോഡലിനെ വാചകങ്ങൾ മനസ്സിലാക്കി സൃഷ്ടിക്കാൻ പഠിപ്പിക്കൽ.
- ഫൈൻ-ട്യൂണിംഗ്: പ്രത്യേക പ്രവൃത്തികളുടെ പ്രകടനം മെച്ചപ്പെടുത്താൻ മോഡൽ ക്രമീകരിക്കൽ.

SLMകൾ മൊബൈൽ ഉപകരണങ്ങൾ അല്ലെങ്കിൽ എഡ്ജ് കംപ്യൂട്ടിംഗ് പ്ലാറ്റ്ഫോമുകൾ പോലുള്ള സ്രോതസ്സു പരിധിയുള്ള പരിസരങ്ങളിൽ വിനിയോഗിക്കാൻ ആവശ്യമായ പ്രകടനം പാലിക്കാനായി വികസിപ്പിച്ചെടുത്തതാണ്. കാര്യക്ഷമതയിൽ ഉന്മുഖമായി, SLMകൾ പ്രകടനവും ആക്സസിബിലിറ്റിയും പൊരുത്തപ്പെടുത്തി വിവിധ മേഖലകളിലാണ് വ്യാപകമായ പ്രയോഗങ്ങൾ സാധ്യമാക്കുന്നത്.

## പഠനലക്ഷ്യങ്ങൾ

പാഠം അവസാനിക്കുന്നത് വരെ, താഴെ പറയുന്ന ചോദ്യങ്ങൾക്ക് ഉത്തരം നൽകാൻ കഴിഞ്ഞിരിക്കണം:

## വലിയ ഭാഷാ മോഡലുകളും ചെറുകിട ഭാഷാ മോഡലുകളും തമ്മിലുള്ള വ്യത്യാസങ്ങൾ

LLMകളും SLMകളും പ്രൊബബിലിസ്റ്റിക് മെഷീൻ ലേണിംഗ് അടിസ്ഥാനപരമായ സിദ്ധാന്തങ്ങൾ പിന്തുടരുന്നു, ആർക്കിടെക്ചറൽ ഡിസൈനിലും പരിശീലന രീതികളിലും ഡാറ്റ ഉൽപ്പാദനപ്രക്രിയകളിലും മോഡൽ വിലയിരുത്തലിലും സമാന സമീപനങ്ങൾ സ്വീകരിക്കുന്നു. എങ്കിലും, ചില പ്രധാന ഘടകങ്ങൾ ഈ രണ്ടു മോഡലുകളെ വേർതിരിക്കുന്നു.

## ചെറുകിട ഭാഷാ മോഡലുകളുടെ പ്രയോഗങ്ങൾ

SLMകളുടെ വ്യാപകമായ പ്രയോഗങ്ങൾ ഉൾപ്പെടുന്നു:

- ചാറ്റ്‌ബോട്ടുകൾ: ഉപഭോക്തൃ പിന്തുണയും സംഭാഷണ രീതിയിലുള്ള സംവാദവും നൽകുക.
- ഉള്ളടക്കം സൃഷ്ടി: സമ്പ്രേഷകരെ ആശയങ്ങളോ ലേഖനഡ്രാഫ്റ്റുകളോ സൃഷ്ടിക്കുവാൻ സഹായിക്കുക.
- വിദ്യാഭ്യാസം: എഴുതൽ അസൈൻമെന്റുകളിലും പുതിയ ഭാഷകൾ പഠിക്കലിലും വിദ്യാർത്ഥികളെ സഹായിക്കൽ.
- ആക്സസിബിലിറ്റി: വാക്‌സമ്മത സംവിധാനങ്ങൾ പോലുള്ള ഹാനികരത്തിലുള്ള വ്യക്തികൾക്കായുള്ള ഉപകരണങ്ങൾ സൃഷ്ടിക്കൽ.

**വലുപ്പം**
  
LLMകളും SLMകളും തമ്മിലുള്ള പ്രധാന വ്യത്യാസം മോഡലിന്റെ അളവിലാണ്. ChatGPT (GPT-4) പോലുള്ള LLMകൾ ഏകദേശം 1.76 ട്രില്യൺ പരിഷ്കരണങ്ങൾ ഉൾക്കൊള്ളാം, എന്നാൽ Mistral 7B പോലുള്ള വൃത്തിയുള്ള സ്രോതസ്സ് SLMകൾ ഏകദേശം 7 ബില്ല്യൺ പരിഷ്കരണങ്ങളോടെയാണ് രൂപകൽപ്പന ചെയ്തിരിക്കുന്നത്. ഈ വ്യത്യാസം മോഡൽ സങ്കേതത്തിലും പരിശീലന പ്രക്രിയകളിലും വരുത്തുന്ന വ്യത്യാസങ്ങളാൽ ആണ്. ഉദാഹരണത്തിന്, ChatGPT എൻകോഡർ-ഡികോഡർ ഘടനയിൽ സെൽഫ്-അറ്റൻഷൻ മൊക്കാനിസം ഉപയോഗിക്കുന്നതിനിടെ, Mistral 7B സ്ലൈഡിംഗ് വിൻഡോ അറ്റൻഷൻ ഉപയോഗിക്കുന്നു, ഇത് ഡികോഡർ-ോർണി മോഡലിൽ കൂടുതൽ കാര്യക്ഷമമായ പരിശീലനം അനുവദിക്കുന്നു. ഈ സംവിധാന വ്യത്യാസം മോഡലുകളുടെ സങ്കീർണതയിലും പ്രകടനത്തിലും വലിയ ഫലങ്ങൾ ഉണ്ട്.

**അർത്ഥമാക്കൽ**

SLMകൾ സാധാരണയായി പ്രത്യേക ഡൊമെയിനുകളിൽ മികച്ച പ്രകടനം കാഴ്ചവയ്ക്കാൻ ഒതുക്കപ്പെട്ടവയാണ്, അതിനാൽ അവർ വ്യാപകമായ പല മേഖലകളിലുമുള്ള വിശാലമായ സാങ്കേതിക സബോധം നൽകുന്നതിൽ പരിമിതിശേഷിയുള്ളവയാകാം. മറിച്ച്, LLMകൾ മനുഷ്യസ്വഭാവമുള്ള ബുദ്ധി അനുകരിക്കാൻ ലക്ഷ്യമിട്ടതാണ്. വലിയ, വ്യത്യസ്ത ഡാറ്റാസെറ്റുകൾ ഉപയോഗിച്ച് പരിശീലനം നടന്ന LLMകൾ വിവിധ മേഖലകളിൽ മികച്ച പ്രകടനം കാഴ്ചവച്ചുകൊണ്ട് കൂടുതൽ വൈവിധ്യവും സുഗമതയും നൽകുന്നു. അതായത്, LLMകൾ പ്രകൃതിദത്ത ഭാഷാ പ്രൊസസ്സിംഗ്, പ്രോഗ്രാമിംഗ് തുടങ്ങിയ വിവിധ താഴ്ന്ന ഇടപാടുകളിൽ കൂടുതൽ അനുയോജ്യമാണ്.

**കമ്പ്യൂട്ടിങ്**

LLMകളുടെ പരിശീലനവും വിനിയോഗവും സ്രോതസ്സു ഭാരം കൂടിയ പ്രക്രിയകൾ ആണ്, സാധാരണയായി വലിയ GPU ക്ലസ്റ്ററുമായി സജ്ജമാകണം. ഉദാഹരണത്തിന്, ChatGPT പോലുള്ള മോഡൽ ആദ്യമായി തുടങ്ങുവാൻ ആയിരക്കണക്കിന് GPUകൾ നീണ്ടകാലം വേണം. മറിച്ച്, SLMകൾ കുറച്ചുപേരടികൾ എണ്ണമുള്ളതിനാൽ കംപ്യൂട്ടേഷൻ സ്രോതസ്സിൽ കൂടുതൽ പ്രാപ്യമാകും. Mistral 7B പോലുള്ള മോഡലുകൾ ഇടത്തരം GPU കഴിവുള്ള ലോക്കൽ മെഷീനുകളിൽ പരിശീലനവും പ്രവർത്തനവും സാധിക്കും, എങ്കിലും പരിശീലനം പല GPUകളിൽ ചുരുങ്ങാതെ പല മണിക്കൂറുകൾക്കായി നടക്കും.

**പക്ഷപാതം**

LLMകളിൽ പ്രധാനമായുള്ള പ്രശ്‌നം ഒരു പക്ഷപാതമാണ്, ഇത് പരിശീലന ഡാറ്റയുടെ സ്വഭാവത്തിൽ നിന്നാണ്. ഈ മോഡലുകൾ സാധാരണ ഇന്റർനെറ്റിൽ നിന്നുള്ള അസംസ്കൃത, ഓഫൺ ഡാറ്റ ഉപയോഗിക്കുന്നു, ഇത് ചില സംഘംകളെ കുറച്ച് പ്രതിനിധീകരിക്കാമോ അല്ലെങ്കിൽ തെറ്റായി പ്രതിനിധീകരിക്കാമോ, തെറ്റായ ലേബലുകൾ ഉൾപ്പെടുത്താമോ, ഭിന്നഭാഷാഭേദങ്ങൾ, ഭൂമിശാസ്ത്ര വ്യത്യാസങ്ങൾ, വ്യാകരണസൂത്രങ്ങൾ മൂലമുള്ള ഭാഷാപ്രവൃത്തി ബാധിക്കാം. കൂടാതെ, LLM ആർക്കിടെക്ചർ സങ്കീർണ്ണത വിധേയമായി പാർപ്പിത്വം പ്രവര്ത്തിച്ചേക്കാം, ഇത് സൂക്ഷ്മമായി ഫൈൻ ട്യൂണിംഗ് ചെയ്യാതെ ശ്രദ്ധയിൽപ്പെടാതെ പോകാം. മറ flip-യ്ക്ക് മോശം ഡാറ്റാ സ്രോതസ്സ് ഉപയോഗിക്കുന്ന SLMകൾ കുറച്ച് മുൻകൂർ നിയന്ത്രണമുള്ള, ഡൊമെയ്ൻ-നിർദ്ദിഷ്ട ഡാറ്റാസെറ്റുകളിൽ പരിശീലനം നേടിയതിനാൽ ഇത്തരം പാഴ്‌യം കുറവാണെങ്കിലും അവ അതിൽ നിന്നും പൂര്‍ണമായും ഒഴിവാകാറില്ല.

**ഇൻഫറൻസ്**

SLMകളുടെ ചെറിയ വലുപ്പം അവയെ ഇൻഫറൻസ് വേഗത്തിൽ ഒരു വലിയ മുൻ‌ഗണന നൽകുന്നു, ഇത് ലോക്കൽ ഹാർഡ്‌വെയറുകളിൽ ഫലങ്ങൾ കാര്യക്ഷമമായി സൃഷ്ടിക്കാൻ സാധിക്കും, പ്രത്യക്കparallel പ്രോസസ്സിംഗ് ആവശ്യപ്പെടാതെ. മറ flip-യ്ക്ക്, വലിയ വലുപ്പവും സങ്കീർണതയും മൂലം, LLMകൾ സാധാരണ സ്ഥിരതയും കനത്ത parallel കംപ്യൂട്ടേഷണൽ സ്രോതസ്സും ആവശ്യമാകും ചേരുന്ന ഇൻഫറൻസ് സമയം നേടാൻ. ഏകകാലം ഉപയോഗിക്കുന്ന പല ഉപയോക്താക്കളും LLMയുടെ പ്രതികരണമ Plantation ബ്ലോക്ക് ചെയ്യും, പ്രത്യേകിച്ച് വലിയ തോത്തിൽ വിനിയോഗിക്കുമ്പോൾ.

സംഗ്രഹത്തിൽ, LLMകളും SLMകളും മെഷീൻ ലേണിങ്ങിന്റെ അടിസ്ഥാനത്തിൽ ഇരുപാതികളായിരുന്നാലും, മോഡൽ വലിപ്പം, സ്രോതസ്സു ആവശ്യങ്ങൾ, കോൺടെക്സ്റ്റുവൽ ബോധം, പക്ഷപാതത്തോട് പ്രതികരണം, ഇൻഫറൻസ് വേഗം എന്നിവയിൽ വലിയ വ്യത്യാസമാണ് കാണിക്കുന്നത്. ഈ വ്യത്യാസങ്ങൾ അവരുടെ വ്യത്യസ്ത ഉപയോഗ ആവശ്യകതകൾക്കനുസരിച്ച് ഇവയെ അനുയോജ്യവുമാക്കുന്നു, LLMകൾ കൂടുതൽ വ്യത്യസ്തതയിലും സ്രോതസ്സു ഭാരവുമായി, SLMകൾ കുറവായ കംപ്യൂട്ടേഷണൽ ആവശ്യങ്ങളോടെ ഡൊമെയിൻ-കാര്യക്ഷമത നൽകുന്നു.

***ഗమనസൂചകം: ഈ പാഠത്തിൽ, മൈക്രോസോഫ്റ്റ് ഫൈ-3 / 3.5 മാതൃക ഉപയോഗിച്ചു SLM പരിചയപ്പെടിക്കും.***

## ഫൈ-3 / ഫൈ-3.5 കുടുംബം പരിചയപ്പെടുത്തല്‍

ഫൈ-3 / 3.5 കുടുംബം പ്രധാനമായും വാചക, ദൃശ്യ, ഏജന്റ് (MoE) പ്രയോഗ സാഹചര്യങ്ങൾ ലക്ഷ്യമിടുന്നു:

### ഫൈ-3 / 3.5 ഇൻസ്ട്രക്ട്

പ്രധാനമായും വാചക സൃഷ്ടി, ചാറ്റ് പൂർത്തീകരണം, ഉള്ളടക്ക വിവര തുണക്കം മുതലായവയ്ക്ക് വേണ്ടി.

**ഫൈ-3-മിനി**

3.8B ഭാഷാ മോഡൽ മൈക്രോസോഫ്റ്റ് ഫൗണ്ട്രി, ഹഗ്ഗിങ് ഫേസ്, ഒല്ലാമയിൽ ലഭ്യമാണ്. ഫൈ-3 ഡാറ്റാബേസിലെ സമാനതയുള്ള അല്ലെങ്കിൽ വലിയ വലുപ്പമുളള ഭാഷാ മോഡലുകളുമായി താരതമ്യപ്പെടുത്തുമ്പോൾ മികച്ച പ്രകടനം കാഴ്ചവയ്ക്കുന്നു (താഴെ ബഞ്ച്മാർക്ക് സംഖ്യകൾ കാണുക, ഉയർന്ന സംഖ്യകൾ മികച്ചതാണ്). ഫൈ-3-മിനി അതിന്റെ വലുപ്പത്തോടുകൂടെ ഇരട്ടിയുള്ള മോഡലുകളിൽ പോലും മികച്ച പ്രകടനം കാഴ്ചവയ്ക്കുന്നു, ഫൈ-3-സ്മാൾ, ഫൈ-3-മീഡിയം എന്നിവയും GPT-3.5 അടക്കമുള്ള വലിയ മോഡലുകൾ മിനുകുന്നു.

**ഫൈ-3-സ്മാൾ & മീഡിയം**

7B പരിഷ്കരണങ്ങളോടുള്ള ഫൈ-3-സ്മാൾ വിവിധ ഭാഷ, വിവേകക്ഷമത, പ്രോഗ്രാമിംഗ്, ഗണിത ബഞ്ച്മാർക്കുകളിൽ GPT-3.5T നെ മുടെ കൊട്ടു.

14B പരിഷ്കരണങ്ങളുള്ള ഫൈ-3-മീഡിയം ഈ പ്രവണത തുടരുകയും ജെമിനി 1.0 പ്രോ മോഡലിനെ മുകളിൽ മറികടക്കുകയും ചെയ്യുന്നു.

**ഫൈ-3.5-മിനി**

അത് ഫൈ-3-മിനിയുടെ അപ്ഗ്രേഡായി കരുതാം. പരിഷ്കരണ സംഖ്യ യൂിട്ട നിലനിൽക്കും, എന്നാൽ അത് 20+ ഭാഷകളെ (അറബിക്, ചൈനീസ്, ചെക്ക്, ഡാനിഷ്, ഡച്ച്, ഇംഗ്ലീഷ്, ഫിന്നിഷ്, ഫ്രഞ്ച്, ജർമൻ, നേഫ്യൂ, ഹംഗേറിയൻ, ഇറ്റാലിയൻ, ജാപ്പനീസ്, കൊറിയൻ, നോർവീജിയൻ, പോളിഷ്, പൊർച്ചുഗീസ്, റഷ്യൻ, സ്‌പാനിഷ്, സ്വീഡിഷ്, തായ്, തുര്‍ക്കിഷ്, ഉക്രെയ്നിയൻ) പിന്തുണയ്ക്കാനും ദീർഘകാല കോൺടെക്സ്റ്റിനെക്കുറിച്ചുള്ള ശക്തമായ പിന്തുണ ചേർക്കാനും വിലയിരുത്തപ്പെടുന്നു.

3.8B പരിഷ്കരണങ്ങളോടെ ഫൈ-3.5-മിനി സമാന വലുപ്പത്തിലുള്ള ഭാഷാ മോഡലുകളെ മറികടക്കുകയും ഇരട്ടിയുള്ള മോഡലുകളോട് സാദൃശ്യമുള്ള പ്രകടനം കാഴ്ചവയ്ക്കുകയും ചെയ്യുന്നു.

### ഫൈ-3 / 3.5 ദൃശ്യങ്ങൾ

ഫൈ-3/3.5 ഇൻസ്ട്രക്ട് മോഡൽ ഫൈയുടെ മനസ്സിലാക്കലാണ്; ദൃശ്യങ്ങൾ ഫൈയ്ക്ക് ലോകത്തെ തിരിച്ചറിയാനുള്ള കണ്ണുകളാണ്.


**ഫൈ-3-ਦൃശ്യ**

4.2B പരിഷ്കരണങ്ങളോടെ ഫൈ-3-ਦൃശ്യ സാധാരണ ദൃശ്യ വിവേക പരീക്ഷണങ്ങളിൽ ക്ലോഡ്-3 ഹൈവിക്, ജെമിനി 1.0 പ്രോ വിപുലമായ മോഡലുകളെ മറികടക്കുന്നു, OCR, പട്ടിക, രേഖാചിത്ര ബോധപൂർവ്വം മുതലായ പരീക്ഷണങ്ങളിൽ.


**ഫൈ-3.5-ਦൃശ്യ**

ഫൈ-3.5-ਦൃശ്യയും ഫൈ-3-ਦൃശ്യത്തിന്റെ അപ്ഗ്രേഡാണ്, ഇത് ബഹുചിത്ര പിന്തുണ ചേർക്കുന്നു. ഇത് കാരണം, ചിത്രങ്ങളെയും വീഡിയോകളെയും കാണാനും മനസ്സിലാക്കാനും കഴിയും.

ഫൈ-3.5-ਦൃശ്യ ക്ലോഡ്-3.5 സോനെറ്റും ജെമിനി 1.5 ഫ്ലാഷും പോലുള്ള വലിയ മോഡലുകളെ OCR, പട്ടിക, ചാർട്ട് വിവരണം പരീക്ഷണങ്ങളിൽ മറികടക്കും; സാധാരണ ദൃശ്യ അറിവ് വിവേകത്തിൽ സമാനമാനമാണ്. ബഹുമേഖലാ ഇൻപുട്ടായും പ്രവർത്തിക്കുന്നു.


### ഫൈ-3.5-MoE

***മിക്‌സ്ചർ ഓഫ് എക്സ്പേർട്ട്സ് (MoE)*** മോഡലുകൾക്ക് കുറച്ച് കംപ്യൂട്ടിൽ മുൻപരിശോധന അനുവദിക്കുന്നു, അതായത് ഒരേ കംപ്യൂട്ട് ബഡ്ജറ്റിൽ മോഡലിന്റെ വലുപ്പം അല്ലെങ്കിൽ ഡാറ്റാസെറ്റ് വലിപ്പം ഏറെക്കുറെ വർദ്ധിപ്പിക്കാം. പ്രത്യേകിച്ച്, MoE മോഡല്_dense മോഡലിനെ അപേക്ഷിച്ച് മുൻപരിശോധനയിൽ അതിൻറെ ഗുണനിലവാരം കൂടുതലായ വേഗത്തിൽ നേടും.

ഫൈ-3.5-MoE 16x3.8B വിദഗ്ധ മൊഡ്യൂളുകൾ ഉൾക്കൊള്ളുന്നു. 6.6B സജീവ പരിഷ്കരണങ്ങളോടെ ഫൈ-3.5-MoE വലിയ മോഡലുകൾ പോലുള്ള വിവേക, ഭാഷാ പണ്ഡിത്യം, ഗണിത താളിൽ സമാന നിലവാരം നേടേയും.

വ്യത്യസ്ത സാഹചര്യങ്ങളിൽ അടിസ്ഥാനമാക്കി ഫൈ-3/3.5 കുടുംബ മോഡലുകൾ ഉപയോഗിക്കാം. LLMകൾക്ക് വ്യത്യസ്തമായി, ഫൈ-3/3.5-മിനി അല്ലെങ്കിൽ ഫൈ-3/3.5-ദൃശ്യങ്ങൾ എഡ്ജ് ഉപകരണങ്ങളിൽ വിനിയോഗിക്കാം.

NVIDIA NIM-ന്റെ പ്രധാന സവിശേഷതകൾ:

- **വിനിയോഗത്തിനു എളുപ്പം:** NIM ഒരു കമാൻഡ് ഉപയോഗിച്ച് AI മോഡലുകൾ വിനിയോഗം സാധ്യമാക്കുന്നു, നിലവിലുള്ള പ്രവൃത്തിഭാഗങ്ങളിൽ എളുപ്പത്തിൽ സംയോജിപ്പിക്കാൻ.
- **പ്രദർശന നിലവാരം:** TensorRT, TensorRT-LLM പോലുള്ള NVIDIAയുടെ മുൻകൂട്ടി മെച്ചപ്പൂറ്റ ഇൻഫറൻസ് എൻജിനുകൾ ഉപയോഗിച്ച് കുറവായ ദൈർഘ്യം, ഉയർന്ന വഴിമുട്ടാണ് ഉറപ്പുവരുത്തുന്നത്.
- **സ്കേയിലബിലിറ്റി:** NIM Kubernetes-ൽ ഓട്ടോസ്കെയ്ലിംഗ് പിന്തുണക്കുന്നു, വ്യത്യസ്ത ജോലിഭാരങ്ങൾ ഫലപ്രദമായി കൈകാര്യം ചെയ്യാൻ.
- **സുരക്ഷയും നിയന്ത്രണവും:** സംഘടനകൾക്ക് അവരുടെ ഡാറ്റയും ആപ്ലിക്കേഷനുകളും സ്വയം നിയന്ത്രിക്കാനായി സ്വന്തം നിയന്ത്രിത അന്തസാഹചര്യത്തിൽ NIM മൈക്രോസർവീസുകൾ ഹോസ്റ്റ് ചെയ്യാം.
- **സ്റ്റാൻഡേർഡ് APIs:** NIM വ്യവസായ-സ്റ്റാൻഡേർഡ് APIs നൽകുന്നു, ചാറ്റ്ബോട്ടുകൾ, AI അസിസ്റ്റന്റുകൾ എന്നിവ പോലുള്ള AI ആപ്ലിക്കേഷനുകൾ നിർമ്മിക്കാൻ, സംയോജിപ്പിക്കാൻ ഇത് എളുപ്പമാക്കുന്നു.

### Phi-3/3.5 ലോക്കലായി പ്രവർത്തിപ്പിക്കൽ
Phi-3-നോ, GPT-3 പോലുള്ള ഏതെങ്കിലും ഭാഷാ മോഡലിനോ ബന്ധപ്പെട്ട ഇൻഫറൻസ് дегенത് നൽകുന്ന ഇൻപുട്ട് അടിസ്ഥാനമാക്കി പ്രതികരണങ്ങൾ അല്ലെങ്കിൽ പ്രവചനങ്ങൾ സൃഷ്ടിക്കുന്ന പ്രക്രിയയെ സൂചിപ്പിക്കുന്നു. Phi-3-ന് നിങ്ങള് ഒരു പ്രോസ് ടോ മറ്റോ ചോദ്യം നല്‍കിയപ്പോള്, അതിന്റെ പരിശീലിത ന്യുറൽ നെറ്റ്‌വർക്കുകൾ ഉപയോഗിച്ച് അവ പരിശീലനത്തിനായുള്ള ഡാറ്റയിലെ പാറ്റേണുകളും ബന്ധങ്ങളും വിശകലനം ചെയ്ത് ഏറ്റവും സാദ്ധ്യവും പ്രസക്തവുമായ മറുപടി കാണിച്ചു നൽകുന്നു.

**ഹഗ്ഗിംഗ് ഫേസ് ട്രാൻസ്ഫോർമർ**
Hugging Face Transformers പ്രകൃതിഭാഷ പ്രോസസ്സിങ്ങിനും (NLP) മറ്റ് മെഷീൻ ലേണിംഗ് ടാസ്കുകൾക്കുമായി രൂപകൽപ്പന ചെയ്ത ഒരു ശക്തമായ ലൈബ്രറിയാണ്. ഇതിന്റെ ചില പ്രധാന കാരണങ്ങൾ ഇവിടെ:

1. **പ്രീട്രെയിന്ഡ് മോഡലുകൾ**: ടാക്സ്റ്റ് ക്ലാസിഫിക്കേഷൻ, നാമമൂല്യ തിരിച്ചറിയൽ, ചോദ്യോത്തര, സംക്ഷേപണം, വിവർത്തനം, ടെക്സ്റ്റ് ജനറേഷൻ എന്നീ വിവിധ ടാസ്കുകൾക്കായി ഉപയോഗിക്കാൻ ആയിരക്കണക്കിന് പ്രീട്രെയിന്ഡ് മോഡലുകൾ ഇത് നൽകുന്നു.

2. **ഫ്രെയിമ്വർക്ക് ഇന്ററോപ്പറബിലിറ്റി**: PyTorch, TensorFlow, JAX തുടങ്ങിയവ ഉൾപ്പെടെയുള്ള പല ഡീപ് ലേണിംഗ് ഫ്രെയിമ്വർക്കുകളും ലൈബ്രറി പിന്തുണയ്ക്കുന്നു. ഇത് ഒരേ ഫ്രെയിംവർക്കിൽ മോഡൽ പരിശീലിപ്പിച്ച് മറ്റൊരിടത്ത് ഉപയോഗിക്കാൻ അനുവദിക്കുന്നു.

3. **മൾട്ടിമോഡൽ ശേഷികൾ**: NLP-ക്ക് പുറമെ Hugging Face Transformers കമ്പ്യൂട്ടർ വിഷൻ (ഉദാ., ചിത്ര വർഗ്ഗീകരണം, ഓബ്ജക്റ്റ് ഡിറ്റക്ഷൻ) ഓഡിയോ പ്രോസസ്സിങ് (ഉദാ., സംസാര തിരിച്ചറിയൽ, ഓഡിയോ ക്ലാസിഫിക്കേഷൻ) ടാസ്കുകൾക്കും പിന്തുണ നൽകുന്നു.

**GenAI-യ്ക്ക് ONNX റൺടൈം**

[ONNX Runtime](https://github.com/microsoft/onnxruntime-genai?WT.mc_id=academic-105485-koreyst)跨平台Inference 与训练机器学习加速器。 ONNX Runtime for Generative AI (GENAI)是一种强大的工具，它帮助您高效地在各种平台上运行生成式AI模型。

## ONNX Runtime എന്നത് എന്താണ്?
ONNX Runtime ഒരു ഓപ്പൺ-സോഴ്‌സ് പ്രോജക്ട് ആണ് ഇത് മെഷീൻ ലേണിംഗ് മോഡലുകളുടെ ഉയർന്ന പ്രകടനം ഉള്ള ഇൻഫറൻസ് സാധ്യമാക്കുന്നു. Open Neural Network Exchange (ONNX) ഫോർമാറ്റിലുള്ള മോഡലുകൾ പിന്തുണയ്ക്കുന്നു, ഇത് മെഷീൻ ലേണിംഗ് മോഡലുകൾ പ്രതിനിധാനം ചെയ്യുന്നതിനുള്ള ഒരു സ്റ്റാൻഡേർഡാണ്. ONNX Runtime ഇൻഫറൻസ് വേഗത കൂട്ടുകയും ചെലവ് കുറയ്ക്കുകയും ചെയ്യുന്നു, PyTorch, TensorFlow/Keras പോലുള്ള ഡീപ് ലേണിംഗ് ഫ്രെയിമ്വർക്കുകളും scikit-learn, LightGBM, XGBoost പോലുള്ള ക്ലാസിക്കൽ മെഷീൻ ലേണിംഗ് ലൈബ്രറികളും പിന്തുണയ്ക്കുന്നു. ONNX Runtime വിവിധ ഹാർഡ്വെയർ, ഡ്രൈവർ, ഓപ്പറേറ്റിംഗ് സിസ്റ്റങ്ങളുമായി പൊരുത്തപ്പെടുന്നു, ആവശ്യമായിടങ്ങളിൽ ഹാർഡ്വെയർ ആക്സിലറേറ്റർമാരെ ഉപയോഗിച്ച് മികച്ച പ്രകടനം നൽകുന്നു, കൂടാതെ ഗ്രാഫ് অপ്റ്റിമൈസേഷനുകളും ട്രാൻസ്ഫോമുകളും ചെയ്യുന്നു.

## Generative AI എന്താണ്?
Generative AI എന്നത് പുതിയ ഉള്ളടക്കം സൃഷ്ടിക്കാൻ കഴിയുന്ന AI സിസ്റ്റങ്ങളേക്കുറിച്ചാണ്, ഉദാഹരണത്തിന് ടെക്സ്റ്റ്, ചിത്രങ്ങൾ, സംഗീതം മുതലായവ, ഇവ ഉ training-ൽ നൽകിയ ഡാറ്റയുടെ അടിസ്ഥാനത്തിലാണ് സൃഷ്ടിക്കുന്നത്. ഉദാഹരണങ്ങൾ: GPT-3 പോലുള്ള ഭാഷാ മോഡലുകളും Stable Diffusion പോലുള്ള ചിത്ര സൃഷ്ടി മോഡലുകളും. ONNX Runtime for GenAI ലൈബ്രറി ONNX മോഡലുകളിലേക്കുള്ള ജനറേറ്റീവ് AI ലൂപ്പും, ONNX Runtime ഉപയോഗിച്ചുള്ള ഇൻഫറൻസ്, ലോഗിറ്റ്സ് പ്രോസസ്സിംഗ്, സെർച്ചും സാംപ്ലിംഗും, KV കാഷെ മാനേജ്മെന്റും നൽകുന്നു.

## ONNX Runtime for GENAI
ONNX Runtime for GENAI, ONNX Runtime-ന്റെ ശേഷികൾ വർധിപ്പിച്ച് ജനറേറ്റീവ് AI മോഡലുകൾക്കുള്ള പിന്തുണ നൽകുന്നു. ചില പ്രധാന പ്രത്യേകതകൾ:

- **വിപുലമായ പ്ലാറ്റ്‌ഫോം പിന്തുണ:** Windows, Linux, macOS, Android, iOS എന്നിവ ഉൾപ്പെടെയുള്ള പല പ്ലാറ്റ്‌ഫോമുകളിലും പ്രവർത്തിക്കുന്നു.
- **മോഡൽ പിന്തുണ:** LLaMA, GPT-Neo, BLOOM തുടങ്ങിയ പ്രശസ്ത ജനറേറ്റീവ് AI മോഡലുകൾ പിന്തുണയ്ക്കുന്നു.
- **പ്രകടന മെച്ചപ്പെടുത്തൽ:** NVIDIA GPU-കൾ, AMD GPU-കൾ എന്നിവ പോലുള്ള വിവിധ ഹൈഡ്രൈവ് ആക്സിലറേറ്റർമാരെക്കായുള്ള മെച്ചപ്പെടുത്തലുകൾ ഉൾക്കൊള്ളുന്നു.
- **ഉപയോഗ സൗകര്യം:** აპ്ലിക്കേഷനുകളിലേക്ക് എളുപ്പത്തിൽ സംയോജിപ്പിക്കാൻ API കൾ നൽകുന്നു, കുറഞ്ഞ കോഡിലൂടെ ടെക്സ്റ്റ്, ചിത്രം തുടങ്ങിയ ഉള്ളടക്കം സൃഷ്ടിക്കാൻ സാധിക്കുന്നു.
- ഉപയോക്താക്കൾക്ക് ഉയർന്ന നിലയിലെ generate() മെത്തോഡ് വിളിക്കാനോ, മോഡലിന്റെ ഓരോ ചുറ്റിലും ലോപ്പ് നടത്തിക്കൊണ്ട് ടോക്കൺ ഒന്നൊന്നായി സൃഷ്ടിക്കാനോ, ചേർന്നുള്ള പാരാമീറ്ററുകൾ അപ്ഡേറ്റ് ചെയ്യാനോ കഴിയും.
- ONNX റൺടൈം, greedy/beam സെർച്ചും TopP, TopK സാംപ്ലിംഗും ടോക്കൺ ശ്രേണികൾ സൃഷ്ടിക്കാൻ പിന്തുണയുണ്ട്, കൂടാതെ ആവർത്തന പിഴവുകൾ പോലുള്ള ലോഗിറ്റ്സ് പ്രോസസ്സിംഗും ഉൾപ്പെടുന്നു. ഉപയോക്താക്കൾക്ക് എളുപ്പത്തിൽ കസ്റ്റം സ്കോറിംഗ് അടിക്കുക കഴിയും.

### Generative AI എക്സ്റ്റൻഷനുകൾ ഇൻസ്റ്റാൾ ചെയ്യുക:

### ഒരു മോഡൽ ഓടിക്കുക: ഇത് Python-ൽ ഒരു ലളിതമായ ഉദാഹരണം:
```Python
import onnxruntime_genai as og

model = og.Model('path_to_your_model.onnx')

tokenizer = og.Tokenizer(model)

input_text = "Hello, how are you?"

input_tokens = tokenizer.encode(input_text)

output_tokens = model.generate(input_tokens)

output_text = tokenizer.decode(output_tokens)

print(output_text) 
```
### ഡെമോ: ONNX Runtime GenAI ഉപയോഗിച്ച് Phi-3.5-Vision വിളിക്കൽ


```python

import onnxruntime_genai as og

model_path = './Your Phi-3.5-vision-instruct ONNX Path'

img_path = './Your Image Path'

model = og.Model(model_path)

processor = model.create_multimodal_processor()

tokenizer_stream = processor.create_stream()

text = "Your Prompt"

prompt = "<|user|>\n"

prompt += "<|image_1|>\n"

prompt += f"{text}<|end|>\n"

prompt += "<|assistant|>\n"

image = og.Images.open(img_path)

inputs = processor(prompt, images=image)

params = og.GeneratorParams(model)

params.set_inputs(inputs)

params.set_search_options(max_length=3072)

generator = og.Generator(model, params)

while not generator.is_done():

    generator.compute_logits()
    
    generator.generate_next_token()

    new_token = generator.get_next_tokens()[0]
    
    output = tokenizer_stream.decode(new_token)
    
    print(tokenizer_stream.decode(new_token), end='', flush=True)

```
