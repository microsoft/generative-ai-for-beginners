# ആരംഭിക്കുന്നവർക്കായി ജനിതക AI (ആവിഷ്കരണ പതിപ്പ് 3) - ഒരു കോഴ്സ്

മൈക്രോസോഫ്റ്റ് ക്ലൗഡ് അഡ്വക്കേറ്റ്സ് അവതരിപ്പിക്കുന്ന 21 പാഠങ്ങളുടെ സമഗ്ര കോഴ്സിലൂടെ ജനിതക AI ആപ്ലിക്കേഷൻ നിർമ്മാണത്തിന്റെ അടിസ്ഥാനപരമായ കാര്യങ്ങൾ പഠിക്കുക.

## 🌱 ആരംഭിക്കൽ

ഈ കോഴ്സിൽ 21 പാഠങ്ങളുണ്ട്. ഓരോ പാഠവും തനിയെ ഉള്ള വിഷയം ഉൾക്കൊള്ളുന്നു, നിങ്ങളുടെ ഇഷ്ടാനുസരണം എവിടെ വേണെങ്കിലും തുടങ്ങാം!

പാഠങ്ങൾ "പഠിയ്ക്കുക" എന്ന പഠന വിഭാഗവും, പൈത്തൺ (**Python**) ഉം ടൈപ്‌സ്‌ക്രിപ്റ്റ് (**TypeScript**) ഉം ഉപയോഗിച്ച് കോഡ് ഉദാഹരണങ്ങൾ അടങ്ങിയ "നിർമാണം ചെയ്യുക" എന്ന പാഠവുമാണ്.

.NET ഡെവലപ്പർമാർക്ക്, [Generative AI for Beginners (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst) കാണുക!

ഓരോ പാഠത്തിനും "കീപ്പ് ലേണിംഗ്" വിഭാഗം ഉൾക്കൊള്ളുന്നു, അതിൽ അധിക പഠന ഉപകരണങ്ങളും ഉണ്ട്.

## നിങ്ങൾക്ക് വേണം
### ഈ കോഴ്സ് കോഡുകൾ പ്രവർത്തിപ്പിക്കാൻ താഴെ ഏതെങ്കിലും ഒരു പര്യാപ്തമാണ്:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **പാഠങ്ങൾ:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **പാഠങ്ങൾ:** "githubmodels" (GitHub Models ജൂലൈ 2026 അവസാനം പ്രഖ്യാപനത്തോടെ അവസാനിക്കുന്നു - Microsoft Foundry Models ഉപയോഗിക്കുക)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **പാഠങ്ങൾ:** "oai-assignment" 
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - നിങ്ങളുടെ സ്വന്തം യന്ത്രത്തിൽ മോഡലുകൾ പൂര്‍ണമായും ഓഫ്ലൈനായി പ്രവർത്തിപ്പിക്കുക, ക്ലൗഡ് സബ്‌സ്‌ക്രിപ്ഷൻ ആവശ്യമില്ല
   
- പൈത്തൺ അല്ലെങ്കിൽ ടൈപ്‌സ്‌ക്രിപ്റ്റ് അടിസ്ഥാന അറിവ് ഉപകാരപ്പെടും - \*പൂർണ്ണമായ തുടക്കക്കാർക്കായി ഈ [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) மற்றும் [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) കോഴ്സുകൾ പരിശോധിക്കുക
- ഈ റിപോസിറ്ററി മുഴുവൻ [ഫോർക്ക് ചെയ്യാൻ GitHub അക്കൗണ്ട്](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) വേണം

വികസന പരിസ്ഥിതി ക്രമീകരിക്കുന്നതിന് സഹായിക്കുന്ന **[Course Setup](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** പാഠം ഞങ്ങൾ തയ്യാറാക്കിയിട്ടുണ്ട്.
