## [2026-07-15] — പാഠം 09 (ഇമേജ് ആപ്ലിക്കേഷനുകൾ) GPT ഇമേജ് മോഡലുകൾക്കായി പുനഃരാഖ്യാനം

### മാറ്റങ്ങൾ

- **പാഠം 09 "ഇമേജ് ജനറേഷൻ ആപ്ലിക്കേഷനുകൾ നിർമ്മിക്കൽ"** പോരുന്ന പുതിയ **`gpt-image`**

    `base64.b64decode(...)` ഉപയോഗിച്ചാണ് അപ്ഡേറ്റ് ചെയ്തത്, ഡൗൺലോഡ് ചെയ്ത `url` കൂടാതെ `requests` ഉപയോഗിക്കുന്നതിനുപകരം.
  - ഇമേജ് API വേർഷൻ `2025-04-01-preview` ആയി ഉയർത്തി.
  - നിർമ്മിതമായ "താപനില" വിഭാഗം (ഇമേജ് മോഡലുകൾ `temperature` സ്വീകരിക്കുന്നില്ല) ഒഴിവാക്കി,
    DALL·E-2 മാത്രം ഉള്ള ചിത്രം **മാറിപ്പിക്കൽ** ഉള്ളടക്കം **ഇമേജ് എഡിറ്റിംഗ്** (മാസ്ക്/ഇൻപെയിന്റിംഗ്) വിഭാഗം ആയി മാറ്റി.
  - `README.md`, `python/aoai-app.py`, `python/oai-app.py`, `python/aoai-solution.py`, രണ്ട്
    അസൈൻമെന്റ് നോട്ട്ബുക്കുകൾ (`aoai-assignment.ipynb`, `oai-assignment.ipynb`),
    `typescript/image-generation-app` (`main.ts`, `.env-sample`), .NET `.dib` നോട്ട്ബുക്ക് എന്നിവയും പുതുക്കി.
