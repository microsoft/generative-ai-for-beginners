# ಆರಂಭಿಕರಿಗಾಗಿ ಜನಕ AI (ಆವೃತ್ತಿ 3) - ಒಂದು ಕೋರ್ಸ್

ಮೈಕ್ರೋಸಾಫ್ಟ್ ಕ್ಲೌಡ್ ಅಡ್ವೊಕೇಟ್ಸ್ ಅವರ 21 ಪಾಠಗಳ ಸಮಗ್ರ ಕೋರ್ಸ್ ಮೂಲಕ ಜನಕ AI ಅಪ್ಲಿಕೇಶನ್ ಗಳ ನಿರ್ಮಾಣದ ಮೂಲತತ್ವಗಳನ್ನು ಕಲಿಯಿರಿ.

## 🌱 ಪ್ರಾರಂಭಿಸುವುದು

ಈ ಕೋರ್ಸ್ 21 ಪಾಠಗಳನ್ನು ಹೊಂದಿದೆ. ಪ್ರತಿಯೊಂದು ಪಾಠವೂ ತನ್ನದೇ ವಿಷಯವನ್ನು ಒಳಗೊಂಡಿದೆ, ಆದ್ದರಿಂದ ನೀವು ಎಲ್ಲಿ ಬೇಕಾದರೂ ಪ್ರಾರಂಭಿಸಬಹುದು!

ಪಾಠಗಳನ್ನು "ಕಲಿಯಿ" (Learn) ಪಾಠಗಳು ಜನಕ AI ಕಲಿಕೆಯನ್ನು ವಿವರಿಸುವ ಮೂಲಕ ಅಥವಾ "ನಿರ್ಮಿಸಿ" (Build) ಪಾಠಗಳು ಕಲಿಕೆಯೊಂದಿಗೆ ಪೈಥಾನ್ ಮತ್ತು ಟೈಪ್‌ಸ್ಕ್ರಿಪ್ಟ್‌ ಎರಡರಲ್ಲಿಯೂ ಉದಾಹರಣೆ ಕೋಡ್ ಅನ್ನು ವಿವರಿಸುವ ಮೂಲಕ ಗುರುತಿಸಲಾಗಿದೆ.

.NET ಡೆವಲಪರ್‌ಗಳಿಗೆ [Generative AI for Beginners (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst) ನೋಡಿ!
