# ಆರಂಭಿಕರಿಗೆ ಜನರೇಟಿವ್ AI ಗಾಗಿ ಸಣ್ಣ ಭಾಷಾ ಮಾದರಿಗಳ ಪರಿಚಯ
ಜನರೇಟಿವ್ AI ಕೃತಕ ಬುದ್ಧಿಮತ್ತೆಯ ಒಂದು ಮನೋಗ್ರಾಹ್ಯ ಕ್ಷೇತ್ರವಾಗಿದ್ದು, ಹೊಸ ವಿಷಯವನ್ನು ರಚಿಸುವ ಸಾಮರ್ಥ್ಯ ಹೊಂದಿರುವ ವ್ಯವಸ್ಥೆಗಳ ಸೃಷ್ಟಿಯ ಮೇಲೆ ಕೇಂದ್ರೀಕರಿಸುತ್ತದೆ. ಈ ವಿಷಯವು ಪಠ್ಯ ಮತ್ತು ಚಿತ್ರಗಳಿಂದ ಸಂಗೀತ ಮತ್ತು ಹಾಗು ಸಂಪೂರ್ಣ ಆಭಾಸಿಕ ವಾತಾವರಣಗಳವರೆಗೆ ವ್ಯಾಪಿಸಬಹುದು. ಜನರೇಟಿವ್ AI ಯ ಅತ್ಯಂತ ರೋಚಕ ಅನ್ವಯಗಳಲ್ಲಿ ಒಂದಾದುದು ಭಾಷಾ ಮಾದರಿಗಳ ಕ್ಷೇತ್ರದಲ್ಲಿದೆ.

## ಸಣ್ಣ ಭಾಷಾ ಮಾದರಿಗಳು ಎಂದರೆ 무엇?

ಸಣ್ಣ ಭಾಷೆ ಮಾದರಿ (SLM) ಸಾಕಷ್ಟು ದೊಡ್ಡ ಭಾಷಾ ಮಾದರಿ (LLM) ಯ ಸಂಕುಚಿತ ರೂಪವನ್ನು ಪ್ರತಿನಿಧಿಸುತ್ತದೆ, LLM ಗಳ ವಾಸ್ತುಶಿಲ್ಪ ತತ್ವಗಳು ಮತ್ತು ತಂತ್ರಗಳನ್ನು ಬಳಸಿ, ಆದರೆ ಗಣನಾತ್ಮಕ ಪದರಗಣೆ ಗಣನೀಯವಾಗಿ ಕಡಿಮೆ ಆಗಿರುವದು.

SLM ಗಳು ಮಾನವಸಮಾನ ಪಠ್ಯವನ್ನು ರಚಿಸಲು ವಿನ್ಯಾಸ ಮಾಡಲ್ಪಟ್ಟ ಭಾಷಾ ಮಾದರಿಗಳ ಉಪಸಮೂಹವಾಗಿದ್ದು, GPT-4 ಹಾಗು ಇನ್ನಿತರ ದೊಡ್ಡ ಮಾದರಿಗಳಿಗಿಂತ компакт್ ಮತ್ತು ಪರಿಣಾಮಕಾರಿ ಆಗಿವೆ, ಇದು ಗಣನಾ ಸಂಪನ್ಮೂಲಗಳು ಸೀಮಿತವಾದ ಸಂದರ್ಭದಲ್ಲಿ ಅನ್ವಯಿಸಲು ಸೂಕ್ತವಾಗಿರುತ್ತದೆ. ಸಣ್ಣ ಆಯ್ದ ಗಾತ್ರದಿದ್ದರೂ ಮುಳ್ಳಿ ಕಾರ್ಯಗಳನ್ನು ನಿರ್ವಹಿಸಬಹುದು. ಸಾಮಾನ್ಯವಾಗಿ SLM ಗಳು LLM ಗಳ ಸಂಕುಚಿತ ಅಥವಾ ಡಿಸ್ಟಿಲ್ಲೇಷನ್ ಮೂಲಕ ರಚಿಸಲಾಗುತ್ತದೆ, ಮೂಲ ಮಾದರಿಯ ಬಹು ಭಾಗದ ಕಾರ್ಯಕ್ಷಮತೆ ಮತ್ತು ಭಾಷಾ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಉಳಿಸುವ ಉದ್ದೇಶದಿಂದ. ಈ ಮಾದರಿ ಗಾತ್ರದ ಕಡಿಮೆ, ಒಟ್ಟಾರೆ ಸುಲಭತೆಯನ್ನು ಕಡಿಮೆ ಮಾಡುತ್ತದೆ, ಇದು ಸ್ಮರಣೆ ಬಳಕೆ ಮತ್ತು ಗಣನಾತ್ಮಕ ಅಗತ್ಯಗಳ ಹಿನ್ನೆಲೆಯಲ್ಲಿ SLM ಗಳು ಹೆಚ್ಚು ಪರಿಣಾಮಕಾರಿ ಮಾಡುತ್ತದೆ. ಇವುನ್ ಇವುಗಳ ಈ ಸುಧಾರಣೆಗಳೆರಡರಲ್ಲಿ, SLM ಗಳು ಬಹುಶಃ ವಿಸ್ತೃತ ಮಾದರಿ ಗಾತ್ರಕ್ಕಿಂತ performance ಅಥವಾ ಆಳವಾದ ಅರ್ಥಮಾಡಿಕೊಡುವಿಕೆಯಲ್ಲಿ ಕೆಲವು ವ್ಯತ್ಯಾಸಗಳಿರಬಹುದು:

- ಪಠ್ಯ ರಚನೆ: ಸಸ್ಯಾತ್ಮಕ ಮತ್ತು ಸಾಂದರ್ಭಿಕವಾಗಿ ಪ್ರಸ್ತುತವರ್ತನೆ ಮಾಡುವ ವಾಕ್ಯಗಳು ಅಥವಾ ಅಧ್ಯಾಯಗಳನ್ನು ರಚಿಸುವುದು.
- ಪಠ್ಯ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ: ನೀಡಲಾದ ಪ್ರಾಂಪ್ಟ್ ಆಧರಿಸಿ ವಾಕ್ಯಗಳನ್ನು ಊಹಿಸುತ್ತಾ ಪೂರ್ಣಗೊಳಿಸುವುದು.
- ಅನುವಾದ: ಒಂದು ಭಾಷೆಯಿಂದ ಮತ್ತೊಂದು ಭಾಷೆಗೆ ಪಠ್ಯವನ್ನು ಪರಿವರ್ತಿಸುವುದು.
- ಸಾರಾಂಶ: ಉದ್ದವಾದ ಪಠ್ಯವನ್ನು ರುಚಿಕರವಾದ ಮತ್ತು ಸಂಕ್ಷಿಪ್ತ ಸಾರಾಂಶಗಳಾಗಿ ಸಂಕ್ಷಿಪ್ತಗೊಳಿಸುವುದು.

ದೊಡ್ಡ ಮಾದರಿಗಳಿಗಿಂತ ಕೆಲವು ಕಾರ್ಯಕ್ಷಮತೆ ಅಥವಾ ಅರ್ಥಮಾಡುವಿಕೆಯಲ್ಲಿ ವ್ಯತ್ಯಾಸಗಳೊಂದಿಗೆ.

## ಸಣ್ಣ ಭಾಷಾ ಮಾದರಿಗಳು ಹೇಗೆ ಕೆಲಸಮಾಡುತ್ತವೆ?
SLM ಗಳು ತುಂಬಾ ಪ್ರಮಾಣದ ಪಠ್ಯ ಡೇಟಾದ ಮೇಲೆ ತರಬೇತಿ ನೀಡಲ್ಪಡುತ್ತವೆ. ತರಬೇತಿಯ ವೇಳೆ, ಇವು ಭಾಷೆಯ ಮಾದರಿಗಳ ಮತ್ತು ಸಂರಚನೆಗಳನ್ನು ಕಲಿಯುತ್ತವೆ, ಪರಿಣಾಮವಾಗಿ ವ್ಯಾಕರಣಾತ್ಮಕವಾಗಿ ಸರಿಯಾದ ಮತ್ತು ಸಾಂದರ್ಭಿಕವಾಗಿ ಸೂಕ್ತವಾದ ಪಠ್ಯವನ್ನು ರಚಿಸಬಲ್ಲದು. ತರಬೇತಿ ಪ್ರಕ್ರಿಯೆಯಲ್ಲಿ ಒಳಗೊಂಡಿದ್ದು:

- ಡೇಟಾ ಸಂಗ್ರಹಣೆ: ವಿವಿಧ ಮೂಲಗಳಿಂದ ದೊಡ್ಡ ಪಠ್ಯ ಡೇಟಾಸೆಟ್ ಗಳ ಸಂಗ್ರಹ.
- ಪೂರ್ವ ಪ್ರಕ್ರಿಯೆ: ತರಬೇತಿಗೆ ಸೂಕ್ತವಾಗಲು ಡೇಟಾವನ್ನು ಶುದ್ಧ ಮತ್ತು ಕ್ರಮಬದ್ಧಗೊಳಿಸುವುದು.
- ತರಬೇತಿ: ಯಂತ್ರ ಅಧ್ಯಯನ ಆಲ್ಗಾರಿದಮ್ಗಳ ಬಳಸಿ ಮಾದರಿಯನ್ನು ಪಠ್ಯದ ಅರಿವು ಮತ್ತು ರಚನೆಗಾಗಿ ಪ್ರೊತ್ಸಾಹಿಸುವುದು.
- ಫೈನ್ ಟ್ಯೂನಿಂಗ್: ವಿಶೇಷ ಕಾರ್ಯಗಳಲ್ಲಿ ಸಂಪಾದನೆ ಉತ್ತಮಗೊಳಿಸಲು ಮಾದರಿಯನ್ನು ಸರಿಹೊಂದಿಸುವುದು.

SLM ಗಳ ಅಭಿವೃದ್ಧಿ ಸಂಪನ್ಮೂಲ-ಕಡಿಮೆ ಪರಿಸರಗಳಲ್ಲಿ, ಉದಾಹರಣೆಗೆ ಮೊಬೈಲ್ ಸಾಧನಗಳು ಅಥವಾ ಎಡ್ಜ್ ಕಂಪ್ಯೂಟಿಂಗ್ ಪ್ಲಾಟ್ಫಾರ್ಮ್ ಗಳಲ್ಲಿ ನಿಯೋಜಿಸಲು ಬಯಸುವ ಅವಶ್ಯಕತೆಗೆ ಅನುಗುಣವಾಗಿ ನಡೆಯುತ್ತಿದೆ, ಇಲ್ಲಿ ಪೂರ್ಣ-ಮಾರ್ಗದ LLM ಗಳು ಭಾರೀ ಸಂಪನ್ಮೂಲ ಅವಶ್ಯಕತೆಗಳ ಕಾರಣ ಅನ್ವಯಪ್ರಾಯವಾಗದಿರಬಹುದು. ಪರಿಣಾಮಕಾರಿತ್ವದ ಮೇಲೆ ಜೋಡಿಸಿ, SLM ಗಳು ಪ್ರದರ್ಶನ ಮತ್ತು ಪ್ರವೇಶವನ್ನು ಸಮತೋಲನಗೊಳಿಸುತ್ತವೆ, ಅನೇಕ ಕ್ಷೇತ್ರಗಳಲ್ಲಿ ವಿಸ್ತೃತ ಅನ್ವಯತೆಯನ್ನು ಸಾಧ್ಯವಾಗಿಸುತ್ತವೆ.

## ಕಲಿಕೆಯ ಗುರಿಗಳು

ಈ ಪಾಠದಲ್ಲಿ, ನಾವು SLM ಬಗ್ಗೆ ತಿಳಿವು ನೀಡಲು ಮತ್ತು ಅದನ್ನು Microsoft Phi-3 ಜೊತೆಗೆ ಸಂಯೋಜಿಸಿ ಪಠ್ಯ ವಿಷಯ, ದೃಶ್ಯ ಮತ್ತು MoE ನಲ್ಲಿ ವಿವಿಧ ಸನ್ನಿವೇಶಗಳನ್ನು ಕಲಿಯಲು ನಿರೀಕ್ಷಿಸುತ್ತೇವೆ.

ಈ ಪಾಠದ ಅಂತ್ಯದಲ್ಲಿ, ನೀವು ಕೆಳಗಿನ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರಿಸಲು ಸಾಧ್ಯವಾಗಬೇಕು:

- SLM ಮತ್ತು LLM ನಡುವೆ ಏನು ಭೇದವಿದೆ?
- Microsoft Phi-3/3.5 ಕುಟುಂಬವೇನು?
- Microsoft Phi-3/3.5 ಕುಟುಂಬದೊಂದಿಗೆ ಇನ್ಫರೆನ್ಸ್ ಹೇಗೆ ನಡೆಸುವುದು?

ಸಿದ್ಧರಿದ್ದೀರಾ? ಆರಂಭಿಸೋಣ.

## ದೊಡ್ಡ ಭಾಷಾ ಮಾದರಿಗಳು (LLMs) ಮತ್ತು ಸಣ್ಣ ಭಾಷಾ ಮಾದರಿಗಳು (SLMs) ನಡುವೆ ವ್ಯತ್ಯಾಸಗಳು

LLM ಮತ್ತು SLM ಇಬ್ಬರೂ ಸಂಖ್ಯಾಶಾಸ್ತ್ರೀಯ ಯಂತ್ರ ಅಧ್ಯಯನ ಮೂಲತತ್ವಗಳ ಮೇಲೇ ನಿರ್ಮಿತವಾಗಿವೆ, ಅವುಗಳ ವಾಸ್ತುಶಿಲ್ಪ ವಿನ್ಯಾಸ, ತರಬೇತಿ ವಿಧಾನಗಳು, ಡೇಟಾ ಉತ್ಪಾದನೆ ಪ್ರಕ್ರಿಯೆಗಳು ಮತ್ತು ಮಾದರಿ ಮೌಲ್ಯಮಾಪನ ತಂತ್ರಗಳಲ್ಲಿ ಒಂದೇ ರೀತಿಯ ಕ್ರಮಗಳನ್ನು ಅನುಸರಿಸುತ್ತವೆ. ಆದಾಗ್ಯೂ, ಈ ಎರಡು ಮಾದರಿ ವಿಧಗಳ ಮಧ್ಯೆ ಹಲವಾರು ಪ್ರಮುಖ ಅಂಶಗಳು ವ್ಯತ್ಯಾಸವನ್ನು ತರುವುದಾಗಿ ಕಂಡುಬರುತ್ತದೆ.

## ಸಣ್ಣ ಭಾಷಾ ಮಾದರಿಗಳ ಅನ್ವಯಗಳು

SLM ಗಳಿಗೆ ವ್ಯಾಪಕ ಅನ್ವಯಗಳಿವೆ, ಅವುಗಳ ಪೈಕಿ:

- ಚಾಟ್‌ಬಾಟ್‌ಗಳು: ಗ್ರಾಹಕ ಸೇವೆಯನ್ನು ಒದಗಿಸುವುದು ಮತ್ತು ಬಳಕೆದಾರರೊಂದಿಗೆ ಸಂಭಾಷಣಾತ್ಮಕ ರೀತಿಯಲ್ಲಿ ಸಂವಹನ ಮಾಡುವುದು.
- ವಿಷಯ ರಚನೆ: ಲೇಖಕರಿಗೆ ಆಸಕ್ತಿಗಳು ಪ್ರಸ್ತಾಪಿಸುವುದರಲ್ಲಿ ಅಥವಾ ಸಂಪೂರ್ಣ ಲೇಖನಗಳನ್ನು ಮಸೂದೆ ರೂಪಿಸುವುದರಲ್ಲಿ ಸಹಾಯ ಮಾಡುವುದು.
- ಶಿಕ್ಷಣ: ವಿದ್ಯಾರ್ಥಿಗಳಿಗೆ ಬರವಣಿಗೆ ಕಾರ್ಯಗಳಲ್ಲಿ ಮತ್ತು ಹೊಸ ಭಾಷೆಗಳ ಕಲಿಕೆಯಲ್ಲೂ ಸಹಾಯ.
- ಪ್ರವೇಶ ಸಾಮರ್ಥ್ಯ: ಅಂಗವೈಕಲ್ಯ ಹೊಂದಿರುವ ವ್ಯಕ್ತಿಗಳಿಗೆ ಪಠ್ಯದಿಂದ ಶಬ್ದಕ್ಕೆ ವ್ಯವಸ್ಥೆಗಳು ಸೇರಿದಂತೆ ಉಪಕರಣಗಳನ್ನು ರಚಿಸುವುದು.

**ಗಾತ್ರ**
  
LLM ಗಳು ಮತ್ತು SLM ಗಳು ನಡುವೆ ಪ್ರಮುಖ ವ್ಯತ್ಯಾಸ ಮಾದರಿಯ ಗಾತ್ರದಲ್ಲಿ ಇದೆ. ChatGPT (GPT-4) వంటి LLM ಗಳು ಅಂದುಕೊಂಡರೆ ഏകಕೋಟಿ 1.76 ಟ್ರಿಲಿಯನ್ ಪಾರಾಮೀಟರ್ ಗಳನ್ನು ಹೊಂದಿರಬಹುದು, ಆದರೆ Mistral 7B പോലുള്ള ಮುಕ್ತ ಮೂಲದ SLM ಗಳು ಸುಮಾರು 7 ಬಿಲಿಯನ್ ಪಾರಾಮೀಟರ್ ಗಳನ್ನು ಹೊಂದಿದ್ದು ಗಣನೀಯವಾಗಿ ಕಡಿಮೆ. ಈ ವ್ಯತ್ಯಾಸವು ಮುಖ್ಯವಾಗಿ ಮಾದರಿ ವಾಸ್ತುಶಿಲ್ಪ ಮತ್ತು ತರಬೇತಿ ಪ್ರಕ್ರಿಯೆಗಳಲ್ಲಿ ಬದಲಾಗುವಿಕೆಯಿಂದ ಉಂಟಾಗುತ್ತದೆ. ಉದಾಹರಣೆಗೆ, ChatGPT ಸ್ವಯಂ-ಶ್ರದ್ಧಾ ಯಂತಿಕೆ ಹಾಗೂ ಎಂಕೋಡರ್-ಡೆಕೋಡರ್ ಕಾರ್ಯಚಟುವಟಿಕೆಯಲ್ಲಿ ಬಳಸುತ್ತದೆ, ಆದರೆ Mistral 7B ಸ್ಲೈಡಿಂಗ್ ವಿಂಡೋ ಶ್ರದ್ಧಾ ಯಂತಿಕೆಯನ್ನು ಬಳಸಿ ಡೆಕೋಡರ್-ಮಾತ್ರ ಮಾದರಿಯಲ್ಲಿ ಹೆಚ್ಚು ಪರಿಣಾಮಕಾರಿಯಾಗಿ ತರಬೇತಿಗೆ ಅವಕಾಶ ನೀಡುತ್ತದೆ. ಈ ವಾಸ್ತುಶಿಲ್ಪ ವ್ಯತ್ಯಾಸವು ಮಾದರಿಗಳ ಸಂಕೀರ್ಣತೆ ಮತ್ತು ಕಾರ್ಯಕ್ಷಮತೆಯಲ್ಲಿ ಮಹತ್ವಪೂರ್ಣ ಪರಿಣಾಮಗಳನ್ನು ಹೊಂದಿದೆ.

**ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವಿಕೆ**

LLM ಗಳ ತರಬೇತಿ ಮತ್ತು ನಿಯೋಜನೆ ಸಂಪನ್ಮೂಲ-ಭಾರೀ ಪ್ರಕ್ರಿಯೆಗಳು ಆಗಿದ್ದು, ಸಾಮಾನ್ಯವಾಗಿ ದೊಡ್ಡ ಪ್ರಮಾಣದ GPU ಕ್ಲಸ್ಟರ್ ಗಳಂತಹ ಗಣನಾತ್ಮಕ ಮೂಲಸೌಕರ್ಯವನ್ನು ಅಗತ್ಯವಿರುತ್ತದೆ. ಉದಾಹರಣೆಗೆ, ChatGPT ತರಬೇತಿಗೆ ಸಾವಿರಾರು GPU ಗಳ ಅವಧಿ ಬೇಕಾಗಬಹುದು. ಹೀಗಾಗಿ, SLM ಗಳು ಬಾಧಾಕರಿ ಪಾರಾಮೀಟರ್ ಸಂಖ್ಯೆಗಳೊಂದಿಗೆ ಗಣನಾತ್ಮಕ ಸಂಪನ್ಮೂಲಗಳಲ್ಲಿ ಹೆಚ್ಚು ಸುಲಭವಂತೆಯಾಗಿವೆ. **ಪಕ್ಷಪಾತ**

LLM ಗಳಲ್ಲಿ पक्षಪಾತ ಒಂದು ಪರಿಚಿತ ಸಮಸ್ಯೆಯಾಗಿದ್ದು, ಮುಖ್ಯವಾಗಿ ತರಬೇತಿ ಡೇಟಾದ ಸ್ವಭಾವದಿಂದ ಉಂಟಾಗುತ್ತದೆ. ಇವು ಅಂತರ್ಜಾಲದಿಂದ ಲಭ್ಯವಿರುವ ಕಚ್ಚಾ, ತೆರೆಯಾದ ಡೇಟಾ ಮೇಲೆ ಅವಲಂಬಿ ಆಗುವ ಶಾಸ್ತ್ರೀಯ ಮಾದರಿಗಳು, ಕೆಲವು ಸಮುದಾಯಗಳನ್ನು ಅಲ್ಪಪ್ರತಿನಿಧಿಸುತ್ತವೆ ಅಥವಾ ತಪ್ಪಾಗಿ ಪ್ರತಿನಿಧಿಸುತ್ತವೆ, ತಪ್ಪು ಲೇಬಲಿಂಗ್ ಟೋಡುವಂತೆ ಮಾಡಬಹುದು ಅಥವಾ ಭಾಷಾಸಾಂದ್ರತೆ, ಭೌಗೋಳಿಕ ಬದಲಾವಣೆಗಳು ಮತ್ತು ವ್ಯಾಕರಣ ನಿಯಮಗಳಿಂದ ಪ್ರಭಾವಿತವಾದ ಭಾಷಾ ಬಾಯಿಲ್‍ಗಳನ್ನು ಒಳಗೊಂಡಿರಬಹುದು. ಜೊತೆಗೆ, LLM ವಾಸ್ತುಶಿಲ್ಪಗಳ ಸಂಕೀರ್ಣತೆ ಅನಿಮಿತ ಪಾಲನಾ ಪಕ್ಷಪಾತವನ್ನು ಹೆಚ್ಚಿಸಬಹುದು, ಇದು ಸೂಕ್ಷ್ಮವಾಗಿ ಫೈನ್-ಟ್ಯೂನಿಂಗ್ ಇಲ್ಲದೆ ಗಮನ ಸೆಳೆಯದಿರಬಹುದು. ಆದರೆ SLM ಗಳು ಹೆಚ್ಚಿನ ನಿಯಂತ್ರಿತ, ಡೊಮೇನ್-ನಿರ್ದಿಷ್ಟ ಡೇಟಾ ಸೆಟ್ ಗಳ ಪೋನ್‍ಣಿತಾಯಿತಾಗಿದ್ದರಿಂದ, ಇವು ಪಕ್ಷಪಾತಗಳಿಗೆ ಕಡಿಮೆ ಒಲಿಸುತ್ತವೆ, ಆದರೂ ಸಂಪೂರ್ಣ ರಿತಿಯಲ್ಲಿ ಮುಕ್ತವಲ್ಲ.

Phi-3 / 3.5 ಸೂಚ್ಸೂತ್ರ ಮುಖ್ಯವಾಗಿ ಪಠ್ಯವನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು Phi ಯ ಸಾಮರ್ಥ್ಯವನ್ನು ಸೂಚಿಸುತ್ತದೆ ಮತ್ತು ದೃಶ್ಯವು Phi ಗೆ ಜಗತ್ತನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ಕಣ್ಣುಗಳನ್ನು ನೀಡುತ್ತದೆ ಎಂದು ಭಾವಿಸಬಹುದು.


**Phi-3-ದೃಶ್ಯ**

4.2B ಪಾರಾಮೀಟರ್‌ಗಳ Phi-3-ದೃಶ್ಯ ಸಾಮಾನ್ಯ ದೃಶ್ಯ ತರ್ಕ ಕಾರ್ಯಗಳು, OCR, ಟೇಬಲ್ ಮತ್ತು ಚಿತ್ರಿಕೆ ಗ್ರಾಹಕ ತರ್ಕ ಕಾರ್ಯಗಳಲ್ಲಿ Claude-3 Haiku ಮತ್ತು Gemini 1.0 ಪ್ರೋ ಸೇರಿದಂತೆ ದೊಡ್ಡ ಮಾದರಿಗಳನ್ನು ಮೀರಿಸುತ್ತದೆ.


**Phi-3.5-ದೃಶ್ಯ**

Phi-3.5-ದೃಶ್ಯ Phi-3-ದೃಶ್ಯದ ಅಪ್ಗ್ರೇಡ್ ಆಗಿದ್ದು, ಇದು ಬಹುಚಿತ್ರ ಬೆಂಬಲವನ್ನು ಹೊಂದಿದ್ದು. ಇದನ್ನು ಉತ್ತಮ ದೃಶ್ಯ ಎಂದು ನೋಡಿ ನಿಮಗೆ ಚಿತ್ರಗಳನ್ನು ಮಾತ್ರವಲ್ಲದು, ವೀಡಿಯೋಗಳನ್ನು ಕೂಡ ನೋಡಲು ಸಾಮರ್ಥ್ಯವನ್ನು ನೀಡುತ್ತದೆ.

Phi-3.5-ದೃಶ್ಯ OCR, ಟೇಬಲ್ ಮತ್ತು ಚಾರ್ಟ್ ಮನವಿ ಕಾರ್ಯಗಳಲ್ಲಿ Claude-3.5 Sonnet ಮತ್ತು Gemini 1.5 Flash ನಂತಹ ದೊಡ್ಡ ಮಾದರಿಗಳನ್ನು ಮೀರಿಸುತ್ತದೆ ಮತ್ತು ಸಾಮಾನ್ಯ ದೃಶ್ಯ ಜ್ಞಾನ ತರ್ಕ ಕಾರ್ಯಗಳಲ್ಲಿ ಸಮಾನ. ಇದು ಬಹು-ಫ್ರೇಮ್ ಇನ್‌ಪುಟ್ ಬೆಂಬಲವನ್ನು ಒದಗಿಸುತ್ತದೆ, ಅಂದರೆ ಬಹುಚಿತ್ರ ಇನ್‌ಪುಟ್‌ಗಳ ಮೇಲೆ ತರ್ಕ prouಹರಣ ಮಾಡಲು ಸಾಧ್ಯ.


### Phi-3.5-MoE

***ಮಿಕ್ಷರ್ ಆಫ್ ಎಕ್ಸ್ಪರ್ಟ್‌ಗಳು (MoE)*** ಕಡಿಮೆ ಗಣನವನ್ನು ಬಳಸಿ ಮಾದರಿಗಳನ್ನು ಪ್ರೀಟ್ರೇನಿಂಗ್‌ನೇರಲು ಅನುಮತಿಸುತ್ತದೆ, ಇದರಿಂದ_dense model_ ಗೆ ಸಮಾನ ಗಣನ ಬಜೆಟ್‌ನೊಂದಿಗೆ ನೀವು ಮಾದರಿ ಅಥವಾ ಡೇಟಾಸೆಟ್ ಗಾತ್ರವನ್ನು ಬಹುಮಟ್ಟಿಗೆ ವಿಸ್ತರಿಸಬಹುದು. ವಿಶೇಷವಾಗಿ, MoE ಮಾದರಿ ತನ್ನ_dense_ ಸಹೋದ್ಯೋಗಿಯಂತೆ ತರಬೇತಿಯ ವೇಳೆ ಹೆಚ್ಚು ವೇಗದಿಂದ ಅದೇ ಗುಣಮಟ್ಟಕ್ಕೆ ತಲುಪಬಹುದು.

Phi-3.5-MoE 16x3.8B ತಜ್ಞ ಮೋಡ್ಯೂಲ್ ಗಳಿಂದ બનેದಿದ್ದು, ಕೇವಲ 6.6B ಸಕ್ರಿಯ ಪಾರಾಮೀಟರ್ ಗಳೊಂದಿಗೆ ಹೆಚ್ಚಿನ ದೊಡ್ಡ ಮಾದರಿಗಳಂತಹ ತರ್ಕ, ಭಾಷಾ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವಿಕೆ ಮತ್ತು ಗಣಿತ ಕಾರ್ಯಗಳನ್ನು ಸಾಧಿಸುತ್ತದೆ.

ನಾವು ವಿವಿಧ ಸನ್ನಿವೇಶಗಳಲ್ಲಿ Phi-3/3.5 ಕುಟುಂಬ ಮಾದರಿಗಳನ್ನು ಬಳಸಬಹುದು. LLM ಯ ಭಿನ್ನವಾಗಿ, Phi-3/3.5-ಮಿನಿ ಅಥವಾ Phi-3/3.5-ದೃಶ್ಯವನ್ನು ಎಡ್ಜ್ ಸಾಧನಗಳಲ್ಲಿ ನಿಯೋಜಿಸಬಹುದು.

**ಹಗ್ಗಿಂಗ್ ಫೇಸ್ ಟ್ರಾನ್ಸ್‌ಫಾರ್ಮರ್**
ಹಗ್ಗಿಂಗ್ ಫೇಸ್ ಟ್ರಾನ್ಸ್‌ಫಾರ್ಮರ್‌ಗಳು ಸ್ವಾಭಾವಿಕ ಭಾಷಾ ಪ್ರಕ್ರಿಯೆಗಳು (NLP) ಹಾಗು ಇತರ ಮೆಷಿನ್ ಲರ್ನಿಂಗ್ ಕಾರ್ಯಗಳಿಗೆ ವಿನ್ಯಾಸಗೊಳಿಸಿದ ಶಕ್ತಿಶಾಲಿ ಗ್ರಂಥಾಲಯವಾಗಿದೆ. ಕೊರತೆಯಲ್ಲಿದೆ ಕೆಲವು ಪ್ರಮುಖ ಅಂಶಗಳು:

1. **ಪೂರ್ವ-ತರಬೇತಿ ಪಡೆದ ಮಾದರಿಗಳು:** ಪಠ್ಯ ವರ್ಗೀಕರಣ, ಹೆಸರಾದ ಘಟಕ ಗುರುತಿಸುವಿಕೆ, ಪ್ರಶ್ನೋತ್ತರ, ಸಾರಾಂಶ, ಅನುವಾದ ಮತ್ತು ಪಠ್ಯ ಸೃಷ್ಟಿಯಂತಹ ವಿವಿಧ ಕಾರ್ಯಕ್ಕೆ ಬಳಸಬಹುದಾದ ಸಾವಿರಾರು ಪೂರ್ವ-ತರಬೇತಿ ಪಡೆದ ಮಾದರಿಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ.

2. **ಫ್ರೇಮ್ವರ್ಕ್ ಪರಸ್ಪರಕಾರಿತ್ವ:** ಗ್ರಂಥಾಲಯವು ಪೈಟಾರ್ಚ್, ಟೆನ್ಸರ್‌ಫ್ಲೋ ಮತ್ತು ಜ್ಯಾಕ್ಸ್ ಸೇರಿದಂತೆ ಹಲವಾರು ಡೀಪ್ ಲರ್ನಿಂಗ್ ಫ್ರೇಮ್ವರ್ಕ್‌ಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ. ಇದರಿಂದ ನೀವು ಒಂದು ಫ್ರೇಮ್ವರ್ಕ್‌ನಲ್ಲಿ ಮಾದರಿಯನ್ನು ತರಬೇತಿಹೊಂದಿಸಿ, ಇನ್ನೊಂದು ಫ್ರೇಮ್ವರ್ಕ್‌ನಲ್ಲಿ ಬಳಸಬಹುದು.

3. **ಬಹುವಿಧ ಸಾಮರ್ಥ್ಯಗಳು:** NLP ಜೊತೆಗೆ, ಹಗ್ಗಿಂಗ್ ಫೇಸ್ ಟ್ರಾನ್ಸ್‌ಫಾರ್ಮರ್‌ಗಳು ಕಂಪ್ಯೂಟರ್ ದೃಷ್ಟಿ (ಉದಾ: ಚಿತ್ರ ವರ್ಗೀಕರಣ, ವಸ್ತು ಪತ್ತೆ) ಮತ್ತು ಧ್ವನಿ ಪ್ರಕ್ರಿಯಿಸುವಿಕೆ (ಉದಾ: ಮಾತನಾಡುವಿಕೆ ಗುರುತಿಸುವಿಕೆ, ಧ್ವನಿ ವರ್ಗೀಕರಣ) ಕಾರ್ಯಗಳನ್ನು ಸಹ ಬೆಂಬಲಿಸುತ್ತವೆ.

4. **ಉಪಯೋಗ ಸುಲಭತೆ:** ಗ್ರಂಥಾಲಯವು ಮಾದರಿಗಳನ್ನು ಸುಲಭವಾಗಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ಸೂಕ್ಷ್ಮ-ಸಂಯೋಜನೆ ಮಾಡಲು API ಗಳು ಮತ್ತು ಸಾಧನಗಳನ್ನು ನೀಡುತ್ತದೆ, ಇನ್ನೂ ಆರಂಭಿಕರಿಂದ ಪರಿಣಿತರಿಗೂ ಇವು ಸುಲಭವಾಗಿ ಲಭ್ಯವಿದೆ.

5. **ಸಮುದಾಯ ಮತ್ತು ಸಂಪನ್ಮೂಲಗಳು:** ಹಗ್ಗಿಂಗ್ ಫೇಸ್ ಕೈಗಾರಿಕೆಯ ಸಮುದಾಯ ಇರುವುದಾಗಿ, ವ್ಯಾಪಕ ದಾಖಲಾತಿ, ಪಾಠಗಳು ಮತ್ತು ಮಾರ್ಗದರ್ಶಿಗಳನ್ನು ಒದಗಿಸುವ ಮೂಲಕ ಬಳಕೆದಾರರು ಪ್ರಾರಂಭಿಸಲು ಮತ್ತು ಗ್ರಂಥಾಲಯವನ್ನು ಅತ್ಯುತ್ತಮವಾಗಿ ಬಳಸಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

**ಜನ್ AI ಗಾಗಿ ONNX ರಂಟೈಮ್**

[ONNX ರಂಟೈಮ್](https://github.com/microsoft/onnxruntime-genai?WT.mc_id=academic-105485-koreyst) ಕ್ರಾಸ್-ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಇನ್ಫರೆನ್ಸ್ ಮತ್ತು ತರಬೇತಿ ಮೆಷಿನ್-ಲರ್ನಿಂಗ್ ತ್ವರಕ. Jain AI ಗಾಗಿ ONNX ರಂಟೈಮ್ (GENAI) ಪ್ರಬಲವಾದ ಸಾಧನವಾಗಿದ್ದು ವಿವಿಧ ವೇದಿಕೆಗಳಲ್ಲಿ ಸೃಜನಾತ್ಮಕ AI ಮಾದರಿಗಳನ್ನು ಪರಿಣಾಮಕಾರಿಯಾಗಿ ಚಾಲನೆ ಮಾಡಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

## ONNX ರಂಟೈಮ್ ಎಂದರೆ ಏನು?
ONNX ರಂಟೈಮ್ ಒಂದು ಓಪನ್-ಸೋರ್ಸ್ ಯೋಜನೆಯಾಗಿದೆ ಇದು ಮೆಷಿನ್ ಲರ್ನಿಂಗ್ ಮಾದರಿಗಳ ಉನ್ನತ-ಕಾರ್ಯಕ್ಷಮ ಇನ್ಫರೆನ್ಸ್ ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ. ಇದು Open Neural Network Exchange (ONNX) ಸ್ವರೂಪದ ಮಾದರಿಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ, ಇದು ಮೆಷಿನ್ ಲರ್ನಿಂಗ್ ಮಾದರಿಗಳನ್ನು ಪ್ರತಿನಿಧಿಸುವ ಮಾನಕವಾಗಿದೆ. ONNX ರಂಟೈಮ್ ಇನ್ಫರೆನ್ಸ್ ವೇಗವಾಗಿ ಗ್ರಾಹಕ ಅನುಭವಗಳನ್ನು ನಿರ್ವಹಿಸಲು ಮತ್ತು ವೆಚ್ಚಗಳನ್ನು ಕಡಿಮೆ ಮಾಡಲು ಸಾಧ್ಯವಾಗಿಸುತ್ತದೆ, ಇದರಲ್ಲಿ ಪೈಟಾರ್ಚ್ ಮತ್ತು ಟೆನ್ಸರ್‌ಫ್ಲೋ/ಕೇರಿಸ್ ಡೀಪ್ ಲರ್ನಿಂಗ್ ಫ್ರೇಮ್ವರ್ಕ್‌ಗಳಿಂದ ಹಿಡಿದುस्कारಿಕ ಮೆಷಿನ್ ಲರ್ನಿಂಗ್ ಪುಸ್ತಕಾಲಯಗಳು ಸ್ಕೈಕಿಟ್-ಲರ್ನ್, ಲೈಟ್‌GBM, XGBoost ಮುಂತಾದವುಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ. ONNX ರಂಟೈಮ್ ವಿವಿಧ ಹಾರ್ಡ್‌ವೇರ್, ಡ್ರೈವರ್‌ಗಳು ಮತ್ತು ಕಾರ್ಯಾಚರಣೆ ವ್ಯವಸ್ಥೆಗಳೊಂದಿಗೆ ಹೊಂದಿಕೆಯಾಗಿದ್ದು, ಹಾರ್ಡ್‌ವೇರ್ ತ್ವರಕಗಳನ್ನು ಉಪಯೋಗಿಸುವ ಮೂಲಕ ಗರಿಷ್ಠ ಕಾರ್ಯಕ್ಷಮತೆಯನ್ನು ಸಾದ್ಯಮಾಡುತ್ತದೆ ಮತ್ತು ಗ್ರಾಫ್ ಆಪ್ಟಿಮೈಸೇಶನ್ ಮತ್ತು ಪರಿವರ್ತನೆಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ.

## ಜನರೇಟಿವ್ AI ಎಂದರೆ ಏನು?
ಜನರೇಟಿವ್ AI ಎಂದರೆ ತರಬೇತಿಗೊಂಡ ದತ್ತಾಂಶ ಆಧರಿಸಿ ಹೊಸ ವಸ್ತುಗಳನ್ನು ಅಥವಾ ವಿಷಯವನ್ನು ಸೃಷ್ಟಿಸಬಹುದಾದ AI ವ್ಯವಸ್ಥೆಗಳು, ಉದಾಹರಣೆಗೆ ಪಠ್ಯ, ಚಿತ್ರಗಳು, ಅಥವಾ ಸಂಗೀತ. ಉದಾಹರಣೆಗಳು GPT-3 ಮುಂತಾದ ಭಾಷಾ ಮಾದರಿಗಳು ಮತ್ತು Stable Diffusion ಮೊದಲಿನ ಚಿತ್ರ ಸೃಷ್ಟಿ ಮಾದರಿಗಳು. ONNX ರಂಟೈಮ್ ಗಾಗಿ ಜನರೇಟಿವ್ AI ಗ್ರಂಥಾಲಯವು ONNX ಮಾದರಿಗಳಿಗಾಗಿ ಜನರೇಟಿವ್ AI ಲೂಪ್ ಅನ್ನು ಒದಗಿಸುತ್ತದೆ, ಇದರಲ್ಲಿ ONNX ರಂಟೈಮ್ ಹಿನ್ನೆಲೆಯಲ್ಲಿನ ಇನ್ಫರೆನ್ಸ್, ಲಾಜಿಟ್ ಪ್ರಕ್ರಿಯೆ, ಶೋಧನೆ ಮತ್ತು സാമ്പ್ಲಿಂಗ್, ಮತ್ತು KV ಕ್ಯಾಶೆ ನಿರ್ವಹಣೆ ಸೇರಿವೆ.

## GENAI ಗಾಗಿ ONNX ರಂಟೈಮ್
GENAI ಗಾಗಿ ONNX ರಂಟೈಮ್ ONNX ರಂಟೈಮ್ ನ ಸಾಮರ್ಥ್ಯವನ್ನು ವಿಸ್ತರಿಸಿ ಜನರೇಟಿವ್ AI ಮಾದರಿಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ. ಪ್ರಮುಖ ವೈಶಿಷ್ಟ್ಯಗಳು ಕೆಳಗಿನಂತೆ:

- **ವಿಸ್ತೃತ ವೇದಿಕೆ ಬೆಂಬಲ:** ವಿಂಡೋಸ್, ಲಿನಕ್ಸ್, ಮ್ಯಾಕ್‌ಒಎಸ್, ಆಂಡ್ರಾಯ್ಡ್ ಮತ್ತು ಐಒಎಸ್ ಸೇರಿದಂತೆ ವಿವಿಧ ವೇದಿಕೆಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.
- **ಮಾದರಿ ಬೆಂಬಲ:** LLaMA, GPT-Neo, BLOOM ಮತ್ತು ಇನ್ನಿತರ ಜನಪ್ರಿಯ ಜನರೇಟಿವ್ AI ಮಾದರಿಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ.
- **ಕಾರ್ಯಕ್ಷಮತೆ ಆಪ್ಟಿಮೈಸೇಶನ್:** NVIDIA GPU ಗಳು, AMD GPU ಗಳು ಮತ್ತು ಇನ್ನಿತರ ಹಾರ್ಡ್‌ವೇರ್ ತ್ವರಕಗಳಿಗಾಗಿ ಆಪ್ಟಿಮೈಸೇಶನ್‌ಗಳನ್ನು ಒಳಗೊಂಡಿವೆ.
- **ಬಳಕೆ ಸುಲಭತ:** ಅಪ್ಲಿಕೇಶನ್‌ಗಳಿಗೆ ಸುಲಭ ಏಕೀಕರಣಕ್ಕಾಗಿ API ಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ, ಕಡಿಮೆ ಕೋಡ್ ಬಳಸಿ ಪಠ್ಯ, ಚಿತ್ರಗಳು ಮತ್ತು ಇತರ ವಿಷಯಗಳನ್ನು ಸೃಷ್ಟಿಸಲು ಅನುಮತಿಸುತ್ತದೆ.
- ಬಳಕೆದಾರರು ಉನ್ನತ ಮಟ್ಟದ generate() ವಿಧಾನವನ್ನು ಕರೆಸಬಹುದು ಅಥವಾ ಮಾದರಿಯ ಪ್ರತಿಯೊಂದು ಪುನರಾವೃತಿಯಲ್ಲಿ ಒಂದು ಟೋಕನ್ ತಯಾರಿಸಿ ಸರಣಿಯಲ್ಲಿ ಹೋಲಿಕೆ ಅಥವಾ ಉತ್ಪಾದನಾ ಪರಿಮಾಣಗಳನ್ನು ಸೆಟ್ ಮಾಡಬಹುದು.
- ONNX ರಂಟೈಮ್ ಲಾಜಿ ಪ್ರಾಸೆಸಿಂಗ್, ಹಾಸ್ಟಿಂಗ್ ಪೀನಾಲ್ಟಿಗಳು ಸೇರಿದಂತೆ greedy/ಬೀಮ್ ಶೋಧನೆ ಮತ್ತು TopP, TopK ಸ್ಯಾಂಪ್ಲಿಂಗ್, ಟೋಕನ್ ಸರಣಿಗಳನ್ನು ಸೃಷ್ಟಿಸಲು ಬೆಂಬಲ ನೀಡುತ್ತದೆ. ಇದಲ್ಲದೆ ಕಸ್ಟಮ್ ಸ್ಕೋರಿಂಗ್ ಅನ್ನು ಸುಲಭವಾಗಿ ಸೇರಿಸಬಹುದು.

## ಪ್ರಾರಂಭಿಸುವುದು
GENAI ಗಾಗಿ ONNX ರಂಟೈಮ್ ಮೂಲಕ ಪ್ರಾರಂಭಿಸಲು ನೀವು ಈ ಹಂತಗಳನ್ನು ಅನುಸರಿಸಬಹುದು:

### ONNX ರಂಟೈಮ್ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ:
```Python
pip install onnxruntime
```
### ಜನರೇಟಿವ್ AI ವಿಸ್ತರಣೆಗಳನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ:
```Python
pip install onnxruntime-genai
```

### ಮಾದರಿಯನ್ನು ಚಾಲನೆ ಮಾಡಿ: ಇದು Python ನಲ್ಲಿ ಸರಳ ಉದಾಹರಣೆ:
```Python
import onnxruntime_genai as og

model = og.Model('path_to_your_model.onnx')

tokenizer = og.Tokenizer(model)

input_text = "Hello, how are you?"

input_tokens = tokenizer.encode(input_text)

output_tokens = model.generate(input_tokens)

output_text = tokenizer.decode(output_tokens)

print(output_text) 
```
### ಡೆಮೊ: ONNX ರಂಟೈಮ್ GenAI ಬಳಸಿ Phi-3.5-Vision ಅನ್ನು ಕರೆಮಾಡುವುದು


```python

import onnxruntime_genai as og

model_path = './Your Phi-3.5-vision-instruct ONNX Path'

img_path = './Your Image Path'

model = og.Model(model_path)

processor = model.create_multimodal_processor()

tokenizer_stream = processor.create_stream()

text = "Your Prompt"

prompt = "<|user|>\n"

prompt += "<|image_1|>\n"

prompt += f"{text}<|end|>\n"

prompt += "<|assistant|>\n"

image = og.Images.open(img_path)

inputs = processor(prompt, images=image)

params = og.GeneratorParams(model)

params.set_inputs(inputs)

params.set_search_options(max_length=3072)

generator = og.Generator(model, params)

while not generator.is_done():

    generator.compute_logits()
    
    generator.generate_next_token()

    new_token = generator.get_next_tokens()[0]
    
    output = tokenizer_stream.decode(new_token)
    
    print(tokenizer_stream.decode(new_token), end='', flush=True)

```


**ಇತರೆ**

ONNX ರಂಟೈಮ್, ಒಲ್ಲಾಮಾ, ಮತ್ತು ಫೌಂಡ್ರಿ ಲೊಕಲ್ ರೆಫರೆನ್ಸ್ ವಿಧಾನಗಳನ್ನು ಹೊರತುಪಡಿಸಿ, ನಾವು ವಿವಿಧ ತಯಾರಕರಿಂದ ನೀಡಲಾದ ಮಾದರಿ ರೆಫರೆನ್ಸ್ ವಿಧಾನಗಳ ಆಧಾರದ ಮೇಲೆ ಸಂಖ್ಯಾತ್ಮಕ ಮಾದರಿಗಳ ರೆಫರೆನ್ಸನ್ನು ಪೂರ್ಣಗೊಳಿಸಬಹುದು. ಉದಾಹರಣೆಗಾಗಿ Apple MLX ಫ್ರೇಮ್ವರ್ಕ್ ಮತ್ತು Apple Metal, Qualcomm QNN ಮತ್ತು NPU, Intel OpenVINO ಮತ್ತು CPU/GPU ಮುಂತಾದವು. ಇನ್ನಷ್ಟು ವಿಷಯಕ್ಕಾಗಿ [Phi-3 ಕುಕ್‌ಬುಕ್](https://github.com/microsoft/phi-3cookbook?WT.mc_id=academic-105485-koreyst) ಅನ್ನು ನೋಡಬಹುದು.
