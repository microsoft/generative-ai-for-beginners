# ਬਿਗਿਨਰਾਂ ਲਈ ਜਨਰੇਟਿਵ AI (ਵਰਜ਼ਨ 3) - ਇੱਕ ਕੋਰਸ

ਮਾਈਕ੍ਰੋਸਾਫਟ ਕਲਾਉਡ ਐਡਵੋਕੇਟਾਂ ਵਲੋਂ ਸਾਡੇ 21-ਪਾਠਾਂ ਵਾਲੇ ਵਿਆਪਕ ਕੋਰਸ ਨਾਲ ਜਨਰੇਟਿਵ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਦੇ ਨਿਹੜੇ ਸਿਖੋ।

## 🌱 ਸ਼ੁਰੂਆਤ ਕਰੋ

ਇਸ ਕੋਰਸ ਵਿੱਚ 21 ਪਾਠ ਹਨ। ਹਰ ਪਾਠ ਆਪਣਾ ਵਿਸ਼ਾ ਕਵਰ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਤੁਸੀਂ ਜਿੱਥੇ ਚਾਹੋ ਸ਼ੁਰੂ ਕਰੋ!

ਪਾਠ "ਸਿੱਖੋ" ਜਾਂ "ਤਿਆਰ ਕਰੋ" ਲੇਬਲਡ ਹਨ। "ਸਿੱਖੋ" ਪਾਠ ਜਨਰੇਟਿਵ AI ਦੇ ਸੰਕਲਪ ਨੂੰ ਸਮਝਾਉਂਦੇ ਹਨ ਅਤੇ "ਤਿਆਰ ਕਰੋ" ਪਾਠ ਸੰਕਲਪ ਅਤੇ ਕੋਡ ਉਦਾਹਰਣਾਂ ਦੋਹਾਂ ਲਈ **Python** ਅਤੇ **TypeScript** ਵਿੱਚ ਸੁਝਾਅ ਨਹੀਂ ਹੋਣ 'ਤੇ ਵੀ।

.NET ਡਿਵੈਲਪਰਾਂ ਲਈ ਦੇਖੋ [ਬਿਗਿਨਰਾਂ ਲਈ ਜਨਰੇਟਿਵ AI (.NET ਐਡੀਸ਼ਨ)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

ਹਰ ਪਾਠ ਵਿੱਚ ਇੱਕ "ਝਾਰੀ ਸਿੱਖਣ" ਖੰਡ ਵੀ ਹੁੰਦਾ ਹੈ ਜਿਸ ਵਿੱਚ ਵਾਧੂ ਸਿੱਖਣ ਵਾਲੇ ਔਜ਼ਾਰ ਸ਼ਾਮਲ ਹਨ।

 - [Azure OpenAI ਸਰਵਿਸ](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **ਪਾਠ:** "aoai-assignment"
