# الذكاء الاصطناعي التوليدي للمبتدئين (الإصدار 3) - دورة تعليمية

تعلم أساسيات بناء تطبيقات الذكاء الاصطناعي التوليدي مع دورتنا الشاملة المكونة من 21 درسًا من Microsoft Cloud Advocates.

## 🌱 البداية

تحتوي هذه الدورة على 21 درسًا. يغطي كل درس موضوعه الخاص، لذا ابدأ من حيث تريد!

يتم تصنيف الدروس إما كدروس "تعلم" تشرح مفهومًا في الذكاء الاصطناعي التوليدي أو كدروس "بناء" تشرح مفهومًا مع أمثلة رمز برمجي بـ **Python** و **TypeScript** عندما يكون ذلك ممكنًا.

لمطوري .NET راجع [الذكاء الاصطناعي التوليدي للمبتدئين (إصدار .NET)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

يتضمن كل درس أيضًا قسم "استمر بالتعلم" مع أدوات تعلم إضافية.

## ما تحتاجه
### لتشغيل رمز هذه الدورة، يمكنك استخدام إما:
 - [خدمة Azure OpenAI](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **الدروس:** "aoai-assignment"
 - [نماذج Microsoft Foundry](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **الدروس:** "githubmodels" (نماذج GitHub ستتوقف في نهاية يوليو 2026 - استخدم نماذج Microsoft Foundry بدلاً منها)
 - [واجهة برمجة تطبيقات OpenAI](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **الدروس:** "oai-assignment"
 - [Foundry محلي](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - تشغيل النماذج بالكامل بدون اتصال بالإنترنت على جهازك الخاص، بدون الحاجة لاشتراك سحابي
   
- معرفة أساسية بـ Python أو TypeScript مفيدة - \*للمبتدئين تمامًا راجع هذه الدورات [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) و [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst)
- حساب GitHub لعمل [تفرع لهذا المستودع بالكامل](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) إلى حساب GitHub الخاص بك

لقد أنشأنا درس **[إعداد الدورة](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** لمساعدتك في إعداد بيئة التطوير الخاصة بك.

لا تنسَ [تقييم (⭐) هذا المستودع](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) لتجده بسهولة لاحقًا.
