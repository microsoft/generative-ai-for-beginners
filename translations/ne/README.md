# शुरुवातीहरूका लागि जेनेरेटिभ एआई (संस्करण ३) - एक कोर्स

माइक्रोसफ्ट क्लाउड एड्भोकेट्ससंग हाम्रो २१-पाठ व्यापक कोर्सद्वारा जेनेरेटिभ एआई अनुप्रयोग निर्माणका आधारभूत कुरा सिक्नुहोस्।

## 🌱 सुरु गर्ने तरिका

यो कोर्समा २१ पाठहरू छन्। प्रत्येक पाठले आफ्नो विषय समेट्छ, त्यसैले जहाँबाट पनि सुरु गर्न सक्नुहुन्छ!

पाठहरू "सिक्ने" (Learn) भनेर लेबल गरिएका छन् जुन जेनेरेटिभ एआई अवधारणा बुझाउँछन् वा "बनाउने" (Build) पाठहरूले एक अवधारणा र कोड उदाहरणहरू **Python** र **TypeScript** दुबैमा व्याख्या गर्छन् जहाँ सम्भव छ।

.NET विकासकर्ताहरूले [Generative AI for Beginners (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst) पनि हेर्नुहोस्!
