# Generatyvinis DI pradedantiesiems (3 versija) - kursas

Išmokite pagrindus, kaip kurti generatyvines DI programas su mūsų 21 pamokos išsamiu kursu, kurį rengia Microsoft Cloud Advocates.

## 🌱 Pradžia

Šis kursas turi 21 pamoką. Kiekviena pamoka nagrinėja savo temą, todėl pradėkite bet kur, kaip norite!

Pamokos žymimos kaip „Mokymasis“ pamokos, aiškinančios generatyvinio DI koncepciją, arba „Kūrimas“ pamokos, kurios aiškina koncepciją ir pateikia kodo pavyzdžius tiek **Python**, tiek **TypeScript** kalbomis, jei įmanoma.

.NET kūrėjams rekomenduojame [Generatyvinis DI pradedantiesiems (.NET leidimas)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Kiekviena pamoka taip pat turi skyrių „Tęskite mokymąsi“ su papildomomis mokymo priemonėmis.

## Ko jums reikia
### Norint paleisti šio kurso kodą, galite naudoti:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Pamokos:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Pamokos:** "githubmodels" (GitHub Models bus nutraukti 2026 m. liepos pabaigoje - vietoje jų naudokite Microsoft Foundry Models)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Pamokos:** "oai-assignment"
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Paleiskite modelius visiškai neprisijungę savo įrenginyje, nereikia jokių debesijos prenumeratų
   
- Pagrindinės Python ar TypeScript žinios yra naudingos - \*Pradedantiesiems rekomenduojame šiuos [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) ir [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) kursus
- GitHub paskyra, kad galėtumėte [atskirti šį repositoriją](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) savo GitHub paskyroje

Sukūrėme **[Kurso sąrankos](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** pamoką, kuri padės jums paruošti kūrimo aplinką.

Nepamirškite [paskelbti (🌟) žvaigždutės šiam repozitorijui](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst), kad lengviau jį rastumėte vėliau.
