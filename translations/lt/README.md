# Generatyvinis DI pradedantiesiems (3 versija) - Kursas

Susipažinkite su generatyvinių DI programų kūrimo pagrindais per mūsų 21 pamokos išsamų kursą, kurį parengė Microsoft Cloud Advocates.

## 🌱 Pradžia

Šiame kurse yra 21 pamoka. Kiekviena pamoka apima savo temą, tad pradėkite nuo bet kurios!

Pamokos yra žymimos kaip "Mokytis" – paaiškinančios generatyvinio DI sąvokas, arba "Kurti" – paaiškinančios sąvokas ir pateikiančios kodo pavyzdžius tiek **Python**, tiek **TypeScript** kalbomis, kai tai įmanoma.

.NET programuotojams siūlome [Generatyvinis DI pradedantiesiems (.NET leidimas)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Kiekvienoje pamokoje yra skyrius „Toliau mokykitės“ su papildomomis mokymosi priemonėmis.

## Ko jums reikia
### Tam, kad paleisti šio kurso kodą, galite naudoti:
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) – **Pamokos:** „aoai-assignment“
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) – **Pamokos:** „githubmodels“ (GitHub Models bus nutrauktas 2026 metų liepos pabaigoje – naudokite vietoj jo Microsoft Foundry Models)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) – **Pamokos:** „oai-assignment“
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) – Modelių paleidimas visiškai neprisijungus savo įrenginyje, nereikia debesų prenumeratos
   
- Pagrindinės Python ar TypeScript žinios naudingos – *Pradedantiesiems rekomenduojame šiuos [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) ir [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) kursus
- GitHub paskyra, kad galėtumėte [šakoti visą šį repozitorijų](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) į savo GitHub paskyrą

Nepamirškite [žvaigždutės (🌟) šiame repozitorijoje](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst), kad vėliau lengviau jį rastumėte.
