# AI ya Kizazi kwa Waanzilishi (Toleo la 3) - Kozi

Jifunze misingi ya kujenga programu za AI ya Kizazi na kozi yetu kamili ya masomo 21 na Microsoft Cloud Advocates.

## 🌱 Kuanzia

Kozi hii ina masomo 21. Kila somo linashughulikia mada yake hivyo anza popote ulipendezalo!

Masomo yamewekwa lebo iwe ni "Jifunze" masomo yanayotafsiri dhana ya AI ya Kizazi au "Jenga" masomo yanayotafsiri dhana na mifano ya msimbo kwa **Python** na **TypeScript** inapowezekana.

Kwa Waendelezaji wa .NET angalia [AI ya Kizazi kwa Waanzilishi (Toleo la .NET)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst)!

Kila somo pia lina sehemu ya "Endelea Kujifunza" yenye zana za ziada za kujifunza.

### Kuendesha msimbo wa kozi hii, unaweza kutumia:

- Ujuzi wa msingi wa Python au TypeScript ni msaada - \*Kwa waanzilishi kamili angalia kozi hizi za [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) na [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst)
- Akaunti ya GitHub ili [kutoa nakala ya repo yote hii](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) kwa akaunti yako ya GitHub mwenyewe
