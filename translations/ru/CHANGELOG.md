# Журнал изменений

Все заметные изменения в учебной программе Generative AI for Beginners документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Поскольку это
учебная программа, а не версия программного продукта, записи сгруппированы по дате.

## [2026-07-16] — Валидация контента + Изображения к уроку 09

## [2026-07-15] — Переписан урок 09 (Изображения: Приложения) для моделей GPT Image

### Изменено

- **Переписан урок 09 "Создание приложений генерации изображений"** вокруг текущей семейства моделей **`gpt-image`**
  (по умолчанию **`gpt-image-2`**; `gpt-image-1.5` / `gpt-image-1-mini` также GA), заменяя
  устаревший контент DALL·E 2/3. Основные исправления:
  - модели `gpt-image` возвращают изображение в виде **base64 (`b64_json`)**, а не URL. Обновлены все примеры для
    `base64.b64decode(...)` вместо загрузки `url` с помощью `requests`.
  - Повышена версия API изображений до `2025-04-01-preview`.
  - Заменён сфабрикованный раздел "temperature" (модели изображений не принимают `temperature`) и
    контент вариаций изображений только для DALL·E-2 на раздел **редактирования изображений** (маски/заплатки).
  - Обновлены `README.md`, `python/aoai-app.py`, `python/oai-app.py`, `python/aoai-solution.py`, оба
    ноутбука для заданий (`aoai-assignment.ipynb`, `oai-assignment.ipynb`),
    `typescript/image-generation-app` (`main.ts`, `.env-sample`), и .NET ноутбук `.dib`.

### Удалено

- Удалены устаревшие образцы `python/aoai-app-variation.py` и `python/oai-app-variation.py`
  ( `images.create_variation` предназначен только для DALL·E-2 и не поддерживается `gpt-image` ).
- Удалены 4 "осиротевших" ресурса изображений, связанные с удалённым разделом сравнения температуры
  (`v1-generated-image.png`, `v2-generated-image.png`, `v1-temp-generated-image.png`,
  `v2-temp-generated-image.png`).
- Удалена ненужная зависимость `requests` из примеров Python и требований урока.

### Проверено

- Проведено комплексное тестирование `aoai-app.py` с развернутой моделью `gpt-image-1.5`, подтверждена работа раскодирования base64
  и сохранение PNG. Ноутбуки подтверждены как валидный JSON.

## [2026-07-14] — Обновление модели по умолчанию + Руководство по моделям рассуждения

### Изменено

- **Модель чата по умолчанию `gpt-4o-mini` → `gpt-5-mini`** во всех исполняемых примерах учебной программы,
  документации и конфигурации. Это вызвано статусом жизненного цикла модели: на Microsoft Foundry,
  `gpt-4o-mini` (выводится из эксплуатации 2026-10-01) и вся семья `gpt-4.1` (`gpt-4.1`, `gpt-4.1-mini`,
  `gpt-4.1-nano`, выводятся из эксплуатации 2026-10-14) находятся в состоянии **депрецирования**, тогда как **семья GPT-5
  (`gpt-5-mini`, `gpt-5`, `gpt-5-nano`) является Общедоступной** (выводится 2027-02-06). Обновлено:
  - `.env.copy`, `00-course-setup/03-providers.md` (рекомендованные команды развертывания и `az cognitiveservices`),
    и README для уроков 04, 06, 07 и 15.
  - Примеры Python в уроке 06 (`oai-app.py`, `oai-app-recipe.py`, `oai-history-bot.py`,
    `oai-study-buddy.py`, `githubmodels-app.py`) и скрипты урока 08.
  - Примеры TypeScript / JavaScript в уроках 06, 07 и 11, и .NET ноутбуки `.dib` для
    уроков 06 и 07.
  - Ноутбуки для заданий в уроках 04, 06, 07 и 11 (кодовые ячейки), а также примеры с docstring `shared/python/api_utils.py`.
- **Руководство по параметрам моделей рассуждения (новое).** `gpt-5-mini` — это *модель рассуждения*: она **не**
  поддерживает `temperature`/`top_p` и использует `max_completion_tokens` (завершения чата) /
  `max_output_tokens` (API ответов) вместо `max_tokens`. Соответственно:
  - Удалены `temperature`/`top_p`/`max_tokens` из примеров, которые теперь по умолчанию используют `gpt-5-mini`
    (`githubmodels-app.py`, `aoai-app-recipe.py`, `oai-app-recipe.py`, README урока 15 RAG).
  - Добавлена заметка **"Модели рассуждения не используют `temperature`"** в урок 06, объясняющая, что
    модели рассуждения управляются с помощью **prompt engineering + средств управления рассуждениями**, а не с помощью
    параметров сэмплинга, в то время как `temperature`/`top_p` остаются валидными для моделей без рассуждения
    (GPT-4.x, Mistral, Llama, Phi, открытые модели).
- **`gpt-5-mini` не используется в уроке по тонкой настройке (урок 18).** GPT-5 поддерживает только
  fine-tuning с подкреплением (RFT); руководство по контролируемой тонкой настройке (SFT) урока 18 оставлено
  `gpt-4.1-mini`, который поддерживает SFT/DPO.
- **Для демонстраций температуры используется модель Llama.** Чтобы продолжить обучение `temperature` (которую модели рассуждения
  отвергают), используется модель `Llama-3.3-70B-Instruct` через конечную точку Foundry Models. Добавлена новая
  переменная `AZURE_INFERENCE_CHAT_MODEL` в `.env.copy`; ноутбуки уроков 04/06 `githubmodels` и
  пример `06` `js-githubmodels` читают её (с возвратом к `Llama-3.3-70B-Instruct`) и сохраняют свои
  демонстрации `temperature`/`top_p`/`max_tokens`.
- **Обновлены примеры JS / .NET для GPT-5.** Удалены `temperature`/`top_p`/`max_tokens` из примеров GPT-5
  (`06` `recipe-app` TypeScript, `06` `.dib` .NET — также исправляет `MaxOutputTokenCount`,
  чтобы вывод рассуждений не обрезался). Пример `06` `js-githubmodels` теперь использует Llama для сохранения демонстрации температуры.
  В `.dib` указано, что `Azure.AI.Inference` + модель Llama — это способ
  демонстрации `Temperature` в .NET.
- Оставлены на месте `gpt-4o-mini` / `gpt-5-mini` там, где они остались точными: ссылки на кодирование токенов `tiktoken`,
  списки доступности каталога моделей, а также речевые модели урока 02 (`gpt-4o-transcribe`).
- Образцы уроков 20 (Mistral) и 21 (Meta) сохраняют `temperature`/`max_tokens`, так как они ориентированы на модели Mistral/Llama,
  которые эти параметры поддерживают.

### Изменено

- **Chat Completions API → Responses API** во всех примерах чатов на Python и TypeScript
  (`client.responses.create(...)` → `response.output_text`), включая уроки 04, 06, 07, 11,
  15 и 18, а также их файлы README.
- **GitHub Models → Microsoft Foundry Models** во всем тексте, ссылках и примерах. GitHub Models
  будет закрыт в конце июля 2026 года; примеры теперь указывают на каталог моделей Microsoft Foundry и используют
  переменные окружения `AZURE_INFERENCE_ENDPOINT` / `AZURE_INFERENCE_CREDENTIAL`.
- **Документация `.env.copy`, `AGENTS.md` и провайдера** обновлена с учетом того, что Azure OpenAI теперь часть
  Microsoft Foundry, и версия API по умолчанию увеличена до `2024-10-21`.
- **Примеры на TypeScript** (уроки 06, 07, 08, 11) переведены с устаревшего бета SDK `@azure/openai`
  на пакет `openai` (чат-приложения используют Responses API; приложение поиска использует
  клиента embedding).
- **.NET блокноты** (`dotnet/*.dib`) стандартизированы на `Azure.AI.OpenAI` **2.1.0**: уроки 06 и 07
  используют API `ChatClient`, урок 08 использует `EmbeddingClient` (`GenerateEmbedding` / `ToFloats`), и
  урок 09 использует `ImageClient` (`GenerateImage`) с `gpt-image-1`, заменяя устаревшие
  `OpenAIClient` / `GetEmbeddingsAsync` / `GetImageGenerationsAsync` из `1.0.0-beta.9`.
- **Модернизация названий продуктов**: "Azure AI Studio" / "Azure AI Foundry" → **Microsoft Foundry**
  (уроки 14, 16, 17) и "Bing" → **Microsoft Copilot** (урок 12), где имелись в виду
  текущие продукты.
- **DevContainer** (`.devcontainer/`) теперь включает расширения Pylance, Black, Ruff, ESLint, Prettier и Copilot,
  включает форматирование при сохранении и устанавливает `ruff`, `black`, `mypy` и `pytest`, чтобы проверки CI
  можно было воспроизвести локально.
- **Генерация изображений** (урок 09) рекомендует `gpt-image-1` для Azure (каталог Azure убрал
  `dall-e-3`).
- **`docs/ENHANCED_FEATURES_ROADMAP.md`** обновлено с учетом выполненных работ (миграция API, CI,
  DevContainer, тесты) и текущих фактов (переводы создаются автоматически с помощью
  Azure Co-op Translator; API Ассистентов заменён на API Ответов).

### Исправлено

- **`shared/python/input_validation.py`** — `validate_text_input(allow_empty=True)` теперь возвращает
  пустую строку для входных данных, состоящих только из пробелов, вместо возникновения ошибки «слишком коротко» (в соответствии с
  случаем `None`). Найдено и покрыто новым набором тестов.
- **Примеры изображений из урока 09** — исправлены реальные ошибки: `InvalidRequestError` → `BadRequestError`,
  `images.create` → `images.generate`, `Image.create_variation` → `client.images.create_variation`,

- **Блокнот RAG из урока 15** — восстановлена настройка клиента, заменён удалённый `DataFrame.append`
  на `pd.concat`, а также модернизировано использование устаревшего SDK.
- Устаревшие / снятые с поддержки имена моделей (`gpt-3.5-turbo`, `gpt-35-turbo`) заменены на `gpt-4o-mini`
  в активных примерах; исторические результаты тонкой настройки в уроке 18 сохранены и помечены,
  а не переписаны.

### Устаревшее / Примечания

- **Примеры моделей Microsoft Foundry**, использующих SDK `azure-ai-inference` / `@azure-rest/ai-inference`
