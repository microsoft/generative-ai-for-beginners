# Generatív mesterséges intelligencia kezdőknek (3. verzió) - Egy tanfolyam

Tanuld meg a generatív MI alkalmazások építésének alapjait a Microsoft Cloud Advocates átfogó, 21 leckés tanfolyamával.

## 🌱 Kezdés

Ennek a tanfolyamnak 21 leckéje van. Minden lecke külön témával foglalkozik, így onnan kezdhetsz, ahol szeretnél!

A leckéket kétféleképpen jelöljük: "Learn" leckék egy generatív MI koncepciót magyaráznak el, vagy "Build" leckék, amelyek egy koncepciót és kódrészleteket mutatnak Python és TypeScript nyelven, amikor lehetséges.

A .NET fejlesztőknek ajánljuk a [Generative AI for Beginners (.NET Edition)](https://github.com/microsoft/Generative-AI-for-beginners-dotnet?WT.mc_id=academic-105485-koreyst) tanfolyamot!

Minden lecke tartalmaz egy "Keep Learning" részt további tanulási eszközökkel.

## Amit igényelsz
### A tanfolyam kódjának futtatásához használhatod egyik alábbi lehetőséget: 
 - [Azure OpenAI Service](https://aka.ms/genai-beginners/azure-open-ai?WT.mc_id=academic-105485-koreyst) - **Leckék:** "aoai-assignment"
 - [Microsoft Foundry Models](https://ai.azure.com/catalog/models?WT.mc_id=academic-105485-koreyst) - **Leckék:** "githubmodels" (A GitHub Models 2026 júliusa végén megszűnik — helyette használd a Microsoft Foundry Models-t)
 - [OpenAI API](https://aka.ms/genai-beginners/open-ai?WT.mc_id=academic-105485-koreyst) - **Leckék:** "oai-assignment" 
 - [Foundry Local](https://foundrylocal.ai?WT.mc_id=academic-105485-koreyst) - Modellek teljes offline futtatása saját eszközödön, felhő előfizetés nélkül
   
- Alap Python vagy TypeScript ismeret hasznos - \*Teljesen kezdőknek ezek a [Python](https://aka.ms/genai-beginners/python?WT.mc_id=academic-105485-koreyst) és [TypeScript](https://aka.ms/genai-beginners/typescript?WT.mc_id=academic-105485-koreyst) tanfolyamok segítenek
- Egy GitHub fiók, hogy [forkold ezt a tárolót](https://aka.ms/genai-beginners/github?WT.mc_id=academic-105485-koreyst) saját GitHub fiókodra

Létrehoztunk egy **[Tanfolyam Beállítása](./00-course-setup/README.md?WT.mc_id=academic-105485-koreyst)** leckét, hogy segítsünk fejlesztői környezeted beállításában.

Ne felejtsd el [megcsillagozni (🌟) ezt a tárolót](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst), hogy könnyebben megtaláld később.
